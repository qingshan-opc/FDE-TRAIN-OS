# 第 4 节 · 资源、工具与资料

## 资源

| 名称 | 路径 | 用途 |
|---|---|---|
| 后端智能体 | `/course-assets/bootcamp/day-01/agent-prompts/04-backend.md` | 接口、数据和运行交付 |
| 前端交接 | `day5-replay/frontend-handoff.md` | 本次联调请求合同 |
| 原 API 合同 | 项目根目录 `API_Spec.md` | 保持第一版兼容 |
| 原数据合同 | 项目根目录 `DB_Schema.md` | 判断是否需要数据变化 |

## 名词解释

| 名词 | 小白解释 |
|---|---|
| 兼容性 | 新改动不能让原有接口、数据或页面失效 |
| 数据迁移 | 数据结构变化时让旧数据安全适配新结构 |
| 联调 | 前端真实请求后端，并共同检查结果与错误 |
| 持久化 | 服务重启后，应该保留的数据仍然存在 |

## 联调证据卡

- 服务启动命令与实际结果；
- 健康接口结果；
- 一个成功请求；
- 至少一个错误请求；
- 重启后的数据结果；
- 前端真实页面发出的请求；
- 日志中没有泄露真实密钥。
