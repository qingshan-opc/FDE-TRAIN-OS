> 今日目标：**SQLite + 真实接口 + 前后端联调 V0.8**
> 总时长 130′ · 5 节 · 前四天少讲概念、跟着岗位交接做；第五天再用自己的项目系统复盘。

## 这一天在解决什么

学员先用自己的项目看懂前端、后端和数据库的数据链路，再指挥后端按已批准契约建表和实现真实接口，最后让前端从 Mock 切换到真实 API。AI 只保留 Week2 入口。

学员始终是项目负责人。Agent 负责岗位产出，学员负责提出任务、检查证据、纠偏和明确批准。任何岗位完成后必须停在 `REVIEW`；没有学员的 `APPROVED`，下一个岗位不得开工。
