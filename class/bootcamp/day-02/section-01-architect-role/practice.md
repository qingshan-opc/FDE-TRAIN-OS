# 第 1 节 · 练习

## 知识确认（3′）

1. 用一句话回答：为什么「最好的架构是什么」是个错误问题？
2. 说出架构师拍板前要数的四类约束。
3. ADR 记录的核心内容是什么？（提示：不是「选了什么」）

## 实操任务（5′）

打开你昨天的 PRD.md，在底部追加一段「## 我看到的约束」，凭直觉列出你的周报助手目前面临的约束，至少 3 条。示例：

- 团队：就我一个人 + AI，没人专职运维
- 用户量：部门 30 人，峰值同时在线不超过 10 人
- 时间：训练营期间要能跑起来

不用判断对错——第 4 节你会用架构师提示词正式回答它们。

## 一键粘贴提示词

> 整段复制给 Cursor / Claude Code / 平台 Agent / 任意 AI 搭档。尖括号 `〈〉` 换成你的路径或名称。

```text
你是架构师角色教练。用 5 问帮我分清：架构师和 PM / 写码的人差在哪。
每问我答后简评；最后用一句话定义「今天我要交出的架构决策长什么样」。
```

## 完成标志

- 能不看笔记说出四类约束；
- PRD.md 底部新增「我看到的约束」段，≥3 条；
- 能向同伴解释 ADR 记的是「为什么」而不是「是什么」。
