# 第 5 节 · 练习：运行冲刺（随堂 21′）

## 任务

1. **首跑**（6′）：说明书 + 输入 → 收货，存 `runs/<日期>-<名>/output.md`；
2. **验收**（5′）：按验收段逐条判，写 `verdict.md`：
   ```
   | 判据 | ✓/✗ | 证据（指出具体句） |
   | 总判：通过 / 不通过 |
   | 不通过项归因：说明书歧义 / AI 偏差 |
   ```
3. **迭代**（7′）：不通过 → 改说明书 → 重跑 → 再验收（记录每轮变化）；
4. **二连过**（3′）：连续 2 次全过，收工。

## 证据归档

```
runs/2026-07-24-<skill名>/
├── input.md      ← 这次喂的数据原文
├── output.md     ← 最终通过的产出
└── verdict.md    ← 最终验收单 + 迭代了几轮
```

## 一键粘贴提示词

> 整段复制给 Cursor / Claude Code / 平台 Agent / 任意 AI 搭档。尖括号 `〈〉` 换成你的路径或名称。

```text
你是评测员。按 skills/〈名称〉.md 的验收段，对我粘贴的 output.md 逐条判 ✓/✗ 并指出证据句。
不通过则只允许改说明书或重跑，不要手改产出凑数。
输出 verdict.md 表格，并建议下一轮说明书应改的那一句。
```

## 过关标准

- 连续 2 次验收全过（verdict 逐条 ✓）；
- 迭代过程有记录（改了几轮、每轮改了说明书哪句）；
- 三件套齐全进 Git。
