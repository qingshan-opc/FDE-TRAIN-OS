# 第 5 节 · 练习：上线实操（随堂 20′）

## 任务一：部署（10′）

- [ ] 仓库已连接，分支正确；
- [ ] 平台环境变量照清单配齐；
- [ ] 构建日志全绿，拿到公网 URL；
- [ ] （失败则）用管线定位法记录第一个红字与修复动作。

## 任务二：换设备验证（10′）

| 验证 | 设备/方式 | 结果 |
|------|----------|------|
| 六区块打开正常 | 手机（关 WiFi 用流量） | |
| 活数据：改库 → 页面同步 | 线上管理入口改 + 手机刷新 | |
| 断网关 → 降级版+标识 | 平台面板改错令牌，手机刷新 | |
| 恢复 → AI 版回来 | 令牌改回，手机刷新 | |
| 同桌设备打开 | 另一台电脑/手机 | |

（线上改库方式视平台而定：有的平台有 shell，有的需要重部署含新数据的镜像——问导师你的平台是哪种。）

## 过关标准

- 公网 URL 在两台不同设备可访问；
- 降级往返实测通过；
- 验证表填完交导师。
