## D5-L1 · README：给下一个人看的说明书

**使用方式**：Trae **通用对话**。

**学员指令**：

```text
请帮我完善 README.md 为正式交付版。要求四节：
1. 这是什么：一句话说清系统 + 三个核心页面截图位置说明；
2. 怎么跑起来：从零开始的运行步骤（假设接手的人什么都没装）；
3. 结构与团队：目录结构说明 + 我的一周开发方式（Trae 角色智能体团队：PM/UI/前端/后端/测试）；
4. 已知限制与下一步：诚实列出当前缺陷和 PRD 里"本期不做什么"，以及如果有第 6 天我会做什么。
先读一遍现有 README、PRD 和代码，再动笔；不要夸大任何功能。
```

**教学要点**：README 是交付的第一张脸——面试官/企业方先读它再决定要不要看你的系统。"诚实列出限制"不是减分，是专业。

**平台自检清单**：
- [ ] 我按 README 的步骤在"假装全新"的状态下走了一遍，能跑通
- [ ] 四节齐全，运行步骤没有"装一下依赖就行"这种省略
- [ ] 已知限制如实列出（对照 D3 缺陷清单）
- [ ] 没有夸大宣传的词

**纠偏指令库**：

| 问题 | 指令示例 |
|---|---|
| 运行步骤缺环境前提 | "请补上 Node.js 版本要求和安装命令——接手的人可能什么都没装。" |
| 把限制写得很隐晦 | "已知限制要写得明确具体，例如'AI 分析能力将在 Week2 接入，本周仅展示演示数据'，不要写'偶有小问题'。" |

## D5-L2 · 复盘与 5 分钟路演稿

**使用方式**：Trae **通用对话**（两段指令）。

**学员指令①（复盘）**：

```text
请帮我创建 docs/D5_项目复盘.md 的框架，包含四节：目标达成（对照 PRD 的 MVP 范围逐项核对）、偏差与原因、最大卡点（我卡在哪、怎么出来的）、可复制经验（下次做同类项目，哪 3 件事我还要这么做）。
框架你搭，内容我自己写——不要替我编感想。
```

**学员指令②（路演稿）**：

```text
请基于 docs/PRD.md、README.md 和我的项目现状，帮我列一份 5 分钟路演的提纲：价值（解决什么问题）→ 演示（从驾驶舱看板开场——先看真实统计，再演示一条记录从提交、入库到详情和看板更新）→ 限制（明确说明 AI 分析将在 Week2 接入，当前样例为演示数据）→ 计划（需要对方什么支持）。提纲你出，讲稿我自己写，控制在 800 字以内。
```

**教学要点**：复盘不是感想，是资产（白皮书：复盘必须既讲成功也讲失败）；路演是 FDE 面试题库原题——"用 5 分钟讲清一个 AI 项目的价值、限制、风险和需要配合的事项"。

**平台自检清单**：
- [ ] 复盘四节齐全，含真实数据（重交次数/求助次数/缺陷数）
- [ ] "可复制经验"3 条都是具体做法，不是"要认真"这种空话
- [ ] 路演稿 ≤800 字，含价值/限制/计划三要素
- [ ] 演示动线从驾驶舱看板开场，再进入单条记录全流程
- [ ] 两份文档是我自己写的（语义检查原创性）

## D5-L3 · Week 1 综合验收提交

**使用方式**：**平台内提交**（非 Trae）。平台展示验收清单，学员逐项上传/填写。

**提交内容**：
1. 项目运行证据（本地访问地址 + 关键页面截图或录屏）
2. 全部交付物路径清单（平台自动汇总 D1–D5 各节交付物，学员确认）
3. 个人陈述（≥200 字）：这个项目解决什么问题、我在其中具体负责什么、AI 帮了什么、什么是我判断和验收的

**验收项（平台自动验收 + 助教抽查）**：
- ① V1.0 可运行证据有效
- ② 5 天交付物链路完整（≥12 件）
- ③ 个人陈述通过语义检查（含"AI/方向/判断/验收"要素，非模板套用）
- ④ 全周诚实标记无违规（无编造路径、无未标"待建设"的缺失项）
- ⑤ 全周 Git 提交记录连续（≥5 次）

**平台自检清单**：
- [ ] 我在提交前自己又完整跑了一遍主流程
- [ ] 交付物清单我逐项确认过，没有挂名文件
- [ ] 个人陈述是我自己的话

## D5-L4 · 作品集与证书

**使用方式**：**平台功能**（非 Trae）。综合验收通过后自动解锁。

**学员操作**：
1. 生成个人作品集页：能力雷达（全栈系统理解/需求与产品/AI工具链/验收与质量）+ 5 天交付物时间线 + 项目亮点自述
2. 领取 Week 1 结业证书（唯一编号，可分享验真链接）
3. 打磨作品集"亮点自述"（≤150 字，将出现在分享页顶部）

**教学要点**：作品集怎么讲给面试官听——讲"我指挥 AI 团队按真实流程交付了一个系统"，而不是"我上了五天课"。**你的能力证据 = 12+ 件交付物 + 可验真证书，不是一张结课截图。**

**平台自检清单**：
- [ ] 作品集页展示 ≥12 件交付物
- [ ] 证书编号可验真（我自己点分享链接验证过）
- [ ] 亮点自述是我自己的话，提到了我的领域选题

## D5-L5 · 结业：下一步往哪走

**使用方式**：**平台功能** + 可选 Trae 打磨。

**学员操作**：
1. 登记意向（三选一，可多选）：**求职**（OPC 就业通道）/ **接企业订单**（OPC 订单对接指引，运营 7 天内跟进）/ **续报 Week 2**（Skill 及 Agent）
2. 观看 Week 2 预告片 + 运维工程师角色简介（部署概念，Week 2/3 实操）
3. 可选加分项：把项目演示录屏（≤3 分钟）补充进作品集

**结业寄语（课件收尾文案）**：
> 五天前，你在 Trae 里创建了六个"同事"；今天，你带着他们交付了一个真系统。
> 这一周你做的事有个正式的名字：**前线部署**——把模糊需求变成可验收结果。
> Week 2 见，我们让你的团队学会"技能"和"自主工作"。

**平台自检清单**：
- [ ] 意向已提交（求职/接单/续报至少一项）
- [ ] 我看完 Week 2 预告
- [ ] （可选）演示录屏已上传作品集
