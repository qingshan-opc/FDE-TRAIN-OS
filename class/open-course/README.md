**Day 1 快测 6 题（考点范围）**

1. 六次浪潮各自让「什么人」变得值钱？第六次浪潮你凭什么站上去？
2. 幻觉为什么「不是 bug 是机制」？
3. 同一个模型，为什么在 Agent 工具里比在聊天窗里「更能干」？（提示：harness）
4. 在生态四层里各放一个名词：GPT / Ollama / MCP / 你的驾驶舱。
5. RAG 解决什么问题？怎么解决的？
6. Eval 和「我觉得还行」的区别？
