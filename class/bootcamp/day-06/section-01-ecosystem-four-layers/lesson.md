## 讲授要点

### 四层生态地图（讲解图主线）

```
L4 应用层    驾驶舱 · Cursor · 企业 SaaS · 聊天产品
L3 编排层    RAG · Agent · Workflow · Prompt 管线
L2 模型层    GPT-4o · Claude 3.5 · Qwen · DeepSeek
L1 基建层    GPU 集群 · 向量库 · 模型网关 · 托管平台
```

### LLM · 大语言模型

- 机制：用海量文本训练，**预测下一个 Token**；
- 能力：生成、理解、推理、Tool Call——都从接龙机制长出；
- 边界：不是事实库，输出必须验收（下节细讲幻觉）。

### 开源权重 vs 闭源 API

| | 闭源 API | 开源权重 |
|---|---------|---------|
| 代表 | OpenAI、Anthropic、Google | Meta Llama、阿里 Qwen、Mistral |
| 拿到方式 | 调 endpoint，按 Token 付费 | 下载权重，自部署 |
| 权衡 | 快、省心、能力顶 | 成本、隐私、运维自己扛 |

### 多模态 · Multimodal

- 不只文本：看图（GPT-4o）、听音、出图（Midjourney）；
- **本课边界**：驾驶舱只用文本能力——摘要、问答、Tool Call；
- 知道有就行，别用文本模型硬做它不擅长的事。

### FDE 站在哪一层？

- **应用层**：你的驾驶舱、验收标准、用户体验；
- **编排层**：Prompt、RAG、Agent 流程——Week 2 主战场；
- 模型层/基建层：知道名字和权衡，选型交给作业和公开课 O3。

## 🎬 口播稿（7 段 · v2 口语化版 · 已过审）

> 同学们，第六天了。前五天呢，你们用过 ChatGPT，写过 Prompt，第五天还调过那个摘要接口——AI 用是用了，可你真要问"这玩意儿到底是怎么运作的"，估计大部分人说不太清。今天咱们不写代码了，就把这些天用过的东西，从根上捋一遍。第一节先把整张生态地图铺开，品牌名不用记，记一个问题就行：我以后干活，到底在生态的哪一层，对吧。
>
> 先说最底下这层，LLM，大语言模型。它到底在干嘛呢？就一件事：猜下一个词。你给它一段话，它就琢磨"接下来最可能接啥"，然后一个词一个词往外蹦。GPT-4 啊、Claude 啊、还有咱们用的 DeepSeek，名字不一样，底下都是这个活儿。还记得第五天那个比方吗——它就是个认字特别快的实习生，但你别拿它当字典查，它没核实过，嘛。
>
> 整个生态呢，分四层，从下往上：基建、模型、编排、应用。打个比方，就当一栋楼。基建是地基水电——GPU、算力、向量库，盖楼先得有这些；模型层是楼层本身，GPT、Claude、DeepSeek 这些牌子；编排层是装修，Prompt、RAG、Agent，把毛坯房装成能住人的样子；应用层就是你开的店，驾驶舱、客服、写作助手，对吧。
>
> 那问题来了，你在哪层？同学们记好，咱们主要在顶上两层干活——编排和应用。啥意思？就是定方向、验货、把模型接到自己的业务里去。换模型，那是换模型层的牌子，不归你管；地基更不用你操心。这个定位记牢，后面九天你动手的地方，全在这两层，嘛。
>
> 模型层有个事儿得说清楚，就是开源还是闭源。别被这俩词绕进去，真正的区别是——你是调别人 API 呢，还是把模型下载到自己机器上跑。GPT、Claude 这种闭源的，只能调 API，按用了多少 Token 付钱，省心。DeepSeek、Qwen 这种是开源的，权重能下载，你想省钱、怕数据外泄，就自己买机器部署。但注意啊，开源的也能调 API——咱们这门课，就是用 DeepSeek 的 API 接进来的，又便宜又不用自己运维，对吧。所以不是非此即彼，看你图啥：要能力、要省钱、还是要数据不出门，自己掂量。
>
> 还有个词儿，多模态。啥意思呢，就是这模型不光会认字，还能看图、听声音、甚至出图。但咱们这门课的驾驶舱，刻意只用文本——摘要、问答、调工具，就这些。为啥？你得让模型干它擅长的活儿，别拿一个文字模型硬去认图，那是为难它。知道它几斤几两、能干啥不能干啥，比啥都重要，嘛。
>
> 好，第一节收一下。四层地图，基建、模型、编排、应用，你在顶上两层。今天讲的 18 个词儿，全都是从这四层里长出来的。带走一句：这些词不是课文，背完就完——它是你的随身工具，以后哪天听见个词发懵，回来翻这一页就行。下一节咱们拆 Token、上下文窗口、还有幻觉，对吧。
