## 口试四件套（必背）

1. **Harness 四要素**：模型、工具表、记忆、循环（各说一个你的对应产物）；
2. **决策环**：理解 → 规划 → 调工具 → 观察 → 继续；
3. **workflow vs agent**：步骤定死 vs 路径现想；能 workflow 别 agent；
4. **选错图谱**：「我的 Agent 在 ____ 措辞/任务下会误选/漏选，因为 ____，我用 ____ 修了描述。」
