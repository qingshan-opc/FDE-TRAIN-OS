# 第 5 节 · 实战：部署 + 换设备验证（25′ · 实战）

> 🎬 视频位（现阶段：口播稿）
> 按钮按下去。25 分钟后，你的驾驶舱将拥有一个公网地址——发到群里，所有人都能点开。

## 教学目标

- 在托管平台完成部署：连仓库 → 配环境变量 → 构建 → 拿到 URL；
- 完成换设备验证：手机/同桌电脑打开，六区块正常；
- 掌握线上排障路径：构建日志 → 运行日志 → 管线定位（第 1 节的方法实战化）。

## 部署四步（托管平台通用）

```
① 连仓库：平台授权读你的 Git 仓库，选分支（main）
② 配变量：照第 2 节的平台变量清单逐个填入（GATEWAY_TOKEN 等）
③ 构建运行：平台自动跑管线——盯着构建日志，绿了就拿到 URL
④ 复跑清单：在公网 URL 上把 release-checklist 再跑一遍
```

## 线上排障路径（线上≠本地时的反思）

| 症状 | 先想 | 再看 |
|------|------|------|
| 构建失败 | 依赖/版本 | 构建日志第一个红字 |
| 构建成功但打不开 | 启动命令/端口（`--host 0.0.0.0`） | 运行日志 |
| 打开了但数据空 | 数据库文件随镜像了吗 | 运行日志 + 平台文件说明 |
| 摘要一直降级 | 平台变量配了吗/配对了吗 | 环境变量面板 + 运行日志 |

> 心法：**线上每个问题都能映射回管线五步**——第 1 节的找位置练习，今天全部变现。

## 🎬 口播稿（约 1 分钟）

> 「四步：连仓库、配变量、看构建、复跑清单。前两步五分钟，第三步看运气——构建日志红了别慌，第一个红字就是病灶，它和管线五步一一对应。
> 拿到 URL 别急着发群里：先自己手机开流量打开——WiFi 关掉，用真公网。六区块看一遍，断网关测降级，改库测活数据。
> 全绿，发群里。这就是 V1.0。」

## 常见懵点

- 「手机打开样式乱了？」→ 好发现：说明 V0.1 没考虑小屏——记入 backlog，V2 做响应式；今天只要功能可用；
- 「URL 好丑，能换域名吗？」→ 能，要买域名配 DNS（公开课 O3）；今天平台域名够用；
- 「别人能改我的数据吗？」→ 本课应用没有写接口暴露给页面，安全；真实项目要认证（公开课 O3）。

> 拓展（非必修）：自定义域名与 HTTPS、CDN、访问认证 → 公开课 O3 部署篇。
