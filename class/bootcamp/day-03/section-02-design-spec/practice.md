# 第 2 节 · 练习

## 知识确认（3′）

1. 设计规范四件套是哪四件？每件举一个「不给规范时 AI 会怎么自由发挥」的例子。
2. 为什么占位符文案（如 lorem ipsum）会让原型「看起来没问题、上线就翻车」？

## 实操任务（10′）

为「部门周报助手」写一份最小设计规范，直接存为 `design-spec.md`（稍后实战节要把它喂给 AI）：

1. **颜色**：主色、辅助色、警示色各 1 个，写十六进制色值（提示：效率工具常用蓝系主色，警示色常用红/橙）；
2. **字号层级**：大标题 / 区块标题 / 正文 三级，各给像素值；
3. **间距**：定一个基准数，写出它的 2、3、4 倍各用在哪；
4. **圆角阴影**：卡片和按钮的圆角值各一，卡片阴影一句话描述；
5. **三态**：描述主按钮在默认 / 悬停 / 禁用三态下的区别。

## 完成标志

- `design-spec.md` 覆盖四件套 + 三态，每项都有具体数值；
- 全文没有一个「好看」「大气」「高级感」这类不可验收的词；
- 知识确认两题均有书面答案。
