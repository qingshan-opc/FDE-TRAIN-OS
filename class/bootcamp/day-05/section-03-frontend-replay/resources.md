# 第 3 节 · 资源、工具与资料

## 资源

| 名称 | 路径 | 用途 |
|---|---|---|
| 前端智能体 | `/course-assets/bootcamp/day-01/agent-prompts/03-frontend.md` | 检查、实现与交接 |
| UI 交接 | `day5-replay/ui-handoff.md` | 前端实现合同 |
| 原前端交接 | 项目根目录 `frontend-handoff.md` | 找到第一版入口和运行方法 |

## 名词解释

| 名词 | 小白解释 |
|---|---|
| 改动清单 | 开工前写清要改哪些文件和原因 |
| 无关重构 | 与本次需求无关的目录调整、改名或技术替换 |
| 请求合同 | 方法、路径、字段、响应和错误的共同约定 |
| 前端自检 | 由前端确认页面、交互、请求和控制台结果 |

## 前端自检卡

- 页面能够打开；
- 新入口能够找到；
- 加载和空数据有反馈；
- 成功结果与原型一致；
- 错误状态能够恢复；
- 控制台没有新增报错；
- 请求内容与交接合同一致。
