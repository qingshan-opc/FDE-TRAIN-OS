# 第 5 节 · 练习

## 知识确认（3′）

1. PRD 过闸三要素是什么？各用一句话说出判据。
2. 「验收前移」是什么意思？为什么今天的 PRD 质量会影响明天的架构课？

## 实操任务（10′）

**过闸自查与提交**：

1. 打开你的 `PRD.md`，对照三要素逐条打勾：用户故事 ≥3 条且句式完整 / 每条可衡量验收标准 / 写明目标平台；
2. 任一项不达标：回到 AI 对话补约束重生成，更新 `PRD.md` 后再查一遍；
3. 完成日级快测 6 题（≥4 题合格，当晚可重测）；
4. 提交 `PRD.md` 过闸——lab 机器校验将检查文件存在及「用户故事」「验收标准」两节。

## 一键粘贴提示词

> 整段复制给 Cursor / Claude Code / 平台 Agent / 任意 AI 搭档。尖括号 `〈〉` 换成你的路径或名称。

```text
你是 GATE 考官。我将粘贴 PRD.md。
请按三要素打勾/打叉：用户故事句式、可衡量验收、目标平台。
缺项给出「补哪句约束、如何重生成」的指令，不要替我手改 PRD 正文。
```

## 完成标志

- 快测 ≥ 4/6 合格；
- `PRD.md` 三要素自查全部打勾，且通过 lab 机器校验；
- 能口头说明：这份 PRD 明天交给架构师提示词时，对方最关注哪几个字段。
