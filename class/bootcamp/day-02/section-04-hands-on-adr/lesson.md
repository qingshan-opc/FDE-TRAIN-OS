# 第 4 节 · 实战：用架构师提示词写下你的前三条 ADR（35′ · 实战）

> 昨天你定义了做什么，今天你决定怎么搭——把 PRD.md 交给架构师 Agent，产出 architecture.md。

## 教学目标

- 解剖 Architect_Agent_Prompt.md：认出四要素 + 两接口，知道每段在管什么；
- 用提示词驱动 AI，基于 PRD.md 生成 architecture.md：架构风格 + 否决理由、分层图、3 条 ADR；
- 学会「先澄清约束再动笔」的工作节奏，拒绝一步到位。

## 讲授要点

### 第一步：解剖提示词（10′）

打开 `Architect_Agent_Prompt.md`，对照工具包 README 的「四要素 + 两接口」找到对应段落：

| 要素 | 在这份提示词里的位置 | 它管什么 |
|------|---------------------|----------|
| 角色定位 | 开头「你是一位拥有 12 年以上经验的资深软件架构师」 | 决定回答的专业水位 |
| 核心任务 | 「基于 PRD 与非功能需求完成架构设计……记录为 ADR」 | 职责边界：它做什么、不做什么 |
| 关键输入 | 「从 docs/PRD.md 获取」 | 上游交付物从哪读——**这就是为什么 Day 1 的 PRD 必须写好** |
| 关键输出 | architecture.md / adr/ / architecture-handoff.md | 下游（明天的前端、后天的后端）拿什么开工 |
| 协作说明 | 「接收 PM 的 PRD……产出分发给后端工程师」 | 它在流水线的第几棒 |

注意工作流程第 1 条：「**首先通过提问澄清关键约束**」——好提示词自己会反问，这正是第 1 节教的「先数约束再谈方案」。

### 第二步：驱动它干活（20′）

操作顺序（本地 AI 工具或 Agent Lab 均可）：

1. 把 Architect_Agent_Prompt.md 整份粘进对话框；
2. 告诉它：「PRD 在工作区的 PRD.md，请先读，再开始」；
3. **它会反问你约束问题**——用第 3 节填的四问答案回答（团队/用户量/运维条件）；
4. 要求产出三件套：
   - 架构风格选择 + 至少一个被否决方案及理由；
   - 四层分层图（文字表格或 Mermaid）；
   - 3 条 ADR，每条含背景 / 决策 / 理由 / 后果。

建议的 3 条 ADR 主题（可从这选，也可自定）：

- ADR-001：架构风格（单体 vs 微服务 vs Serverless）
- ADR-002：数据库选型（如 SQLite vs PostgreSQL）
- ADR-003：模型调用方式（直连 API vs 后端封装代理）

### 第三步：人工过一遍（5′）

AI 生成 ≠ 合格。逐条检查：理由是否引用了你的真实约束？否决方案是否写清？后果是否包含「什么信号出现时要推翻它」？——引用不实的，指出来让它重写，**不要手改产物，改约束重新生成**。

## 🎬 口播稿（约 2 分钟）

【抛问题】
同学们，给你一份 80 行的提示词，你怎么知道它好不好、会不会用？——像读合同一样读它。今天带你们解剖一遍。

【解剖】
打开架构师提示词。开头第一句，「角色定位」——12 年经验的架构师，这决定了回答的水位。往下，「核心任务」，它的职责边界。再往下，「关键输入」——从 PRD.md 读需求。看到没有，「这就是为什么你昨天的 PRD 必须写好」：上游的交付物，就是下游的燃料。最后是「关键输出」和协作说明——它在流水线的第几棒。

【节奏】
注意它工作流程的第一条——「先提问澄清约束，再动笔」。好提示词自己会反问你。它问团队、问流量、问运维，你就拿第三节填的四问回答它。「别要它一步到位，对话才是工作方式。」

【验收】
产出三样东西：架构风格加否决理由、四层分层图、三条 ADR。每条 ADR 四要素——背景、决策、理由、后果。「AI 生成不等于合格」，理由没引用你的真实约束，就让它重写。记住口诀：不手改产物，改约束重新生成。

【带走的话】
带走一句话——「提示词是合同，ADR 是签字。」

## 常见懵点（导师备用）

- 「AI 直接给了我一份完美文档，还要检查什么？」→ 检查理由的「真实性」：它可能编造你没说过的约束（比如假设你有 5 人团队）——这是幻觉在文档里的形态；
- 「3 条 ADR 都要很长吗？」→ 不用，每条 100–200 字足够，关键是四要素齐全、理由引用真实约束；
- 「Mermaid 图生成不出来怎么办？」→ 用文字分层图完全合格（四层表格 + 每层的组件），图是手段不是目的；
- 「我可以直接把 AI 输出交差吗？」→ 可以交，但导师闸会问「为什么不是微服务」——答不出就是没消化，回去补。
