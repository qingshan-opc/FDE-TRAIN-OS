两步选型法

第一步定平台（用户在哪用你：浏览器 / 应用商店 / 微信里 / 桌面图标）；第二步选框架，四问按顺序：团队会什么 → 生态大不大 → AI 写得好不好 → 项目有多大。
自测 3 问

1 · 小团队要做 iOS+Android 两端、一套代码，选什么？

Flutter 或 React Native（跨端）。原生 Swift+Kotlin 要养两套代码两拨人，是大厂重体验产品的玩法。

2 · 做国内「扫码即用」的点单应用，平台选什么？

小程序——微信原生最稳；要同时出支付宝/抖音小程序就选 Taro 或 uni-app。

3 · 两周原型、千万级订单系统、向量相似推荐，数据库各选什么？

SQLite → PostgreSQL/MySQL → PostgreSQL（pgvector 向量插件）。场景决定数据库，不是名气。
