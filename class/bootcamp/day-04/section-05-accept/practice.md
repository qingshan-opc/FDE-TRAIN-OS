# 第 5 节 · 实操任务

## 本节任务

整理七类证据并检查 Git 记录。

**指挥对象**：通用对话

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@项目经理 Agent 请只整理项目里真实存在的成果，带我逐项核对需求、页面样稿、四个页面、真实数据、检查记录和问题修复。一次核对一类，找不到就写“缺失”，不能编造。全部核对后整理成交付材料清单，等我批准功能冻结。
```

## 学员验收清单

- [ ] 七类证据均可打开
- [ ] 状态与真实执行一致
- [ ] 版本标记对应冻结版
- [ ] 能口述功能、缺陷和 Week2 AI 边界

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
