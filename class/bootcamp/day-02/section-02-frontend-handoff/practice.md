# 第 2 节 · 练习

## 知识确认

1. 四份上游文件各自回答什么问题？
2. 为什么前端必须先复述、不能直接开发？
3. 谁可以回复“确认开发”？

## 本地实操

严格按顺序发送四段提示词：

### P1 · 检查文件

> 请检查工作区是否存在 PRD.md、design-spec.md、ui-flow.md 和 ui-prototype.html。现在不要生成代码。缺少文件时只告诉我缺什么、应切回哪个岗位补齐。

等待检查完成。

### P2 · 五句复述

> 请用 5 句话复述目标用户、页面范围、最重要操作、必须出现的数据状态和前端验收标准。输出后停止。

对照文件纠正偏差。

### P3 · 实施清单

> 理解已经确认。请给出《前端实施清单》，固定使用 frontend/index.html、frontend/styles.css、frontend/app.js，并列出区块、交互、演示数据位置、四种状态和暂不连接的接口。现在不要创建文件。

### P4 · 人工确认

检查清单后，学员本人回复：

> 确认开发。下一步仍然分段完成，不要一次生成全部功能。

## 完成标志

- 四份文件检查结果完整
- 五句复述与原文件一致
- 前端实施清单包含三文件和四种状态
- 确认前没有新建前端代码
