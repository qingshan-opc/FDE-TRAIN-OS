## 4. 三周课纲（被问「都学啥」时用）

只在对方追问细节时发，避免一次刷屏。

**第一周 · 指挥 AI，做出你的产品**  
组建六岗位团队 → 用自己的专业选题 → PRD → 可点击原型 → 真页面 → 真数据 → 测试交付。

对话助手 → 可执行 Skill → Agent 循环 → 长任务 + 人工确认。

**第三周 · 企业沟通特训**  
听懂老板真正要的、把任务写成可验收、把价值讲清楚、把卡点推动下去。
