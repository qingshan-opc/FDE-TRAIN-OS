# 第 3 节 · 练习

## 知识确认

1. HTML、CSS、JavaScript 分别负责什么？
2. 页面有样式但按钮不响应，应该先检查哪个文件和哪个工具？
3. 四种数据状态分别解决什么用户疑问？

## 本地辨认

打开任意一个已有 HTML 文件，只做以下观察：

- 找到 `<link>` 或 `<style>`，判断样式来自哪里；
- 找到 `<script>`，判断行为来自哪里；
- 按 `F12` 打开控制台；
- 不修改文件，不粘贴陌生代码到控制台。

## 状态口述

从自己的项目选一个页面，用四句话说明：

- 加载时显示什么；
- 没有数据时显示什么；
- 成功时显示什么；
- 失败时用户怎样重试。

## 完成标志

- 能用生活语言解释 HTML、CSS、JavaScript 三个文件各自负责什么
- 能打开控制台并找到红色错误区域
