# 新概念词典 · 18 词（FDE 训练营随身附件）

> 用法：这不是课文，是词典。十天里听到任何词发懵，回来查这一页。
> 每词三行：**一句话**（能复述就算懂）· **在哪遇到**（课程第几天）· **延伸阅读**（可选）。

## A. 模型本体

**LLM（大语言模型）**
一句话：用海量文本训练出的「预测下一个词」的机器，生成、理解、推理都从这个机制长出来。
在哪遇到：Day 1 第 2 节；Day 5 接电。
延伸：3Blue1Brown《But what is a GPT?》（视频）

**Token 与上下文窗口**
一句话：模型读写的基本单位（约 0.6–1 个汉字）；上下文窗口是它「一次能看到的字数上限」。
在哪遇到：Day 5（为什么摘要接口要控制输入长度）。
延伸：任意模型的 tokenizer 在线演示。

**幻觉（Hallucination）**
一句话：模型永远在给「最像真的」的答案，而不是「经过核实」的答案——幻觉是机制，不是 bug。
在哪遇到：Day 1 第 2 节；Day 5 第 6 节「AI 输出的验收」。
延伸：随便问模型一个冷门事实并人工核实一次。

**开源权重 vs 闭源 API**
一句话：闭源（GPT/Claude/Gemini）只能调 API；开源权重（Qwen/DeepSeek/Llama）可下载自部署——能力、成本、隐私的三角权衡。
在哪遇到：Day 1 生态图；Day 5 模型网关。
延伸：Hugging Face 模型榜看一眼。

**多模态（Multimodal）**
一句话：不只读写文字，还能看图、听音、出图的模型。
在哪遇到：Day 1 生态图（本课只用文本能力）。
延伸：——

## B. 使用方法

**Prompt / Prompt 工程**
一句话：给模型的任务说明书；工程化 = 角色+背景+任务+约束+输出格式，可迭代、可验收。
在哪遇到：Day 2 Prompt 草稿；Day 5 结构化进阶；速查卡附件。
延伸：`cheatsheet-prompt.md`

**Context Engineering（上下文工程）**
一句话：决定「这次调用放什么进模型的视野」的手艺——给少了它瞎编，给多了它迷失。
在哪遇到：Day 5（摘要接口选哪些数据喂进去）；Week 2（Agent 每轮看到什么）。
延伸：Anthropic 博客《Effective context engineering for AI agents》

**RAG（检索增强生成）**
一句话：先从资料库里检索相关片段，再让模型基于片段回答——治幻觉的主流药方之一。
在哪遇到：Day 1 词典；本课不深入（Week1 红线），知道概念即可。
延伸：任意「RAG in 100 lines」教程。

**Fine-tuning vs Prompting**
一句话：改模型的权重（贵、慢、持久） vs 改给模型的话（快、便宜、每次重新给）——90% 的场景先用后者。
在哪遇到：Day 1 词典。
延伸：——

**Eval（评测）**
一句话：给 AI 产物出考卷：固定题库 + 明确判分，代替「我觉得还行」。
在哪遇到：Day 5 摘要质量 Rubric；Week 2 Skill 验收用例。
延伸：——

**Guardrails（护栏）**
一句话：拦在模型输入输出上的规则——什么不许问、什么不许答、越界时怎么办。
在哪遇到：Day 8 Skill 边界声明就是护栏的一种。
延伸：——

**Vibe Coding（氛围编程）**
一句话：用自然语言描述意图、让 AI 写代码的开发方式；爽点是真的，验收责任也是真的。
在哪遇到：整门课都是——但我们练的是「带验收的 vibe coding」。
延伸：Andrej Karpathy 的原帖（2025.2）

## C. Agent 世界

**Agent（智能体）**
一句话：能自己决定下一步做什么的 AI：理解任务 → 规划 → 调用工具 → 观察结果 → 继续，直到完成或求助。
在哪遇到：Day 8 正式见面；Day 9–10 编排。
延伸：Anthropic《Building effective agents》

**Harness（智能体骨架）**
一句话：让 Agent 跑起来的那套「模型之外的循环」——工具表、记忆、规划、重试、日志都写在 harness 里；同一个模型换一副骨架，能力天差地别。
在哪遇到：Day 8 第 3 节（本课 Agent 平台就是一副 harness）。
延伸：对照体验：同一个模型在聊天窗 vs 在 TRAE 里的差别。

**Workflow vs Agent**
一句话：Workflow 是人写死的流程图（A 完了必走 B）；Agent 是模型现场决策下一步——能写死就写死，写不死才上 Agent。
在哪遇到：Day 8 第 3 节；Day 9 编排。
延伸：Anthropic《Building effective agents》同名章节。

**Tool Calling（工具调用）**
一句话：模型输出「我要调用 X 工具、参数是 Y」的结构化请求，由 harness 执行后把结果喂回去。
在哪遇到：Day 8 Agent 调用你的 Skill 的底层机制。
延伸：OpenAI function calling 文档（看示例即可）。

**MCP（Model Context Protocol）**
一句话：给 AI 接工具/数据源的「USB-C 接口标准」——按标准写一个服务，所有支持 MCP 的 Agent 都能用。
在哪遇到：Day 1 生态图；Week 2 的 Skill 就是它的朴素版。
延伸：modelcontextprotocol.io 首页示例。

**副驾模式 vs 智能体（副驾驶 vs 自动驾驶）**
一句话：副驾模式 是你开它递扳手（补全、问答）；Agent 是你定目的地它开（接任务、跑流程）——信任要求和验收方式完全不同。
在哪遇到：Day 1 词典；Day 8 体会最深。
延伸：——
