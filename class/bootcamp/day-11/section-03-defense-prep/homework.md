# 第 3 节 · 作业

## 随堂验收

- 提纲一页纸填满（关键词式，非逐字稿）；
- 作品段掐表 ≤3′ 且练过兜底预案。

## 课后（20 分钟内）

1. **完整彩排 2 遍**：掐表，总时长 ≤8′；
2. **找一个人讲一遍**（同学/朋友/AI 导师）：让他只问一个问题——「你哪句没听懂」；
3. **兜底材料备齐**：日志截图、全景图、自证表、迭代日志，放同一个文件夹；
4. 早睡。答辩状态比多改一版 PPT 值钱。

## 提交

```bash
git add 答辩提纲 兜底材料
git commit -m "docs: 答辩提纲与兜底材料"
```
