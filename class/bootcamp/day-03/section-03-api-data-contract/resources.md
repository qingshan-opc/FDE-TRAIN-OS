# 第 3 节 · API 与数据合同模板

## API 模板

```markdown
### 接口名称
- 方法与路径：GET /api/items
- 用途：查询列表
- 请求：query、page
- 成功：200 + JSON 示例
- 错误：400 参数错误；500 服务错误
```

## 数据表模板

```markdown
### items
| 字段 | 类型 | 主键 | 必填 | 说明 |
| id | INTEGER | 是 | 是 | 唯一编号 |
```

## 常见状态码

- `200` 查询或修改成功；
- `201` 创建成功；
- `400` 输入不符合合同；
- `404` 目标不存在；
- `500` 后端内部故障。
