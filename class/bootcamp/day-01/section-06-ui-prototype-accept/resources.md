# 第 6 节 · UI 交接与验收卡

## UI 开工前五句复述

- 主要用户是谁；
- 核心问题是什么；
- 用户最重要的操作是什么；
- 第一版有哪些页面或区块；
- 哪些验收标准必须在原型中看得见。

## UI 三份交付物

- `design-spec.md`：视觉与状态规范；
- `ui-flow.md`：页面、跳转和按钮行为；
- `ui-prototype.html`：可直接打开、可点击、使用演示数据的原型。

## 产品经理验收句式

> 请按 `PRD.md` 逐项输出“通过/不通过、对应原文、责任岗位”。只检查，不直接修改 UI 文件。

## 闭环

```text
产品经理发现问题 → UI 修改 → 产品经理复验 → 写入交接日志
```
