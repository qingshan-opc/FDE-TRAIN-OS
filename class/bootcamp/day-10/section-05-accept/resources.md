# 第 5 节 · 资源：验收材料包

## 1. 口试速查卡

```
确认闸三问
  ① 看什么    → 草稿 + 关键数字 + 风险标红（决策所需的最低信息）
  ② 谁来看    → 有责的那个人（本课＝你）
  ③ 多久看一次 → 信任分级：每次都看 → 连续通过攒额度 → 抽看 → 抽看+定期审计

三反模式（闸的死法）
  信息不足 → 逼人盲批     破：确认界面给够决策信息
  频率麻木 → 弹多了必盲批  破：信任分级降频率 + 只在不可撤回步骤前设闸
  无痕可追 → 出事甩锅     破：执行日志三要素，批准驳回都留痕

金句：确认点 + 日志 ＝ 信任的工程设计
```

## 2. GATE 9 评分表（导师用，学员可自评）

| 项 | 通过标准 | 分值 |
|----|---------|------|
| 工具表 3 件 | 说明书 + 边界 + 工具描述，无模糊词 | 20 |
| 编排文档 | 步骤定死、数据流清、闸位正确 | 20 |
| 闸口实测 | 停 / 批 / 驳回三态全部现场演示成功 | 30 |
| 执行日志 | 三要素齐、可回放 | 20 |
| 口试 | 三题至少两题完整 | 10 |

80 分以上过；闸口实测三态缺一态＝不过，现场修完重测。
