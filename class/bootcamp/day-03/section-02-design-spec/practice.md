# 第 2 节 · 实操任务

## 本节任务

指挥后端建表，并要求他用业务语言解释每个字段。

**指挥对象**：@后端工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@后端工程师 Agent 请按已批准的需求，为业务记录建立本地数据仓库。先用大白话逐项告诉我“要保存什么、为什么要保存”，一次只确认一个有疑问的内容。确认后再建立，并用一条演示记录证明它能保存和读出，等我检查。
```

## 学员验收清单

- [ ] 字段与 PRD 和契约一致
- [ ] 状态值受约束
- [ ] 有主键和时间字段
- [ ] 数据库真实创建且能被程序访问
- [ ] 学员能复述核心字段

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
