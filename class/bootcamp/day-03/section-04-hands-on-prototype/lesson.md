# 第 4 节 · 为第二周保留真实 AI 接入口（20′ · 实操+交接）

> 分期开发要诚实：接口可以先定义，但没有接模型就必须明确返回未接入，不能用固定文字冒充 AI。

## 教学目标

- 学员能用自己的项目解释本节概念，而不是背技术名词；
- 学员能向指定岗位下达一句清楚的任务，并说出验收口径；
- 学员只根据真实文件和运行证据批准交付。

## 讲授要点

- 预留接口保持契约形状。
- Week1 返回 501 AI_NOT_CONNECTED 或等价明确状态。
- 交接文档写清第二周 Agent 的输入、输出和写回位置。

**本节岗位**：@后端工程师 Agent

**本节产出**：AI 预留接口 + Week2 交接文档

**本周共同边界**：本周只做桌面 Web 单应用、本地数据库和可验证的数据链路；不做手机端、登录、复杂权限、Docker、生产级高可用，也不接真实 AI。

AI 可以生成文件、代码和建议，但批准权不能交出去。你要看实际文件、亲手验证，再决定通过还是返工。

同学们，本节先到这里。

## 常见懵点（导师备用）

- “能不能让一个 Agent 一次做完？”→ 可以很快看到结果，但会失去岗位交接、状态变化和验收过程，这正是本课要学的部分。
- “我不懂代码怎么验收？”→ 先按页面、文件、请求响应和数据变化验收；让工程师解释原因，不要求学员先会写代码。
- “Agent 说完成了是不是就算完成？”→ 不算。只有实际文件存在、验证真实执行且学员明确批准，状态才从 REVIEW 进入 APPROVED。
