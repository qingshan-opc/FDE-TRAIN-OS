# 第 1 节 · 实操任务

## 本节任务

让通用 AI 只读当前项目并画出证据地图，不修改代码。

**指挥对象**：通用对话

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@项目经理 Agent 请只查看当前项目，带我画一张“数据旅行地图”：用户提交后，数据怎样被保存，又怎样来到列表、详情和驾驶舱。一次只讲一站，让我先复述再继续。最后整理成项目地图；AI 那一站标“第二周接入”。
```

## 学员验收清单

- [ ] 六部分都有真实证据路径
- [ ] 数据链路能从用户操作讲到看板更新
- [ ] Mock 与真实数据状态区分清楚
- [ ] AI 标记为 Week2

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
