# 第 4 节 · 实操任务

## 本节任务

和测试工程师逐项核对，确认没有阻塞缺陷后宣布冻结。

**指挥对象**：@测试工程师 Agent + 学员批准

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@测试工程师 Agent 请带我重新检查已修复的问题，并顺手检查相关功能有没有被带坏。一次只检查一项，按我的真实观察记录结果。最后汇总哪些通过、哪些没通过；驾驶舱数字必须和真实记录对得上。等我批准后才能宣布停止加新功能。
```

## 学员验收清单

- [ ] 四类验收项都有证据
- [ ] 看板数据可追溯
- [ ] 未通过项未被隐藏
- [ ] 冻结由学员明确宣布
- [ ] 冻结后没有新增功能

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
