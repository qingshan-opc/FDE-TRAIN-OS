## 任务二：workflow or agent（4′）

四个任务，各选 workflow 还是 agent，说一句理由：

1. 每周五 17:00 自动生成本周周报；
2. 「帮我看看这份数据里有什么值得注意的」；
3. 每月 1 号把上月数据归档成固定格式文件；
4. 「这个客户为什么流失了？帮我查查各个环节」。

## 过关标准

- 追踪表填完，能指出哪一环昨天是你人肉做的；
- 四题选择合理（1/3 是 workflow，2/4 是 agent），理由落在「可预测 vs 路径多样」。
