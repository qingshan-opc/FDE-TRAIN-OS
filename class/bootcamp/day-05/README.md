## 这一天在解决什么

前四天你手里已经有了真东西：PRD、架构决策、高保真原型、接口与数据库设计。
问题是你可能「会做但说不出」——周五晚上别人问你「这一周学了什么」，你只能掏出几个文件。

理论课为什么放在第五天而不是第一天？**先有体感，再给名字。**
第一天就讲云原生和技术地图，你一个字也记不住；现在每一个理论你都能指着工作区里的文件说「哦，原来这个就是」。

今天的节奏也和前四天不同：没有新提示词、没有新工具，每节 20–30 分钟完整讲授——
设计模式这类「以后才用得上」的内容今天特意不讲（太深，留给第二周以后的你自己），
讲的是你下周就绕不开的：企业数字化五阶段、软件怎么开发出来的、服务器与云原生（含部署管线最小必要，第 4 节讲完五站演进后立刻进终端实验台把命令行八句真敲一遍）、前端四大平台地图、后端语言/框架/数据库地图（**只认地图，课里不给选型建议**——作业由你自己交「我选什么、为什么」）。

下课前，两道手续：快测 21 题；理论地图 theory-map.md 作为企业任务提交。
