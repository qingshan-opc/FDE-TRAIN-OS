# 第 5 节 · 本地实操与提交验证

## 第一轮人工验收

打开 `frontend/index.html`，逐项写“通过/不通过”：

- 页面可打开；
- 页面区块与 PRD 一致；
- 主要操作有可见反馈；
- loading / empty / success / error 均可查看；
- 控制台没有红色错误。

## 四句问题单

每个不通过项写：

```text
位置：
操作：
实际：
预期：
```

## 交给前端

> 请只修复下面的问题，不改变已通过部分和 PRD 范围。逐项说明原因、修改文件和复测步骤。问题清单：〈粘贴四句问题〉。

## 复测

执行与第一次完全相同的操作，保存 `frontend-acceptance.md`，至少包含：

- 第一轮结果；
- 问题单；
- 前端修改文件；
- 第二轮复测结果。

没有真实问题时，由导师指定一条模拟问题，例如临时要求隐藏空数据提示，再要求前端恢复正确状态，用于练习闭环。

## 完成标志

- 已按五项做完第一轮人工验收（通过/不通过）
- 不通过项已写成四句问题单
- 已保存可读取的 frontend-acceptance.md（含两轮结果与复测结论）
- 没有只交「已完成」截图
