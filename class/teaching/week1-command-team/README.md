# 第一周课程设计资料

当前平台课节的唯一生成源是仓库根目录的 `scripts/land_week1_command_team_course.py`。运行后会更新 `class/bootcamp/day-01` 至 `day-05` 的 README、day.yaml、lesson.md 和 practice.md。

本目录中的 `Week1_*.md` 是此前讨论形成的完整设计稿和领域基线，用于追溯课程决策。其中部分标题和节序仍属于 V3/V3.1 草案；如与平台课节冲突，以生成脚本和 `class/bootcamp/day-01..05` 为准。

当前已确认的教学原则：

- 学员是项目负责人，不是被动观看 AI 一次生成成品；
- 七岗位为项目经理、产品经理、UI/UX、前端、后端、测试、运维；
- 每个岗位完成后先自检并停在 REVIEW，学员明确批准后再交接；
- 第一至第四天以实操为主，第五天用学员自己的项目系统讲清开发过程；
- 统一骨架为驾驶舱、提交、列表、详情和 SQLite 数据链路；
- 第一周不做手机端、登录、Docker 和真实 AI；
- 详情页固定保留“AI 分析区｜Week2 接入”，样例必须标“演示数据”。
