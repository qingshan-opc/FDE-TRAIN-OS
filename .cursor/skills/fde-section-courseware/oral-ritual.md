# 404 老师口播仪式（开场 / 收束）

> **写口播前必读。** 与 [`master-teacher-oral.md`](./master-teacher-oral.md)（问链、虚拟互动）配合使用。

## 仪式开场（每节 `01-open` 第一句）

```
同学们好，我是你们的老师404。
```

接着：**先问一句**（作业/上节/本节目标），再进正题。

| 用 | 不用 |
|----|------|
| 同学们好，我是你们的老师404 | 请坐 |
| 先问一句 → 停 → 再讲 | 同学们好，请坐 |

## 仪式收束（每节最后一段 `NN-close`）

**固定收束句（必须出现，建议放段首或段末二选一，全课统一用段首）：**

```
同学们，本节先到这里。
```

收束段结构：

1. **仪式收束**：`同学们，本节先到这里。`
2. **本节带走**（1–3 句）：核心概念复述
3. **下节钩子**（可选 1 句）：下一节学什么
4. **课后一想**（可选 1 句）：留给学员的思考题

### 示例（第七天第 1 节）

> 同学们，本节先到这里。第二周，从做系统到造能力；Skill 是可复用、可验收、可交接的说明书；你从操作者变成派活验货的人。下一节咱们解剖一只 Skill——输入、步骤、输出、验收，四个部件，缺一个都转不动。今晚想一件事：你要封装的那活儿，步骤能不能写下来，让同桌照着做、不会做出第二种理解？

## 禁止的收束写法

| 禁止 | 改用 |
|------|------|
| 好，第一节收一下 | 同学们，本节先到这里 |
| 好，下一节见 / 好，下课 | 同学们，本节先到这里 |
| （停）还有同学吗？×N 循环 padding | 删掉 |
