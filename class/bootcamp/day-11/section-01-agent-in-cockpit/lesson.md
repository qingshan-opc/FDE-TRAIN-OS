# 第 1 节 · 实战：把 Agent 挂进驾驶舱 UI（30′）

> 本周你已通电：可聊 → Skill → Loop → 长任务/HITL。今天把事件流接到驾驶舱助手位，完成 V2.0 可答辩形态。
> 不要再说「助手位空了九天」——它一直在长。

## 教学目标

- 助手位：多轮聊天 + 任务执行 + 确认闸在页内；
- 事件可见：`turn_start` / `tool_call` / `confirm_required` / `done`；
- 对照 teaching 包 V2.0 清单自查。

## 接入三要件

```
① 唤起：页内发消息 → 后端 chat/loop
② 状态：工具调用与当前 turn 可见
③ 闸在页内：approve / reject 按钮写回 task_runner
```

## 流程（30′）

| 时段 | 内容 |
|------|------|
| 0–5′ | 三要件 + 演示脚本 |
| 5–25′ | 粘贴提示词接线 |
| 25–30′ | 对照 checklist 勾选 |

## 常见懵点

- 「要不要重写前端」→ 不要；在现有助手位上接 API；
- 「SSE 必须吗」→ 轮询也可，答辩能看状态即可。
