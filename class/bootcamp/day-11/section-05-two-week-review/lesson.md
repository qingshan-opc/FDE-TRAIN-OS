# 第 5 节 · 复盘与路线（15′ · 概念）

> 🎬 视频位：口播以 `video/scripts/narration/` 为准。课到这里结束——你们是入门，不是精通；接下来把 AI 当学习搭档。

## 教学目标

- 钉死入门边界：有后台、驾驶舱、能规划干活的智能体、关键步骤能审批——样子有了，不是全景精通；
- 接受「AI 领域一直在变」：课会更新，学习系统要自己上线；
- 带走两条继续学的路：盯前沿（官方/靠谱博主）+ 向 AI 许愿追问；`final-review.md` 写清已有 / 还缺 / 第一句许愿。

## 讲授要点（15′）

| 时段 | 内容 |
|------|------|
| 0–4′ | 收官：第二周能交什么；入门够什么、不够什么 |
| 4–8′ | 时代一直在变；两条路：盯前沿 + AI 当学习搭档 |
| 8–15′ | 操作系统许愿例子；问人 vs 问 AI；写三行许愿 |

### 入门边界（写进 final-review.md）

```
我已有：后台 / 驾驶舱 / 智能体 / 确认闸（有就勾，没有就写缺口）
我还缺：＿＿＿（具体到主题，不要写「继续学 AI」）
第一句许愿：我想学会＿＿＿（今晚就向 AI 发出第一问）
```

### 两条继续学的路

1. **盯前沿**：靠谱博主、官方账号、发布会纪要——盯「它解决什么问题」，一周扫一眼。
2. **学习搭档**：向 AI 许愿 → 它铺地图 → 你盯一条追问 → 动手 → 把报错贴回去再问。看不懂的地方，就是下一问。

### 许愿例子（操作系统，课上口述即可）

第一问：「如何做一个操作系统？」先拿地图（语言、引导加载器、内核、驱动、进程内存、文件系统、调试工具），再盯一条：「引导加载器是什么、最小能启动的一步怎么做？」——不要一上来背整本教材。

## 常见懵点

- 「十天就够了吗？」→ 够入门加一套真作品；不够精通和 AI 全景——课停了学习系统才上线；
- 「那我今晚学啥？」→ 写三行：已有 / 还缺 / 第一句许愿，并发出第一问；
- 「问人不是更快吗？」→ 问人沟通成本高、还可能藏着；问 AI 几秒给地图，但答案仍要你验收。
