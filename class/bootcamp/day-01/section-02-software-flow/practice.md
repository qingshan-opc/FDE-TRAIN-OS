# 第 2 节 · 练习

## 知识确认（3′）

1. 六岗位的正确顺序是什么？
2. 产品经理、UI、测试和运维分别交付什么文件或结果？
3. 为什么 AI 时代岗位没有消失，而是价值发生了上移？

## 实操任务（7′）

画一张六岗位接力图：

```text
产品经理 → UI → 前端 → 后端 → 测试 → 运维 → 产品经理最终验收
```

在每条箭头上补充交接物：

- 产品经理 → UI：______；
- UI → 前端：______；
- 前端 → 后端：______；
- 后端 → 测试：______；
- 测试 → 运维：______；
- 运维 → 产品经理：______。

再任选两个岗位，各写一句：传统岗位主要亲手完成什么；AI 时代更重视什么判断或责任。

## 完成标志

- 六岗位顺序正确；
- 六次交接均写出具体文件或结果；
- 至少完成两个岗位的“传统职能 vs AI 时代职能”对比；
- 能解释为什么最终还要回到产品经理验收。
