# 第 4 节 · 本地后端启动卡

## 启动

```text
python backend/server.py
```

若命令不存在，再试：

```text
py backend/server.py
```

## 检查顺序

1. 终端没有红色错误；
2. 打开 `http://127.0.0.1:8000/api/health`；
3. 查询接口返回 `200`；
4. 提交接口返回合同约定状态码；
5. 错误输入返回明确错误；
6. 重启后记录仍在。

## 停止

回到正在运行服务的终端，按 `Ctrl+C`。不要直接关闭整个 QRAE 项目。

## 常见故障

- 端口占用：停止旧服务后重启；
- 找不到 Python：确认安装及 `python --version`；
- 找不到文件：确认终端位于项目根目录；
- JSON 乱码或字段错：回到 `@后端` 对照合同修复。
