# 第 1 节 · 资源：接入参考

## 1. 三要件最小实现速查

| 要件 | 最小实现 | 不做什么 |
|------|---------|---------|
| 唤起 | 页面内对话区 ↔ Agent 运行环境 | 不做账号体系、不做多会话 |
| 状态 | 读 runs/ 最新日志行渲染 | 不做 WebSocket 推送（先手动刷新） |
| 闸在页内 | 草稿渲染 + 批准/驳回按钮写回 | 不做权限分级、不做多人会签 |

## 2. 降级方案（接不通真实 Agent 时）

```
指令面板模式：
  驾驶舱助手位展示「当前步骤 + 待执行指令」
  → 学员复制指令到本机 Agent / TRAE 执行
  → 执行结果（日志行/确认结果）回填助手位
信息回路：人 ⇄ 驾驶舱 ⇄ Agent，一样闭环
```

答辩话术：「我的助手位走的是指令面板模式——先保证信息回路闭环，实时连接是下一步。」这比「没接通」体面一百倍，而且是真的工程权衡。

## 3. 联调排障

| 症状 | 原因 | 修法 |
|------|------|------|
| 状态不更新 | 读的是旧日志文件 | 确认按日期取最新 runs/ 文件 |
| 按钮点了没反应 | 写回路径不通 | 先写本地 JSON/日志行验证回路，再接 Agent |
| 草稿渲染样式乱 | 直接插入 Markdown 原文 | 复用驾驶舱卡片样式，只渲染关键字段 |
| 助手位挤爆布局 | 把它当独立页面做了 | 它是第六个区块，遵守既有栅格 |
