# 第 1 节 · 实操任务

## 本节任务

要求前端工程师只搭工程结构和四个空页面，启动后由学员逐个访问。

**指挥对象**：@前端工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@前端工程师 Agent 请读已批准的需求和页面样稿，先把项目运行起来，只搭四个空白页面和公共导航。用大白话告诉我主要文件夹各放什么，带我逐页打开检查。等我批准后再做页面内容，不要一次全部做完。
```

## 学员验收清单

- [ ] 项目能启动
- [ ] 四个空路由可访问
- [ ] 能说出页面、组件和公共布局放在哪里
- [ ] README 记录启动方式

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
