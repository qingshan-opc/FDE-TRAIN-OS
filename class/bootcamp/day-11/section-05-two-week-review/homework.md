# 第 5 节 · 作业（毕业周作业）

## 今晚（课结束后立刻）

1. **写三行**：`docs/final-review.md` 里「已有 / 还缺 / 第一句许愿」；
2. **发出第一问**：把许愿问发给 AI，把回你的地图截一段贴进复盘；
3. **盯一条追问**：从地图里挑一个不懂的词，追问到能动手的最小一步。

## 本周内

1. 执行 final-review 里「本周内的第一个动作」，结果记进迭代日志；
2. 把驾驶舱任一个区块接到真实工作数据上——哪怕只是导出的表；
3. 给同事/朋友讲一遍你的驾驶舱（8 分钟结构照样好用），收集一个问题写进日志。

## 课程闭环（最后一次提交）

```bash
git add docs/final-review.md
git commit -m "docs: 两周复盘——入门边界与第一句许愿"
```

恭喜你。这门课没有空客套——只有一个可回放、可追责、可继续向 AI 许愿的 Git 仓库。
