# 第 1 节 · 实操任务

## 本节任务

让测试工程师生成用例，由学员抽查可执行性。

**指挥对象**：@测试工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@测试工程师 Agent 请根据已批准的需求，把“怎样算做对了”整理成一份可亲手执行的检查清单。每项只写我该做什么和应该看到什么，并覆盖正常、填错和没有数据的情况。先让我审核清单，不要替我执行或填写通过。
```

## 学员验收清单

- [ ] 至少十条并覆盖三类场景
- [ ] 每条有明确步骤和可判断预期
- [ ] 可追溯到 PRD
- [ ] 包含看板与列表核对

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
