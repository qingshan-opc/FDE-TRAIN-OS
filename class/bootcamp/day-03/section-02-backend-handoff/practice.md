# 第 2 节 · 练习

## 知识确认

1. `frontend-api-needs.md` 给后端什么信息？
2. 为什么澄清问题必须一次只问一个？
3. 谁可以回复“确认后端方案”？

## 本地实操

### P1 · 检查输入

> @后端，请读取 PRD.md、frontend-api-needs.md、frontend/index.html、frontend/app.js 和 frontend-acceptance.md。现在不要设计接口或写代码。缺少文件时只说明缺什么、应回到哪个岗位。

等待检查完成。

### P2 · 复述需求

> 文件齐全后，请分别复述核心业务规则、页面展示数据、用户提交内容、四种页面状态和仍待确认的问题。输出后停止。

### P3 · 逐题澄清

> 请一次只问 1 个问题，依次确认数据来源、核心数据对象、访问权限、隐私限制和本机是否有 Python 3。每题给一个回答示例，等我回答后再继续。

### P4 · 实施清单

> 请展示最小后端方案：Python 标准库 + SQLite；列出 3—5 个接口、2—3 个数据表、本地运行方式、健康检查、错误处理和明确不做项。现在不要创建文件，等我回复“确认后端方案”。

检查后由学员本人回复：`确认后端方案。`

## 提交验证

- 输入文件齐全；
- 复述与上游一致；
- 五类问题逐个完成；
- 方案不过度开发；
- 确认前没有后端代码。
