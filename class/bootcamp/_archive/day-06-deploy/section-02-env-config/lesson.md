# 第 2 节 · 概念：环境与配置分离（15′ · 概念）

> 🎬 视频位（现阶段：口播稿 + 讲解图）
> 「三不原则」第一条的落地工程：代码上公网，配置留家里。

## 教学目标

- 说清为什么配置（密钥/地址/开关）必须与代码分离；
- 掌握三件套的用法：`.env`（本地真值）/ `.env.example`（进 Git 的样板）/ 平台环境变量面板（线上真值）；
- 完成自己项目的环境分家改造。

## 讲授要点（15′）

| 时段 | 内容 |
|------|------|
| 0–5′ | 破题：同一份代码要在三个地方跑（你电脑/同桌电脑/云上），变的是配置不是代码 |
| 5–11′ | 三件套逐个讲 + 代码怎么读（os.environ） |
| 11–15′ | 动手：给自己项目做环境分家（practice） |

### 三件套（一次记牢）

| 文件/位置 | 装什么 | 进 Git 吗 |
|-----------|--------|-----------|
| `.env` | 本地的真实密钥与配置 | ❌ 必须在 `.gitignore` |
| `.env.example` | 样板：键名 + 假值 + 注释 | ✅ 进 Git，告诉别人要配什么 |
| 平台环境变量面板 | 线上的真实密钥与配置 | ❌ 存在平台，不是文件 |

### 代码侧（看懂即可）

```python
import os
GATEWAY_TOKEN = os.environ["GATEWAY_TOKEN"]   # 从环境读，代码里没有真值
```

判断标准一句话：**把仓库公开，项目还能安全运转吗？** 能，才算分家完成。

## 🎬 口播稿（约 1.5 分钟）

> 「想一个矛盾：代码要上 Git 公网仓库，密钥又不能见人——但它们现在在同一个文件里。怎么办？分家。
> 三件套记牢：`.env` 装本地真值，进 gitignore 永不提交；`.env.example` 装样板——键名加假值加注释，进 Git，别人 clone 下来照着配；线上真值放平台的环境变量面板，网页里配，不是文件。
> 代码只干一件事：os.environ 读环境变量。
> 验收标准一句话：把你的仓库现在公开，项目还安全吗？安全，分家才算完成。」

## 常见懵点

- 「.env 不进 Git，换电脑怎么办？」→ 新机器照着 `.env.example` 重新填一份——这正是 example 存在的意义；
- 「平台上改环境变量要重启吗？」→ 托管平台一般会自动重启或提供重启按钮；改完记得验证（第 5 节实测）；
- 「本地跑的时候 .env 怎么被读到？」→ AI 生成时加 `python-dotenv` 类的加载；Agent Lab 通常已处理——问一句即可。
