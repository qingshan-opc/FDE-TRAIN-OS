# Day 1 · 组建你的 AI 项目团队

> 今日目标：**从专业方向到 PRD 与可点击原型**
> 总时长 140′ · 5 节 · 前四天少讲概念、跟着岗位交接做；第五天再用自己的项目系统复盘。

## 这一天在解决什么

学员以项目负责人身份，在 TRAE 中组建七岗位 AI 软件团队，选择与自己专业或工作相关的业务问题，依次指挥项目经理、产品经理和 UI/UX 设计师，完成项目任务书、PRD 与四页可点击原型。

学员始终是项目负责人。Agent 负责岗位产出，学员负责提出任务、检查证据、纠偏和明确批准。任何岗位完成后必须停在 `REVIEW`；没有学员的 `APPROVED`，下一个岗位不得开工。
