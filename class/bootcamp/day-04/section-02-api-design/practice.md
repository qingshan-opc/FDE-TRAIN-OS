# 第 2 节 · 实操任务

## 本节任务

学员逐条执行，之后把自己的记录交给测试工程师整理。

**指挥对象**：学员亲测 → @测试工程师 Agent 整理

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@测试工程师 Agent 请带我亲手执行检查清单。一次只给我一个操作，等我告诉你实际看到什么，再记录通过或问题。没有执行的必须写“未检查”。发现问题时帮我用大白话写清怎样重现、正确结果和实际结果，但不要直接改程序。
```

## 学员验收清单

- [ ] 用例都有真实执行状态
- [ ] 缺陷与实际项目一致
- [ ] 重现步骤足够他人复现
- [ ] 学员至少复核一次严重度判断

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
