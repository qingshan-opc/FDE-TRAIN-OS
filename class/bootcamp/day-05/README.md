## 这一天在解决什么

前四天先做后懂，第五天把自己的真实项目摊开，系统讲清需求、原型、前端、接口、数据库、测试和交付如何连接；随后由运维和项目经理协助完成本地交付、README、路演和综合验收。

学员始终是项目负责人。Agent 负责岗位产出，学员负责提出任务、检查证据、纠偏和明确批准。任何岗位完成后必须停在 `REVIEW`；没有学员的 `APPROVED`，下一个岗位不得开工。
