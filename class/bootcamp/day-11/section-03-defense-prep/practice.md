# 第 3 节 · 练习：答辩提纲一页纸（随堂 12′）

## 提纲模板（填完即一页纸）

```markdown
# 答辩提纲 ·〈你的名字/项目名〉

## 第一段 · 作品演示（3′）
演示路径（点哪几步）：
1.
2.
3.
4.
5.
兜底：昨日成功日志截图在〈路径〉

## 第二段 · 架构讲解（3′）
指着全景图讲三块：
- 四层架构：
- 三 Skill 编排：
- 闸在哪、为什么在那：
主打证据（三强）：

## 第三段 · 迭代故事（2′）
选的 bug：
- 现象：
- 怎么定位：
- 修错了什么：
- 怎么修对：
- 学到什么：

## 诚实声明（如被问到弱项）
- 弱项 1：程度 + 差距 + 下一步
- 弱项 2：程度 + 差距 + 下一步
```

## 彩排（10–15′）

- 掐表走作品演示路径，记录用时：第 1 遍＿＿ 第 2 遍＿＿；
- 超 3′：砍掉一步（通常砍「驾驶舱全貌」的细讲，一句话带过）；
- 走完一遍「挂着预案」：故意关掉某个依赖，练指着日志讲。

## 一键粘贴提示词

> 整段复制给 Cursor / Claude Code / 平台 Agent / 任意 AI 搭档。尖括号 `〈〉` 换成你的路径或名称。

```text
帮我生成 docs/defense-outline.md：作品演示路径 3′ / 架构三点 3′ / 迭代故事五要素 2′ / 诚实声明（哪块降级/未完成）。
用我仓库里的真实路径，不要空话。
```

## 完成标志

- 提纲一页纸填满，关键词式；
- 作品段掐表 ≤3′，且练过兜底；
- 提纲进 Git。
