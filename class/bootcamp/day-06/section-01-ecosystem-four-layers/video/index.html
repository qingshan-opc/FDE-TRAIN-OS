05ACCESS · 开源 vs 闭源

调 API，还是自己部署

别被"开源/闭源"绕进去——真正的区别是：调别人 API，还是把模型下载到自己机器上跑。

自部署：自己买机器 · 自己运维 · Unsplash
本课走这条

调 API

GPT、Claude、DeepSeek-API——按 Token 付钱，省心。开源也能调 API，咱们就是 DeepSeek API 接进来的。

另一条路

自部署权重

Qwen、DeepSeek 权重能下载——省钱、数据不出门，但机器和运维自己扛。
