# 第 1 节 · 实战：Agent 接入驾驶舱（30′ · 实战）

> 🎬 视频位（现阶段：口播稿 + 讲解图）
> 驾驶舱右边那个「AI 助手」位空了九天了。今天让它活过来——这是 V2.0 的最后一块拼图。

## 教学目标

- 把 Agent 接入驾驶舱的 AI 助手区块：可唤起、可看流水线状态、确认闸在页面内可操作；
- 理解接入设计的原则：**助手位是「人-Agent 对话口」，不是装饰**；
- 完成后对照 V2.0 全景图自查：六个区块 + Agent + 三 Skill，一个不缺。

## 接入三要件（0–5′ 讲解）

```
① 唤起：助手位能发消息给 Agent，Agent 能回话
   （最小实现：页面内嵌对话区，接通你的 Agent 运行环境）
② 状态：流水线跑到哪一步，助手位实时可见
   （最小实现：读取 runs/ 最新日志行，显示「当前步骤 + 状态」）
③ 闸在页内：确认界面出现在驾驶舱里，批准/驳回按钮直接点
   （最小实现：B 的草稿渲染进助手位，两个按钮写回确认结果）
```

原则：**驾驶舱是「驾驶」的地方**——状态看得见、刹车踩得到，才叫接入；只挂个聊天框叫摆设。

## 常见懵点

- 「时间不够三件都做怎么办？」→ 优先级：闸 > 状态 > 唤起。宁可只做一个能点「批准/驳回」的真闸，不要三个半成品；
- 「对话区接不通真实 Agent 环境？」→ 降级方案：助手位内嵌「运行指令面板」——展示当前步骤 + 确认按钮，指令复制到 Agent Lab 执行，结果回填——思想不变，打通的是「人-Agent-驾驶舱」的信息回路；
- 「样式和前面区块不统一？」→ 直接复用驾驶舱既有卡片样式，助手位不该长得像外来的。
