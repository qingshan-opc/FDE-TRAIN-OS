# 第 4 节 · 答辩与互评（30′ · 验收）

> 🎬 视频位（现阶段：口播稿）
> 上台。讲得清、拦得住、查得了、迭代真——四个维度，就是你的毕业成绩单。

## 验收流程（30′）

| 时段 | 内容 |
|------|------|
| 0–3′ | 规则宣布：8′/人 + 互评表用法 |
| 3–27′ | 答辩轮转（人数多时分组并行，导师抽签听 2–3 人全程） |
| 27–30′ | 互评表回收 + GATE 10 当场宣布 |

## 答辩规则

- 每人 8 分钟：作品 3′ + 架构 3′ + 迭代故事 2′，响铃即停；
- 演示挂了：启用兜底预案（指着昨日成功日志讲）——**处理事故的方式也计分**；
- 问答穿插在互评环节：听的同学至少提 1 个真问题。

## 互评表（听每人必填）

| 维度 | 1–5 分 | 你印象最深的一个细节 |
|------|--------|---------------------|
| 讲得清（听懂做了什么、为什么） | | |
| 拦得住（确认闸是真实演示） | | |
| 查得了（日志/证据随手能打开） | | |
| 迭代真（bug 故事经得起追问） | | |

规则：打分必须配「一个细节」——写不出细节的分不算数。

## GATE 10（毕业验收）

- 答辩完成 + 互评表收回 ≥2 份；
- 导师复核：十条证据抽查 3 条、闸口演示真实；
- 通过后：授予 **FDE（Forward Deployed Engineer，AI 时代全栈交付工程师）** 称号——课程介绍页上写的那个人，今天是你。

## 🎬 口播稿（约 4 段 · 待审）

> 同学们，上台了。每人八分钟，作品三加架构三加故事二，响铃就停。规则简单：讲得清、拦得住、查得了、迭代真——四个维度，就是你的毕业成绩单。第一个上的别紧张，评委还没建立比较基准呢，对吧。
> 听的人别走神，互评表每个分都要配一个细节——写不出细节，说明你也没听懂，分也不算数。讲得清是听懂做了什么、为什么；拦得住是确认闸真实演示；查得了是日志证据随手能打开；迭代真是 bug 故事经得起追问，对吧。
> 演示挂了不扣分，慌了才扣分——指着昨日成功日志讲，那就是你的第九条证据。被问倒了？这个我现在不会，我的打算是……三件套回答永远安全。互评按细节说话，分低但写得准是帮人，闭眼打高分是害人，咱们都懂。
> GATE 10：答辩完成、互评收回至少两份、导师抽查十条证据三条、闸口演示真实。过了这关，授予 FDE 称号——课程介绍页上写的那个人，今天是你。带走一句：上台不是表演完美，是展示你会交付，对吧。


## 常见懵点

- 「我第一个上，紧张」→ 第一个上的优势：评委还没建立比较基准，且迭代故事段人人爱听真 bug；
- 「被问倒了怎么办？」→ 「这个我现在不会，我的打算是……」——三件套回答永远安全；
- 「互评要给别人打低分吗？」→ 按细节说话：分低但细节写得准，是帮人；闭眼打高分，是害人。
