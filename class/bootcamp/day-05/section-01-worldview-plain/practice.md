# 第 1 节 · 实操任务

## 本节任务

用自己项目的文件路径重画一遍完整研发流程。

**指挥对象**：@项目经理 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@项目经理 Agent 请带我回放这五天产品是怎样一步步做出来的。一次只回顾一个阶段，先问我“谁接了谁的工作、我怎样检查”，再补充我漏掉的地方。最后按真实发生顺序整理成全过程图，没发生的不能写成完成。
```

## 学员验收清单

- [ ] 流程包含完整岗位交接
- [ ] 每步能指向真实文件
- [ ] 区分原型、Mock、真实接口和已发布状态
- [ ] 能解释至少一次学员纠偏如何影响后续

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
