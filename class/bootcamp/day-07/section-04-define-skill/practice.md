# 第 4 节 · 练习：说明书写作冲刺（随堂 25′）

## 任务

按倒序写你的 Skill 说明书（存为 `skills/<名称>.md`）：

| 时段 | 写哪段 | 自查 |
|------|--------|------|
| 5′ | 输出 | 格式/长度/红线齐？有好示例吗？ |
| 5′ | 验收 | ≥3 条可判？结构/数字/意图各一？ |
| 5′ | 输入 | 来源具体到接口/文件？范围明确？ |
| 10′ | 步骤 | 每步是动作动词？换人无歧义？ |

## 换人测试（7′）

同桌只看说明书，回答三问：
1. 这个 Skill 做什么（输入→输出）？
2. 第一步先干什么？
3. 做完了怎么判好坏？

答错/答不上 → 你改说明书（不怪读者）→ 重问，直到三问全对。

## 一键粘贴提示词

> 整段复制给 Cursor / Claude Code / 平台 Agent / 任意 AI 搭档。尖括号 `〈〉` 换成你的路径或名称。

```text
你现在是 Skill 说明书写作搭档。目标文件：skills/〈名称〉.md。
倒序协助我写：输出 → 验收(≥3 可判) → 输入(来源具体) → 步骤(动词、换人无歧义)。
每写完一段先自检，再写下一段。禁止出现「适当/合理/等等」类模糊词。
写完后生成「换人三问」答案键，方便同桌测验。
```

## 过关标准

- 四部件齐全，无 🚫 模糊词；
- 换人测试三问全对；
- `skills/<名称>.md` 进 Git。
