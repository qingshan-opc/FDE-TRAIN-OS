# 第 2 节 · UI 到前端交接卡

## 输入文件

- `PRD.md`：需求与验收标准；
- `design-spec.md`：视觉和组件规范；
- `ui-flow.md`：页面操作路径；
- `ui-prototype.html`：可观察原型。

## 五句复述模板

1. 用户是 ______；
2. 第一版包含 ______；
3. 最重要操作是 ______；
4. 页面必须处理 ______ 状态；
5. 通过标准是 ______。

## 等待点

```text
检查文件 → 等待
五句复述 → 等待
实施清单 → 等待“确认开发”
```
