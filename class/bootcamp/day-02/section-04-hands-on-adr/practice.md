# 第 4 节 · 实操任务

## 本节任务

先让前端完成详情页，再让后端工程师根据 PRD 和前端代码起草契约，由学员批准。

**指挥对象**：@前端工程师 Agent → @后端工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@前端工程师 Agent 请做好详情页，让它显示我在列表中选中的那条记录。AI 区先写“AI 分析区｜第二周接入”和“演示数据”，再放按钮。完成后带我检查；我批准后，请只给我一句交给后端工程师的数据约定任务，不要替他执行。
```

## 学员验收清单

- [ ] 详情字段与 PRD 一致
- [ ] AI 区状态和演示数据标识清楚
- [ ] 五个接口齐全
- [ ] 请求响应字段与页面和 PRD 能对上
- [ ] 学员批准契约后才允许第三天后端开工

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
