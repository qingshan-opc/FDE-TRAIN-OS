# 第 1 节 · 概念：部署是什么 + 管线五步（15′ · 概念）

> 🎬 视频位（现阶段：口播稿 + 讲解图）
> 快答开场（昨晚自查）：代码、数据库、密钥——哪三样不能上公网？对完答案进入正题。

## 教学目标

- 一句话说清部署：把你的应用从「我电脑上的进程」变成「互联网上谁都能访问的服务」；
- 看懂部署管线五步：代码 → 构建 → 镜像 → 运行 → 访问；
- 建立上线前安全直觉：什么能上公网、什么绝不能。

## 讲授要点（15′）

| 时段 | 内容 |
|------|------|

| 4–10′ | 管线五步逐讲 + 每步的「出问题长什么样」 |
| 10–15′ | 安全三不原则 + 今天的主路径（托管平台一键部署） |

### 管线五步（看懂每一步在干嘛）

```
① 代码    Git 仓库是唯一事实源——没进 Git 的东西不存在
② 构建    装依赖、打包——「在我机器上能跑」从这里开始消失
③ 镜像    把应用+环境冻成一个标准包裹（第 3 节细讲）
④ 运行    云上的机器启动这个包裹，7×24 不关机
⑤ 访问    一个公网 URL，谁的浏览器都能打开
```

### 安全三不原则（上线前默背）

1. **密钥/令牌不进 Git、不进镜像**——从环境变量读（第 2 节落地）；
2. **含真实业务数据的库文件不上公网**——本课全是模拟数据，真实项目要三思；
3. **调试模式不上线**——报错详情给黑客看等于送地图。

## 🎬 口播稿（约 1.5 分钟）

> 「先对答案：密钥、含真实数据的库、调试模式——三样不能上公网。
> 部署是什么？一句话：把你的应用从『我电脑上的一个进程』变成『互联网上谁都能访问的服务』。localhost 有两个局限：只有你能看，关机就没。
> 管线五步：代码——Git 是唯一事实源；构建——装依赖打包；镜像——把应用连环境冻成标准包裹；运行——云上的机器 7×24 跑它；访问——一个公网 URL。
> 今天我们不手工操作这五步——托管平台帮你跑管线。但你要看得懂每一步：线上出问题时，知道该往哪步查。」

## 常见懵点

- 「我自己买服务器部署行不行？」→ 行，但那是公开课 O3 的内容；今天用托管平台——约束驱动：最快出可验收结果；
- 「部署和发布是一个意思吗？」→ 部署 = 放到云上跑起来；发布 = 让用户知道并使用。今天只做部署，发布是你的下一步；
- 「数据库也上云吗？」→ SQLite 文件随应用走（它的甜区！）；第 4 节测试清单会验证线上数据正常。

> 拓展（非必修）：CI/CD、蓝绿部署、回滚 → 公开课 O3 部署篇。
