# 服务器命令手册（Day 5 随堂版）

> 手册是查的，不是背的。先在[交互仿真](/course-assets/resources/h5/server-cli-lab.html)里敲出肌肉记忆，用到别的再来查。

## 日常八句（先掌握这些）

| 命令 | 干什么 | 什么时候用 |
|------|--------|-----------|
| `pwd` | 显示当前目录（我在哪） | 刚连上服务器，先定位 |
| `ls` / `ls -l` | 列出文件 / 带详细信息 | 看部署的文件在不在 |
| `cd 目录` | 进入目录（`cd ..` 退一层） | 去应用目录干活 |
| `mkdir -p 路径` | 建文件夹（父目录一起建） | 给日志、数据安家 |
| `curl 地址` | 敲服务的门，看应不应 | 验证服务活着没（200 = 活着） |
| `tail -f 文件` | 实时盯着文件末尾看 | 出问题时第一动作（`Ctrl+C` 退出） |
| `chmod +x 文件` | 给文件「能执行」权限 | 报 permission denied 时 |
| `docker ps` | 看正在跑的容器 | 检查「集装箱」状态（`-a` 看全部） |

## 第二梯队（用到再查）

| 命令 | 干什么 |
|------|--------|
| `cat 文件` | 看完整个小文件 |
| `echo "文字" > 文件` | 写一行进文件（`>>` 追加） |
| `cp 源 目标` | 复制（`-r` 复制文件夹） |
| `mv 源 目标` | 移动 / 改名 |
| `rm 文件` | 删除（**没有回收站，想清楚再敲**） |
| `grep 关键词 文件` | 在文件里搜内容 |
| `top` / `htop` | 看谁在吃 CPU 和内存（`q` 退出） |
| `df -h` | 看磁盘还剩多少 |
| `ps aux \| grep 名字` | 找某个进程 |
| `systemctl status 服务名` | 看系统服务状态（`start/stop/restart`） |
| `ssh 用户@地址` | 连上另一台服务器 |
| `scp 文件 用户@地址:路径` | 把文件送上服务器 |

## 新人三坑

1. **大小写敏感**：`Logs` ≠ `logs`，敲错就是找不到。
2. **空格是分隔符**：路径带空格要加引号 `"my folder"`。
3. **`rm` 没有后悔药**：删除前用 `ls` 确认一眼目标。

## 排障四步（顺序别乱）

1. `curl localhost:端口/healthz` —— 服务活着吗？
2. `tail -f 日志` —— 它在说什么？
3. `docker ps` / `systemctl status` —— 容器或服务在跑吗？
4. `df -h` / `top` —— 是不是资源满了？
