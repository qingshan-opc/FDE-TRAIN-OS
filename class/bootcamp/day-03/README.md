# Day 3 · AI 时代的前端

> 结构依据：`docs/spec/0.4/curriculum-v0.7.md`（角色周：PM → 架构师 → 前端 → 后端 → 全栈理论）
> 今日目标：**用 UI/UX + Web 前端两份角色提示词，为「部门周报助手」生成高保真单页原型 index.html，并学会用设计规范验收还原度**
> 总时长 100′ · 5 节 · 概念 50′，实战 35′，验收 15′

## 这一天在解决什么

Day 1 你定了方向（PRD.md），Day 2 你定了骨架（architecture.md）。今天做脸——用户第一眼看到、每天都在摸的那张脸。

但「做脸」在 AI 时代的含义变了：页面不再是工程师一行行 CSS 调出来的，而是 AI 按你给的规范一次性生成的。你的价值不在「会不会写页面」，而在「能不能说清什么叫好看、什么叫对，并验收出来」。

所以今天的学习路径是：先看懂前端这个角色在 AI 时代变成了什么（第 1 节）；再学会给 AI 下「量化」的美学指令——设计规范四件套（第 2 节）；然后解剖两份前端提示词，理解「UI 先行、API 在后」的协作顺序（第 3 节）；最后亲手跑两轮「生成 → 对照规范验收 → 改约束重生成」，拿到你的 index.html（第 4–5 节）。

明天 Day 4 的后端会给这张脸接上心脏——所以今天的原型必须是「能接数据」的真界面，不是贴图。
