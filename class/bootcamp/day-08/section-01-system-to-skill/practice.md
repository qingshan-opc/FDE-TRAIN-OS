## 任务

对昨晚作业的三件重复事，各过一遍「值不值得」快判：

| 事项 | 频率够吗（≥每周） | 步骤稳定吗 | 需要人拍板吗 | 结论：封/不封/拆 |
|------|------------------|-----------|-------------|-----------------|
| 1. ____ | | | | |
| 2. ____ | | | | |
| 3. ____ | | | | |

「拆」= 部分可封装（如「做决定」不行，但「准备决定所需材料」行）。

## 快答（同桌互考）

- Skill 和 Prompt 的区别，一句话；
