# 设计规范模板 · Design Spec Template（Day 3 配套）

> 用法：复制本模板，把「<尖括号>」换成你的数值，存为 `design-spec.md`，
> 与设计规范一起粘进 AI 工具（搭配 UIUX_Designer_Agent_Prompt.md 使用）。
> 原则：只写可验收的数值，不写「好看」「大气」这类感觉词。

## 1. 颜色

| 角色 | 色值 | 用在哪 |
|------|------|--------|
| 主色 | <如 #2563EB> | 主按钮、链接、选中态 |
| 辅助色 | <如 #F59E0B> | 次要强调、标签 |
| 警示色 | <如 #DC2626> | 错误提示、危险操作 |
| 正文文字 | <如 #1F2937> | 正文 |
| 辅助文字 | <如 #6B7280> | 说明、次要信息 |
| 页面背景 | <如 #FFFFFF 或 #0B1220（暗黑）> | 全局背景 |

## 2. 字号层级

| 层级 | 字号 | 字重 | 用在哪 |
|------|------|------|--------|
| 大标题 | <如 40px> | <如 700> | hero 区主标题 |
| 区块标题 | <如 24px> | <如 600> | 每个功能区块标题 |
| 正文 | <如 16px> | <如 400> | 段落、说明 |
| 辅助说明 | <如 13px> | <如 400> | 页脚、注释 |

## 3. 间距体系

- 基准数：<如 8px>，所有间距只用它的倍数；
- 区块之间：<如 96px>；
- 标题与正文之间：<如 16px>；
- 卡片内边距：<如 24px>。

## 4. 圆角与阴影

- 卡片圆角：<如 12px>；按钮圆角：<如 8px>；
- 卡片阴影：<如 0 4px 16px rgba(0,0,0,0.08)>；
- 全站圆角与阴影各只用一挡，不得混用。

## 5. 交互三态（主按钮）

| 状态 | 表现 |
|------|------|
| 默认 | 主色背景，白字 |
| 悬停 hover | 背景加深 10%，鼠标变手型 |
| 禁用 disabled | 背景变灰（如 #9CA3AF），不可点击，无悬停效果 |

## 6. 两条军规（照抄进提示词）

- 所有文案必须是面向真实用户的中文成品文案，严禁占位符（lorem ipsum / 「示例文字」/ 灰块图）；
- 所有可点击元素必须具备 hover 与 disabled 两态样式。
