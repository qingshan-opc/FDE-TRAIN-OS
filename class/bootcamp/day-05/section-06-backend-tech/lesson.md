## 讲授要点

### 复习一句话：后端在干什么

Day 4 讲过，后端三件事：**业务逻辑**（规则）、**数据**（存和取）、**接口**（和前端对话）。你在浏览器里看不见后端——像餐厅看不见后厨，但每道菜都从那里出来。

### 数据库是什么：给数据一个「住所」

数据库首先是一种**存储媒介**。存储方式很多；做系统时，Excel 里那种结构化数据，不能永远散落在本地文件里——得有个固定住所，这个住所就是数据库。

不同类型的数据，住不同的「房」：

| 类型 | 像什么 | 常见代表 |
|------|--------|----------|
| 关系型 / 结构化 | Excel 表进系统后的正规住所 | PostgreSQL、MySQL |
| 缓存 / 会话 | 临时快取、访问要极快 | Redis |
| 搜索 | 按关键词捞文档 | Elasticsearch |
| 分析报表 | 海量数据秒级聚合 | ClickHouse |
| 图 / 时序等 | 关系网、传感器时间序列 | 图数据库、时序库…… |

一句话：**企业里遇到什么形态的数据，就给它配什么住所。** 知道分类比背一个「正确答案」重要——**具体选哪一家，留到作业里写理由**。

### 权限：谁能动数据

- **账号与角色**：谁能读、谁能写、谁能改表结构——最小权限，默认拒绝；
- **密钥不进代码**：API Key、数据库密码从环境变量或密钥服务读——进 Git 等于送给全世界；
- **审计**：谁什么时候改了什么——企业系统常见要求，原型阶段也要有这个意识。

### 主库与加配（认识名字）

常规业务主库常见：**PostgreSQL、MySQL**；原型常见 **SQLite**（一个文件一个库）。

加配举例：**Redis**（缓存/会话）、**Elasticsearch**（搜索）、**ClickHouse**（分析）、**MongoDB**（文档）等——地图上有名即可，**课里不替你点单**。

### 程序怎么跟库说话：DDL / DQL（以及 DML）

跟关系型数据库打交道，有一套标准语言（SQL 家族），名字别被吓到：

- **DDL**（Data Definition Language）：建表、改表结构——「房子怎么隔间」；
- **DQL**（Data Query Language）：查询——「把符合条件的数据捞出来」；
- **DML**（Data Manipulation Language）：增删改——「往房子里放、拿、改东西」。

程序启用数据，主要靠这套语言。别的库不一定叫 SQL，但往往会有自己的 API 或函数——本质一样：约定好怎么存、怎么取。

### 加配：Redis、搜索库、报表库

标准软件几乎都有一个主库；按需再加专科医生：

- **要用户会话 / 临时状态更快**→ 加 **Redis**。会话体验可以做到接近无感。早期有人把 session 直接塞进 MySQL——单体小流量也许行；人一多就慢、就扛不住。**开放给更多人用时，别把会话长期压在主库上。**
- **要按关键词搜文档**→ **Elasticsearch** 一类搜索库：文档检索，靠语法或 API 调用。
- **要经营分析 / 报表驾驶舱**→ **ClickHouse** 一类分析库：了解「有这么个东西、算报表找它」即可。

### 四条语言线：各自干什么（事实描述）

| 语言 | 常见干什么 | 常见框架（认识名字） |
|------|-----------|---------------------|
| **Python** | AI/数据脚本、API 服务 | Django、Flask、**FastAPI** |
| **Java** | 大型企业核心系统 | **Spring Boot**、Spring Cloud |
| **Go** | 网关、中间件、云基础设施 | Gin、Echo、Fiber |
| **Rust** | 极致性能、系统底层 | Actix、Axum |

还有 **Node.js**（Express、NestJS）等——地图要宽，但**口播和讲义禁止「建议你们选 X」**。

### 作业：你自己交选型理由

课后作业（或 theory-map 后端主题）要求写：

1. 你**打算**用什么语言 + 框架 + 主库（可以变，但要写当前判断）；
2. **为什么**——必须引用你的 PRD、API_Spec、团队约束，不许抄课件推荐句。

### 契约先行：语言是后面的事

接上 Day 4：先把接口契约（API_Spec.md）写清楚——路径、参数、返回、错误码。这份契约用 Java 实现也行，用 Python 实现也行，前端不在乎。**契约是合同，语言只是施工队**——先签合同，施工队可以后挑。

## 常见懵点（导师备用）

- 「PHP、Ruby 怎么不讲？」→ 还在服役，但新项目默认候选里靠后——地图只画主干；
- 「老师是不是在说 Java 没落了？」→ 不是判死刑：AI 让「写得快」的语言更抢镜，但十年级企业系统、招人与规范，Java + Spring Boot 仍然硬。按三句话决策，不要按口味决策；
- 「选错语言很致命吗？」→ 对多数业务系统，不如选错数据库、选错架构致命。真纠结就先跑起来；
- 「PostgreSQL 还是 MySQL？」→ 地图里两个都常见——**作业写你的约束**，课里不给默认答案；
- 「DDL/DQL 一定要背吗？」→ 先建立「改结构 / 查数据 / 改数据」三类动作即可，语法 Day 4 已摸过，今天记地图。
