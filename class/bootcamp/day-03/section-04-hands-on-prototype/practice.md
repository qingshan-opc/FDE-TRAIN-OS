# 第 4 节 · 实操任务

## 本节任务

实现诚实的占位接口，并检查详情页展示边界。

**指挥对象**：@后端工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@后端工程师 Agent 请为第二周的 AI 分析留好入口，但本周不要接入真实 AI，也不能用固定文案冒充结果。先用大白话告诉我第二周要读取什么、返回什么、由谁确认；确认后写成交接说明，并证明当前入口会诚实提示“第二周接入”。
```

## 学员验收清单

- [ ] 预留接口不调用模型
- [ ] 返回明确未接入状态
- [ ] 页面样例仍标演示数据
- [ ] 交接文档写清输入输出与人工确认

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
