# 第 3 节 · 前端三件套速查

```text
HTML = 结构 = 页面有什么
CSS = 样式 = 页面长什么样
JavaScript = 行为 = 操作后发生什么
```

## 四状态速查

- `loading`：正在加载；
- `empty`：没有数据；
- `success`：成功显示；
- `error`：失败并允许重试。

## 控制台

Chrome 或 Edge 中按 `F12`，选择“控制台 / Console”。本课程只要求：

- 会打开；
- 会判断有没有红色错误；
- 会把错误现象交给 `@前端`。

## 安全提醒

不要在前端文件中写入真实密码、API 密钥、身份证号、手机号或公司敏感数据。
