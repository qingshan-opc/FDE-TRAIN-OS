## 讲授要点

### 第一关：快测 21 题

- 范围：今天内容——世界观、**五阶段**、开发流程、服务器与云原生与部署、命令行、前端地图、后端地图；
- 规则：答对 14 题过线；不过线当晚补学对应小节，明天开课前补测；
- 提醒：所有题考「理解」不考「背诵」——如果你哪道题只能靠背，说明那一节还没真懂，回去看讲解图。

### 第二关：理论地图过闸

第一周的毕业作品不是代码，是一张你自己的地图——证明五天的东西在你脑子里连成了网。

规格（theory-map.md）：
1. **七大主题**，每个 3 条要点：
   - 世界观（浪潮重排谁值钱）
   - **企业数字化五阶段**（信息化→…→Agent 化，与驾驶舱/Week2 的落点）
   - 开发流程（调研 → 原型 → 开发 → 验收 → 上线 → 迭代）
   - 服务器与云原生与部署（五站演进 + 管线五步 + 环境分离）
   - 命令行（日常八句 + 亲手敲过才算过）
   - 前端地图（三件套 + 框架名单 + 四问）
   - 后端地图（数据库分类 + 权限 + 四语言框架名单 + **你自己的选型理由**）
2. **每条要点配一个实例**：必须来自你前四天的真实交付物（PRD.md / architecture.md / index.html / API_Spec.md / DB_Schema.md）或一句你自己的类比——不许抄课件；
3. 写完自己当验收官：随便指一条，能不能 30 秒讲给同桌听？讲不顺的，改到讲顺为止。

### 过闸还须：命令行仿真 8 任务全勾

不许复制粘贴——敲一遍顶看十遍。

## 常见懵点（导师备用）

- 「快测和理论地图哪个更重要？」→ 地图。快测防「没学」，地图防「没连起来」——后者才是这一周真正的交付；
- 「实例一定要代码吗？」→ 不要。一句自己的类比也行——要的是「你的」，不是「高级的」。
