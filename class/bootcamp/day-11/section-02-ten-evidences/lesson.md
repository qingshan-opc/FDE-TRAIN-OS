# 第 2 节 · 端到端十条能力证据（20′ · 实战）

> 🎬 视频位（现阶段：口播稿）
> 答辩不是讲情怀，是拿证据。十天学了什么，用十件拿得出手的东西回答。

## 教学目标

- 对照十条能力证据逐条自证：每条必须有文件、运行记录或现场演示支撑；
- 找到自己的三条最强项（答辩主打）和两条最弱项（今晚补或诚实标注）；
- 理解「证据思维」：能力不是说出来的，是拿出来的——这是 FDE 的出厂设置。

## 流程安排（20′）

| 时段 | 内容 |
|------|------|
| 0–3′ | 证据思维破题：十条 = 十天 = 一张能力地图 |
| 3–15′ | 逐条自证：每条 1 分钟——打开证据 ✓ / 没有 ✗ / 太弱 △ |
| 15–20′ | 标三强两弱 + 补救计划（今晚能补的补，补不了的写进答辩诚实声明） |

## 🎬 口播稿（约 5 段 · 待审）

> 同学们，答辩不是讲情怀，是拿证据。十天学了什么，用十件拿得出手的东西回答——方向卡、契约文档、Skill 三件、编排日志、Git 迭代史，每条都得有文件或运行记录撑腰，对吧。
> 现在逐条过十条清单。打开文件、点开运行记录——拿得出来打勾，拿不出来打叉，太弱打三角。每条大概一分钟，别讲故事，先证明这东西在、能打开、能说明我会什么。能力不是说出来的，是拿出来的，对吧。
> 打完别慌，没人十项全能。圈出你最强的三条，那是答辩主打；最弱的两条，今晚能补就补，补不了就写进诚实声明。六七条打叉不丢人，自证诚实比假装全会强，咱们 FDE 出厂设置就是证据思维，对吧。
> 证据在但讲不出来？每条配一句话：这是什么 + 它证明我会什么。比如 orchestration.md 证明你会编排与安全，runs/ 日志证明闸口可回放。现在就写，别拖到上台临场编——评委问的就是这条线，对吧。
> 别人的证据比你多？答辩不评比谁多，比谁讲得清自己有什么。知道哪里弱，本身就是第十一条证据。下一节咱们按 3+3+2 结构写提纲，把三条强项和一条修了三遍的 bug 故事排进八分钟，对吧。


## 常见懵点

- 「我有六七条打叉，是不是完了？」→ 叉多说明自证做得诚实；今晚优先级：补「答辩要讲的那几条」；
- 「证据在但讲不出来怎么办？」→ 每条证据配一句话：「这是什么 + 它证明我会什么」——现在就写；
- 「别人的证据比我多？」→ 答辩不评比谁多，比谁讲得清自己有什么。
