# 第 3 节 · 实操任务

## 本节任务

让项目经理从你的专业、工作或兴趣出发，先陪你完成选题，再生成五天任务书。

**指挥对象**：@项目经理 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@项目经理 Agent 请从我的专业、工作或兴趣出发，带我选一个五天能完成的企业小项目。一次只问一个问题；选定后先整理选题确认单，再把五天目标、团队分工和不做的事问清楚，写成项目任务书。最后用大白话带我检查，等我批准。
```

## 学员验收清单

- [ ] 项目经理一次只问一个问题，先完成选题确认单
- [ ] 任务书包含五天里程碑和七岗位分工
- [ ] 明确四页面、SQLite 和 Week2 AI 边界
- [ ] 状态为 REVIEW，学员通读后才决定是否 APPROVED

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
