# 第 6 节 · 验收：V1.0 + Week 1 复盘（15′ · 验收）

> 🎬 视频位（现阶段：口播稿）
> GATE 6 之后，Week 1 收官。复盘不是感想会，是把六天的经验整理成「下次能直接用的资产」。

## 教学目标

- 通过 GATE 6（V1.0 验收）：线上证据 + 清单 + 安全检查；
- 完成结构化 Week 1 复盘：能力地图自评 + 最大坑 + Week 2 预览；
- 理解 Week 1 → Week 2 的换档：从「做产品」到「做同事」。

## 流程安排（15′）

| 时段 | 内容 |
|------|------|
| 0–6′ | V1.0 验收：线上 URL + 清单 + 安全复核 |
| 6–13′ | 复盘写作：三段式（能力地图/最大坑/朋友的观后感） |
| 13–15′ | Week 2 换档预告 |

## 复盘三段式（写进 `docs/week1-review.md`）

**① 能力地图自评**（✓ 能做到 / △ 做过但虚 / ✗ 还没碰）：

```
□ 约束驱动选型（前端/数据库/模型各做过一次）
□ 信息架构：区块回答业务问题
□ 接口契约设计与验货
□ SQL 四板斧（读 + 指挥 AI）
□ Prompt 四要素 + 结构化输出
□ LLM 运维三角（密钥/超时/降级）
□ AI 输出验收（三条军规 + 用例）
□ 部署管线 + 环境分家
```

**② 最大的坑**：六天里卡你最久的那次——当时怎么想的、最后怎么过的、下次怎么避免。

**③ 朋友的观后感**：昨晚非技术朋友的那句话——它揭示了你产品的什么问题？

## Week 2 换档预告

```
Week 1（M2-M3）：你做产品——驾驶舱 V1.0，四层全通，已上线
Week 2（M4-M5）：你做同事——
  Day 7  把重复工作封装成 Skill（AI 的技能包）
  Day 8  工程化 + Harness/Agent 概念
  Day 9  多 Skill 编排：确认点与日志
  Day 10 V2.0 答辩 + 行业地图 + 你的自学路线
```

## 🎬 口播稿（约 1 分钟）

> 「六天前你不会写 Prompt，今天你有一个公网可访问的、四层全通的、会说人话的驾驶舱。这不是魔法，是每天一层、每天一验收堆出来的。
> 复盘三段：能力地图——哪些 ✓ 哪些 △；最大的坑——下次怎么避免；朋友那句话——产品最真实的镜子。
> 下周换档：Week 1 你做了一个产品，Week 2 你要做一个『同事』——把你的工作方式封装成 AI 能执行的 Skill。今天好好休息，明天见。」

## 常见懵点

- 「△ 比 ✓ 多，是不是落后了？」→ 正常：△ 意味着「见过、做过、不熟练」——Week 2 每天都在复用它们，做着做着就 ✓ 了；
- 「复盘要写多长？」→ 三段各 3–5 句；写不出来的那项，才是你真正的收获清单。
