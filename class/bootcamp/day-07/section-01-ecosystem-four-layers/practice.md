## 实操任务（15′）· SSE 最小接电

目标：在驾驶舱（或独立小页）里跑通 **DeepSeek + SSE 流式输出**——字一个个出来，而不是干等整包。

## 一键粘贴提示词

> 整段复制给 Cursor / Claude Code / 平台 Agent / 任意 AI 搭档。尖括号 `〈〉` 换成你的路径或名称。密钥用环境变量或教务网关，**禁止写入前端仓库**。

```text
我需要接入 DeepSeek-flash（若文档型号名不同，以教务/官方当前 flash 型号为准），采用 SSE 的方式接入。

约束：
1. 调用云端 Chat Completions（或兼容 OpenAI 协议的）接口，开启 stream / SSE（text/event-stream）。
2. 前端（或驾驶舱助手位）边收边显示 token/文本片段；支持「生成中」状态与错误态；断流可重试。
3. API Key 只放在后端或本地 .env（已 gitignore），前端不得硬编码密钥。
4. 最小验收：发送一句「用三句话介绍你自己」，界面能流式打出回复；失败时显示可读错误，不白屏、不假装成功。
5. 交付：可运行的最小代码 + 我怎么启动的 3 行说明（README 小节即可）。

先问我：工作区语言栈（纯 HTML / Node / Python）和密钥从哪读；再改代码，不要一次糊一堆无关重构。
```

### 手工检查清单

- [ ] 请求带流式参数（如 `stream: true`），响应按 SSE/事件流解析，不是一次 `JSON.parse` 全文；
- [ ] 界面有「生成中」；首字出现前可等待，但不得无反馈干等；
- [ ] Key 不在前端源码；断流/401/超时有提示；
- [ ] （加分）网关失败时降级文案，不胡编摘要。
