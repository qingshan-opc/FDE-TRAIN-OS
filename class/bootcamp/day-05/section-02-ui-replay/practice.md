# 第 2 节 · 本地实操

在 QRAE 中切换到 `@UI`。不要继续使用产品经理智能体代替 UI。

## 第 1 段 · 读取并复述

```text
请读取 day5-replay/iteration-prd.md 和 pm-handoff.md。
只复述目标用户、核心动作、范围、业务规则和验收标准。
发现冲突时停止，并明确要求回到 @产品经理。
```

## 第 2 段 · 列页面与状态

```text
请只列本次需要修改的页面区域。
逐项写输入、显示字段、用户动作和结果反馈。
再补充加载、空数据、成功和错误状态。
现在不要生成代码。输出后停止。
```

## 第 3 段 · 生成交互说明

```text
请生成 day5-replay/iteration-ui-spec.md。
用文字线框说明布局、操作顺序、状态变化和异常提示。
每条设计必须标注对应的产品验收标准。
```

## 第 4 段 · 生成 UI 交接

```text
请生成 day5-replay/ui-handoff.md。
写清前端必须实现的元素、交互、状态、文案和证据要求。
保存后停止，等我回复“确认原型”。
```

## 学员检查

- 是否只改动必要区域？
- 四种页面状态是否都有明确反馈？
- 前端是否能仅靠交接文件开始工作？

全部通过后回复：`确认原型`。
