# 第 3 节 · 练习

## 知识确认（3′）

1. TRAE 的“提示词”输入框里应该放临时任务，还是岗位长期说明书？
2. 本课程为什么要求关闭“可被其他智能体调用”？
3. 创建完成后，如何确认当前已经切换到正确岗位？

## 实操任务（17′）

### 第 1 轮 · 跟做产品经理和 UI

1. 点击当前 `@Agent`；
2. 点击“创建智能体”；
3. 名称填“产品经理”；
4. 粘贴产品经理提示词正文；
5. 关闭“可被其他智能体调用”；
6. 点击“创建”；
7. 按相同步骤创建“UI”。

### 第 2 轮 · 独立完成剩余岗位

按同样方法依次创建：

- 前端；
- 后端；
- 测试；
- 运维。

### 第 3 轮 · 切换巡检

在对话框依次选择六个岗位，确认名称旁出现当前选中标记。不要发送项目任务。巡检结束后切回 `@产品经理`。

## 完成标志

- 自定义智能体列表中有且只有本课要求的六个岗位名称；
- 六个岗位均使用对应的独立提示词；
- 六个岗位均已关闭“可被其他智能体调用”；
- 已逐个完成切换验证，最后停留在 `@产品经理`。
