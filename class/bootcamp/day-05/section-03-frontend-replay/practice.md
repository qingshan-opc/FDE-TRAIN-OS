# 第 3 节 · 本地实操

在 QRAE 中切换到 `@前端`。本节允许修改前端代码，但必须先完成检查和确认。

## 第 1 段 · 检查现有前端

```text
请读取 iteration-prd.md、iteration-ui-spec.md、ui-handoff.md 和现有前端代码。
只说明入口文件、相关组件、当前请求位置和可复用部分。
不要修改代码。输出后停止。
```

## 第 2 段 · 提出最小改动

```text
请列出准备修改的文件和每个文件的修改目的。
说明哪些部分保持不变，以及需要后端配合的请求合同。
不要执行修改。输出后停止，等我回复“确认前端改动”。
```

## 第 3 段 · 实现前端

```text
已确认。请只按 UI 交接实现本次改动。
覆盖加载、空数据、成功和错误状态。
不得修改后端业务规则，不得重构无关文件。
```

## 第 4 段 · 自检与交接

```text
请运行项目已有的前端检查，并引导我打开真实页面。
生成 day5-replay/frontend-acceptance.md 和 frontend-handoff.md。
写明修改文件、页面入口、请求合同、四状态结果、证据路径和后端待办。
```

## 学员检查

- 实际修改是否与确认清单一致？
- 四种状态是否能在真实页面看到？
- 浏览器控制台是否存在新增错误？
- 请求合同是否足够让后端接棒？
