# 财务驾驶舱：五天一句话指挥示例

本示例只帮助学员理解怎样说话。每次只复制当前一步；岗位会先确认、一次问一个问题、分步完成并等学员批准。

## 第一天：组队、需求和页面样稿

```text
@项目经理 Agent 我想从自己的专业或工作中选一个五天能做完的小项目。请一次只问我一个问题，帮我把选题和范围问清楚。
```

项目任务书批准后：

```text
@产品经理 Agent 请把已批准的项目任务书变成清楚的需求。一次只问我一个问题，写完告诉我“我的哪些回答变成了哪些需求”，带我检查。
```

需求批准后：

```text
@UI/UX 设计师 Agent 请把四个核心页面做成能打开、能点击的页面样稿，一页一页带我检查。AI 区先写“第二周接入”和“演示数据”，再画按钮。
```

## 第二天：把四个页面做出来

```text
@前端工程师 Agent 请按已批准的需求和页面样稿，先把四个空白页面运行起来，带我逐页打开。等我批准后再一页一页完成。
```

## 第三天：让数据真的保存和变化

```text
@后端工程师 Agent 请让提交、列表、详情和驾驶舱使用同一份真实业务数据。分步告诉我数据怎么走，并用一条真实记录证明。
```

后端批准后：

```text
@前端工程师 Agent 请把四个页面从演示数据换成真实业务数据，带我亲手走一遍“提交—保存—列表—详情—驾驶舱更新”。
```

## 第四天：亲手找问题、修问题

```text
@测试工程师 Agent 请一次带我检查一个场景，等我说出实际结果再记录。发现问题时，帮我生成一句交给责任工程师的修复任务，不要替他修改。
```

## 第五天：交付和讲清楚

```text
@运维工程师 Agent 请一次带我完成一个动作，从零把项目在本地运行起来，并整理成别人看得懂的使用说明。不要写“已上线”。
```

```text
@项目经理 Agent 请主持最终验收，一次让我完成一项演示。按我的真实表现记录结果，不要替我判定通过。
```

## 学员只需要记住

- 说清这一步想要的结果；
- 要求岗位一次只问一个问题；
- 让岗位分步完成并带你检查；
- 明确说“批准”后，再亲自交给下一个岗位。
