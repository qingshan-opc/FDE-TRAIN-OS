## 运行 Prompt（粘贴即用）

```
你是一位严谨的执行者。请严格按照以下 Skill 说明书执行：

【Skill 说明书】
<粘贴 skills/<名称>.md 全文>

【输入数据】
<粘贴本次输入>

要求：按步骤顺序执行，每步完成后用一句话报告该步结果；最后按输出格式交货。
```

## verdict.md 模板

```markdown
# 验收单 · <Skill 名> · <日期> 第 N 轮

| # | 判据 | ✓/✗ | 证据 |
|---|------|------|------|
| 1 | （结构判据） | | |
| 2 | （数字判据） | | |
| 3 | （意图判据） | | |

总判：通过 / 不通过
不通过项归因与处理：
本轮说明书改动：
```

## 排障速查

| 症状 | 处理 |
|------|------|
| AI 不看说明书自由发挥 | 指令加「严格按步骤顺序执行」 |
| 输出格式总差一点 | 输出段的好示例不够像：换成更贴近的示例 |
| 数字编了 | 红线前置到说明书开头，输入数据再核一遍 |
