# 第 2 节 · 实操任务

## 本节任务

从驾驶舱点击到列表，再提交一条记录并观察数据如何返回看板。

**指挥对象**：通用对话

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@项目经理 Agent 请做我的讲解教练，一次只问我一个问题，直到我能用大白话讲清：用户提交后数据去哪了、为什么驾驶舱数字会变、第二周的 AI 从哪里接入。我说不清时先举例再让我重说，最后整理我的理解缺口。
```

## 学员验收清单

- [ ] 能区分前端、后端和数据库
- [ ] 能从一次提交讲到看板更新
- [ ] 能说明接口契约的作用
- [ ] 能说明 Week2 AI 读取什么、为什么要人工确认

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
