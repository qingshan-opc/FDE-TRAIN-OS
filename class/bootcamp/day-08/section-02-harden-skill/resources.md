## 注入指令模板

```
请严格按 Skill 说明书（含边界与异常段）执行。
【输入数据】
<坏输入粘贴处>
要求：如输入不符合边界声明，按声明的方式处理，不要勉强生成交付物。
```

## 失控失败的典型长相（对照检查）

- 数据是空的，却产出了一份「内容完整」的周报（编了）；
- 字段名变了不吭声，产出里对应位置写了「无数据」但其他照常（硬撑）；
- 「合并两周数据」直接给了拼接版，没问你要哪种（闷头乱选）。

## 修复速查

| 症状 | 修哪 | 怎么修 |
|------|------|--------|
| 空数据照编 | 说明书 | 「输入为空时必须停止并列出所缺」前置到说明书开头 |
| 超范围照做 | 说明书 | 边界段加「超范围请求必须先声明并询问」+ 给一个示例 |
| 歧义乱选 | 说明书 | 边界段加「列出 ≤3 种理解请求确认」+ 示例 |
