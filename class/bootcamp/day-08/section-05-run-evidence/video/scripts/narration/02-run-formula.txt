运行公式就一句：说明书加输入。入口在你自己的仓库：可以是 POST 一个 skill/run 接口，可以是一条 CLI，也可以在助手位里显式说「请运行某某 Skill」——先通一条路就行，不必一次做成完整 Agent Loop。输入数据从哪来？业务系统 curl 结果、导出的 JSON，或你准备的 input.md。最后一句指令：「按这份 Skill 执行」。收货后别看感觉，看你写的验收段，逐条判 ✓ 还是 ✗。打个比方：你以前是厨师，现在是质检——锅在 AI 那边，尺子在你这边。有同学问：输入要贴多少？够覆盖输入段写的来源和范围就行，别半拉子数据测全流程。输入和说明书对不上，验收不过不算 AI 的锅，嘛。
