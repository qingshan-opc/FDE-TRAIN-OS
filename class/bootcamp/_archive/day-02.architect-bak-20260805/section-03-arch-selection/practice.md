# 第 3 节 · 实操任务

## 本节任务

实现列表和空态，并标记当前数据来源为 Mock。

**指挥对象**：@前端工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@前端工程师 Agent 请做好列表页，先放至少五条演示记录，并补上“没有记录”时的页面。刚在提交页新增的内容要立刻出现在列表里，页面要写明“当前为演示数据”。完成后带我亲手提交、查看和筛选。
```

## 学员验收清单

- [ ] 至少五条 Mock 且字段合法
- [ ] 空态可验证
- [ ] 提交与列表联动
- [ ] 页面或说明明确当前不是数据库数据

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
