04WEB · 框架选型

从静态店铺到框架时代

地基仍是 HTML / CSS / JS。框架是预制装修套件。

React人最多 · 生态最大 · AI 最会写 · 多数新项目安全牌
Vue国内文档友好 · 中小型 / 单体 / 大屏很合适
Angular全家桶 · 大企业存量多 · 上手偏重
Svelte / Next.jsSvelte 写法省事；Next.js = React + 服务端渲染
不用框架小页面够用——Day 3 的 index.html 就是正确答案
TypeScript Vite 工程化两件套
05APP · 原生与跨端

两套原生，几条跨端路

性能要极致走原生；小团队默认跨端。

Native

Swift / Kotlin

苹果、谷歌官方语言。系统能力最全；代价是两套代码、两拨人。

Cross

Flutter / RN

Flutter 双端长得齐；React Native 会 React 就转得顺。

国内多端

还要顺带出小程序 + App + H5？常看 uni-app 一条龙编排。

06MINI · DESKTOP

小程序与桌面

国内生意绕不开小程序；桌面多用网页技术包壳。

Mini Program

微信原生 / Taro / uni-app

原生最稳（WXML / WXSS / JS）。要微信支付宝抖音再加 H5、App → Taro / uni-app。

Desktop

Electron / Tauri

Electron 零门槛（VS Code、飞书）；Tauri 更轻，体积小很多。

扫码即用 包壳 轻量看 Tauri

四问按序
Q1

团队会什么？

学习成本是真实成本——有团队跟团队走。

Q2

生态大不大？

遇坑有答案、招得到人——没团队跟生态走。

Q3

AI 写得好不好？

语料多的技术，生成质量更稳。

Q4

项目有多大？

小页面不必上框架；长大了再装备。
