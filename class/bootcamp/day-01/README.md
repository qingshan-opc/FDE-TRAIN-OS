# Day 1 · 第一次指挥 AI 开发：从专业问题到交互原型

> 今日目标：**消除对软件开发的畏难，建立六岗位软件工程地图，在 TRAE 创建 AI 开发团队，并用自己的专业知识完成“产品经理确认需求 → UI 生成原型 → 产品经理验收”的第一次交接闭环。**
> 总时长 120′ · 6 节 · 认知 25′ + 工具准备 20′ + 项目实战 75′

## 这一天在解决什么

今天不是从代码、框架或数据库开始，而是先解决小白最容易卡住的两个问题：第一，“我不懂开发，能不能做软件”；第二，“AI 能写很多东西，我应该怎样指挥它”。

答案是：你不需要先成为程序员。你在财务、HR、运营、销售、教育或其他专业领域积累的判断，正是项目的起点。你负责说清真实问题、做选择并判断结果是否合格；AI 岗位智能体负责把这些判断转化为文档、设计和程序。

今天会先看懂一套软件从哪里来：产品经理确认需求，UI 设计交互，前端实现页面，后端接入数据，测试检查系统，运维部署上线，最后再由产品经理回到最初需求做业务验收。然后你会在 TRAE 中创建这六个岗位智能体。岗位之间不会自动替你交接，而是由你通过 `@岗位名称` 手动切换，并用工作区文件传递成果。

完成团队搭建后，你会从自己熟悉的专业领域选择一个可视化项目，与 `@产品经理` 逐题确认需求并得到 `PRD.md`，再交给 `@UI` 生成可点击的交互原型，最后回到 `@产品经理` 按原需求验收。第一天结束时，你不只是“看过一个页面”，而是亲自指挥了一次真实的软件岗位交接。
