## 02 · simple-stack

**PPT（屏幕）**
- 第一次后端先降低门槛
- Python 3 标准库
- SQLite
- 不安装第三方依赖

**口播**
> 第一次后端使用 Python 三标准库。数据保存在本地轻量数据库中。这样可以减少依赖安装和环境差异。你能先看懂开发和运行的完整流程。以后换成其他技术框架，这套验证和交接顺序仍然成立。

文稿：`video/scripts/narration/02-simple-stack.txt`

## 05 · start

**PPT（屏幕）**
- P3 · 学员亲手启动
- 项目根目录
- python backend/server.py
- 终端保持运行

**口播**
> 文件通过后打开工具终端。先确认终端位于项目根目录。再输入运行手册中的启动命令。如果电脑使用启动器，就采用手册中的备用命令。服务启动后终端会持续运行。其实它正在等待请求，并不是电脑卡住了。

文稿：`video/scripts/narration/05-start.txt`

## 06 · health

**PPT（屏幕）**
- 先做健康检查
- 127.0.0.1:8000
- GET /api/health
- 证明服务能响应

**口播**
> 保持终端窗口开启。接着在浏览器访问健康检查地址。看到合同规定的结果，说明服务已经启动并能响应。健康检查失败时先看终端原始错误。不要马上修改很多代码。服务没有启动时也不要进入前端联调。

文稿：`video/scripts/narration/06-health.txt`

## 07 · api-tests

**PPT（屏幕）**

- 一次提交
- 两种错误
- 实际结果对合同

**口播**

文稿：`video/scripts/narration/07-api-tests.txt`

## 08 · restart

**PPT（屏幕）**
