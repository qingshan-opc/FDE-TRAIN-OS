## 讲授要点

### 第一关：18 词抽测

- 范围：今天六节全部考点（见 README 章节地图）；
- 规则：**≥12/18 过线**；不过线当晚补学对应小节，明天开课前补测；
- 18 词清单：LLM · Token/窗口 · 幻觉 · 开源/闭源 · 多模态 · Prompt · Context Engineering · RAG · Fine-tune vs Prompt · Eval · Guardrails · Vibe Coding · Agent · Harness · Workflow vs Agent · Tool Calling · MCP · 副驾模式 vs 智能体

### 第二关：LLM 认知卡

规格（`llm-cognition-card.md`）：

1. **六大主题**，每个 2–3 条要点：
   - 生态四层 / Token与幻觉 / Prompt与RAG / Eval与护栏 / Agent与Harness / 副驾模式 vs 智能体
2. **每条配实例**：来自前五天真实交付物或自己的类比——不许抄课件；
3. 自验收：随机指一条，30 秒讲给同桌听。

### 过闸标准

- 抽测 ≥12/18；
- 认知卡六大主题齐全、有实例；
- 口头 3 词互测通过。
