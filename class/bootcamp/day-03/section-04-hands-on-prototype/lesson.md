# 第 4 节 · 实战：用提示词生成高保真 index.html（35′ · 实战）

> 一句话：两轮循环——生成，对照规范验收，改约束重生成。

## 教学目标

- 走完「规范 → 提示词 → 生成 → 验收 → 重生成」完整闭环；
- 产出「部门周报助手」单页高保真原型 `index.html`；
- 体验「验收师」的真实手感：不手改产物，只改约束。

## 讲授要点

### 今天的页面长什么样

依据 Day 1 的 PRD，单页三段式：

1. **Hero 区**——一句话价值主张 + 主按钮（如「本周周报，10 分钟交差」+「开始生成周报」）；
2. **三个功能区块**——对应 PRD 的三个核心功能（示例：自动汇总本周工作 / 一键生成周报草稿 / 历史周报归档检索）；
3. **页脚**——产品名 + 一句口号。

### 两轮工作法

| 轮次 | 动作 | 时间 |
|------|------|------|
| 第 1 轮 | 粘 UIUX 提示词 + 你的设计规范四件套 + PRD 摘要 → 生成 index.html → 对照规范逐条验收 | 20′ |
| 第 2 轮 | 把验收发现的问题改写成量化约束，补进提示词 → 重新生成 → 复验 | 15′ |

### 验收清单（对照用，也是第 5 节的过闸标准）

- [ ] hero 区 + 三个功能区块齐全；
- [ ] 全页真实中文文案，无占位符（无 lorem ipsum、无「示例文字」、无灰块图）；
- [ ] 主色 / 字号 / 间距 / 圆角与你的 design-spec.md 一致；
- [ ] 主按钮有默认 / 悬停 / 禁用三态样式；
- [ ] 单文件，双击浏览器可直接打开。

### 卡点预案

- AI 输出了多个文件 → 收窄约束：「只输出一个 index.html，所有样式内联在 `<style>` 标签里」；
- 出现占位符 → 加约束：「所有文案必须是面向真实用户的中文成品文案」；
- 三态缺失 → 加约束：「主按钮必须包含 :hover 悬停样式和 disabled 禁用样式」。

## 🎬 口播稿（约 2 分钟）

【开场】同学们，理论到此为止，这 35 分钟全给你动手。目标一个——让「部门周报助手」有脸。

【备料】你手里已有三样东西：PRD、设计规范四件套、两份提示词。今天的战术是「两轮工作法」——第一轮「生成再验收」，第二轮「改约束重生成」。

【第一轮】把 UIUX 提示词整份粘进 AI 工具，接上你的四件套和 PRD 摘要，补一句「只输出一个 index.html」。生成完别急着高兴——拿第 2 节的验收清单，逐条打勾。

【第二轮】发现的问题，全部翻译成量化指令：不说「标题大一点」，说「标题字号从 24 调到 32」。改的是约束，不是产物——手改的产物，下次生成就没了。

【提醒】你会很想直接打开 HTML 改两行代码。忍住。你今天是「验收师」，不是施工队。

【带走的话】带走一句话——第一轮看 AI 的水平，第二轮看你的水平。

## 常见懵点（导师备用）

- 「生成结果和规范差太多，要不要换模型？」→ 先检查你的约束是否量化、是否贴全；八成问题在输入不在模型；
- 「两轮之后还有小问题怎么办？」→ 记进迭代日志，达标即可过闸；完美主义是原型的敌人；
- 「index.html 里要不要写真的 JS 交互？」→ 不要。今天是阶段一（UI 优先），交互逻辑等 Day 4 接 API 时再说。
