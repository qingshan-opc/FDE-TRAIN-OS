## 第一部分 · 口播分镜

【画面：黑底标题「这个时代是怎么来的」】

啊，同学们，今天这个课呢，咱们先不动手写东西，先讲一下就是咱们这个互联网的发展史。嗯，毕竟以后大家要进入到这个行业嘛，那必须要了解，就是这个时代它是一步一步怎么走过来的，你才知道你现在站在哪，对吧。

【画面：时间轴第一格「1990s」】

第一个呢，是九十年代。九十年代的话就是计算机刚出来，那时候一台电脑都还很大，大家应该小时候有见过那种大头的计算机，就是那个头特别大的那种。我不知道咱们这边 00 后有没有见过啊，反正后面的话都逐渐变成液晶屏了。那电脑刚进办公室的时候是干嘛呢？以前大家记账用算盘嘛，现在不用算盘了，把账全都记到电脑里面去。这就叫信息化，说白了就是电脑替代手工，第一波。

【画面：时间轴第二格「2000s」】

然后第二波的话，就是两千年，网页时代。就是 HTML，超文本标记语言嘛，大家都开始做网页了。通过网页干什么呢？展示自己的店面。别人可以通过邮件啊、各种其他的方式啊去联系到你，然后把你的东西买一下。那时候还都是大部分都是快递的线下交易，就是网页负责展示，生意还是在线下做。

【画面：时间轴第三格「云时代」】

第三个时代的话就是云，2010 年左右，云服务时代。云这个概念其实很早就有了，亚马逊是最早把这块服务做起来的。那时候大家是什么情况呢？所有企业都是自己建机房，自己买服务器，自己拉网线。后来机房也不自建了，全都搬到云上去了，本地的服务器全都移掉了。那时候还有很多专门做服务器的厂商，后面也都是把服务器全都卖给这些云厂商了。云厂商干嘛呢？就是把服务器虚拟化一下，给你提供一个服务，它底层那些网络啊、存储啊，都给你包装起来，你可以按需去使用。所以从这个时代开始，基础设施就变成水电煤了，你用多少交多少钱。

【画面：时间轴第四格「移动互联网」】

跟云差不多一块出来的，就是移动互联网时代。以前那些翻盖手机，就没有了嘛，他其实是一个操作系统的进步衍生出来的一个概念。大家都逐渐去买智能手机，通过手机玩游戏啊、聊天啊。然后随着这个基础设施的发展，4G 到 5G 嘛，网络一起来，大家都逐渐把办公也弄到手机上了。比较出名的就是大家沟通都用微信嘛，然后有些用钉钉，钉钉是后面出来的，这个先不说。

【画面：时间轴第五格「AI 时代」点亮】

然后呢，就到 AI 这个时代了。OpenAI 大概是 2015 年就开始开发 GPT 了，当初是马斯克投资的这个企业，后面他们把马斯克给丢出去了，这个八卦咱们就不展开了。他们之前一直是做小模型，2018 年 GPT 一代的时候小火过一次。所以那时候百度就做了一个决定叫 All in AI，也是赶了个早场，但是没吃上饭。真正具有划时代意义的，是 2022 年底 ChatGPT 出来。那是第一次，人类见识到 AI 模型经过一段训练学习之后的泛化能力——就是它会具备很多没有专门训练过的东西，它自己初步有一个简单的思考能力。这个规律也很简单，模型越大，它的泛化能力越强，越智能。这里重点说一下我们国产厂商的贡献啊，像 DeepSeek，它把蒸馏加思考这套东西带进了主流大模型，后面整个大语言模型都受它影响，这个是很了不起的。

【画面：四代方式对比图，第一格亮】

好，AI 来了，那人是怎么用 AI 的？这个才是今天真正要讲的。我把它分成四代，你们自己对号入座一下。我记得我最初的时候去用 GPT 做架构，那时候还都是一句一句地喂，丢东西给它，然后对话，然后再复制粘贴出来用。AI 就是聊天窗口里的一个顾问，你是搬运工。这是第一代。

【画面：第二格亮】

后面的话，大家开始研究怎么把 AI 接入到系统里面。那时候怎么接的呢？就是提示词工程，在提示词里面去写死它，让它返回某一种固定的格式，然后让程序去解析，在页面上显示出来。你这个应用其实就是一个接入了大脑的应用。但是那时候一套应用要好几十套提示词，你给我返回这个格式，你给我返回那个格式，而且很不稳定，还是很不稳定。这是第二代，蛮荒时代。

【画面：第三格亮】

再后面呢，模型增加了一个 Tool Call 的功能，就是你可以把一些本地的工具丢给模型，让模型自己决定怎么调。你只要把这个工具的调用实现了，他会自己去思考，进行一整串的任务。这个时代就是大家说的 Vibe Coding。Vibe Coding 我很早就开始用了，大家怎么用呢？打开编码引擎，开黑窗口，然后天天在那跟他斗智斗勇，一边骂一边用，就是含着泪在用。这是第三代。

【画面：第四格亮，中心 Agent 连出工具/记忆/知识库/流程】

然后后面的话，就是我们现在的这个时代了。我给它起了个名字，叫 Agent 原生系统，这可能是我自己提出来的一个概念啊，是我的理解。Agent 原生系统是什么意思呢？就是 Agent 把所有的东西开始接入起来，Tool Call 只是其中一种，包括记忆机制、记忆引擎，还有 Harness 这套运行架构，还有 RAG 知识库，还有企业的一些流程性的资产，全部接进来，让 Agent 去执行非常长串的任务。这个词大家记住啊，Agent 原生系统，后面咱们所有的课都是在这个地基上盖的。

【画面：回到完整时间轴，五格全亮】

好，今天收个尾。从算盘到电脑，从自建机房到云，从复制粘贴到 Agent 原生系统——每一波浪过来，都淘汰了一批旧的工种，也成就了一批新的人。下一节课咱们就讲，在这个时代，你要成为哪一种人。下课。

### 核心概念卡（术语速查）

| 术语 | 一句话解释 |
| --- | --- |
| 信息化 | 用电脑替代手工（算盘→电脑记账） |
| 虚拟化 | 一台物理服务器切成多份按需分配，云服务的技术底座 |
| 云计算 | 把服务器、网络、存储包装成按需取用的服务 |
| 泛化能力 | 模型做出「没被专门训练过的事」的能力 |
| 蒸馏 | 把大模型的能力压缩「教」给小模型的技术 |
| 推理（思考）模型 | 先想再答、显式推演过程的模型范式（DeepSeek 带火） |
| 提示词工程 | 用写死的提示词约束模型输出格式，供程序解析 |
| API | 程序之间约定好的调用接口/数据格式 |
| Tool Call | 模型自主决定并调用外部工具的能力 |
| Vibe Coding | 以自然语言驱动 AI 写代码的开发方式（CLI 黑窗口时代） |
| Agent | 能扮演角色、自主规划并执行多步任务的 AI 实体 |
| Harness | Agent 的运行架构/宿主环境（工具、记忆、权限的承载层） |
| RAG | 检索增强生成：先查知识库再回答，让模型「开卷考试」 |
| Agent 原生系统 | 把工具、记忆、知识库、流程全部接入 Agent，执行长任务（讲师提法） |

### 金句（可直接做课件标题）

1. 「AI 时代不是凭空来的，是一波一波技术浪潮推过来的。」
2. 「云时代之后，基础设施变成了水电煤。」
3. 「模型第一次展现了泛化能力——它会做没被训练过的事。」
4. 「一个应用几十套提示词，还不稳定——那是给应用接大脑的蛮荒时代。」
5. 「Vibe Coding：一边骂一边用，含着泪在用。」
6. 「Tool Call 只是开始，Agent 原生系统是把记忆、知识库、流程全部接起来。」

### 教学建议（落课参考）

- **对应课程位置**：Day 1 世界观课（可替换/增强现有 1.1「世界观快通」），或作为公开课首节。
- **配图建议**：
  1. 五时代演进时间轴（信息化→网页→云→移动→AI），每代一个标志物（算盘/HTML 页面/机房/翻盖机→智能机/对话气泡）；
  2. 「使用 AI 的四代方式」对比图（复制粘贴 → 提示词管道 → Tool Call 链路 → Agent 原生系统全景：工具+记忆+RAG+流程）；
  3. Agent 原生系统架构示意（中心 Agent，四周挂 Tool Call / 记忆引擎 / Harness / RAG / 企业流程）。
- **知识确认题方向**：
  - 「泛化能力」指的是什么？
  - 云厂商把物理服务器变成按需服务靠的是什么技术？
  - Tool Call 与提示词工程接系统的本质差别？
  - 按讲师的定义，「Agent 原生系统」包含哪些组成？
- **讲师自述待研究点**：Agent 多角色协作部分（口述中「AI 这块可能不太对，你研究一下」），建议补充 multi-agent 协作的准确定义后再入正式讲义。
