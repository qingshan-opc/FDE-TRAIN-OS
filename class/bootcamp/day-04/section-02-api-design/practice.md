# 第 2 节 · 练习

## 知识确认（3′）

1. 用一句话解释 REST，要求出现「URL」和「动词」两个词。
2. 400、404、500 三个错误码，各是谁的锅？各配一句餐厅场景的人话。

## 实操任务（12′）

为「部门周报助手」设计「提交周报」接口的菜单卡片，照下面的格子填：

| 格子 | 你的答案 |
|------|----------|
| 路径 + 方法 | 例：`POST /reports` |
| 请求参数（至少 2 个，写明类型与是否必填） | 例：content（文本，必填）、week（文本，必填） |
| 成功响应（状态码 + 返回什么） | |
| 错误响应 1（状态码 + 什么情况下发生） | |
| 错误响应 2（状态码 + 什么情况下发生） | |

完成后自查两问：

1. 路径里有没有把动词写进去（如 `/submitReport`）？有就改成 REST 风格；
2. 如果同事提交了一份空白周报，应该返回哪个错误码？为什么？

## 完成标志

- 菜单卡片五格全部填满，路径为 REST 风格；
- 至少设计了两个不同含义的错误响应；
- 能答出自查第 2 问（400，因为请求内容不合法，锅在调用方）。
