# 第 2 节 · 练习：缺陷说明书诊断（随堂 7′）

## 任务

下面这份 Skill 说明书有 **5 处缺陷**（对照四部件写作要求），找出并改写：

```markdown
# Skill: 数据整理

## 输入
相关的业务数据

## 步骤
1. 获取数据
2. 分析一下
3. 输出结果

## 输出
一份清晰的报告

## 验收
报告质量高，老板满意
```

## 改写要求

每处缺陷：指出 → 违反哪条要求 → 改写成什么样（以你自己的一个真实场景为例）。

## 参考答案（做完再看）

1. 「相关的业务数据」→ 输入不具体 → 写明来源与范围；
2. 「分析一下」→ 步骤不可执行 → 拆成具体动作；
3. 「清晰的报告」→ 输出无格式 → 格式+长度+红线；
4. 「质量高」→ 验收不可判 → 可判对错的条目；
5. 「老板满意」→ 验收主体不可操作 → 谁验、看什么、怎么算过。

## 过关标准

- 找出 ≥4 处；
- 改写后的每条都过得了「换个人照做不会做出第二种理解」。
