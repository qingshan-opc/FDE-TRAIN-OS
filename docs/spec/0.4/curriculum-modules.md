# 课程模块化重构（v0.5 · 取代 v0.4.1 的 Day 级排布）

> 重构动因：旧版把「FDE 角色」当第一节、把「四层架构」当默认起点——
> 这是设计者视角，不是学员视角。本版从「一个零基础学员的认知路径」重新推导。
> 依据：`class/FDE课程设计_核心决策记录.md`（两周主线、70/30、成果导向不变）。

## 一、学员视角评估：旧版学完会不会懵？

会。逐点说：

| # | 懵点 | 根因 | 本版对策 |
|---|------|------|---------|
| 1 | 第一节讲「FDE 是谁」，但学员还不知道 AI 能干什么，角色没有锚点 | 角色先于世界观 | FDE 降为**课程导论**（Module 0），不是第一节 |
| 2 | 「四层架构」里的第四层「AI 模型」是黑盒——LLM 是什么、从哪来、会什么不会什么，没人讲过 | 缺 LLM 本体认知 | Module 1 先讲 LLM 本体（能力/边界/幻觉）再讲它在架构里的位置 |
| 3 | 学员不知道「为什么是现在」——为什么写代码不值钱了、为什么企业现在要这种人 | 缺技术演进脉络 | 新增**技术演进时间线**（单机→Web→云→移动→AI 辅助→AI 原生） |
| 4 | 学完只认识课堂里的工具，出了教室听到 GPT/Claude/DeepSeek/Ollama/MCP 还是懵 | 缺生态地图 | 新增 **LLM 生态图**（模型层/平台层/协议工具层/应用层，标出「你在这里」） |
| 5 | harness、Agent、RAG、MCP、context engineering、eval 这些 2025–26 行业日常词汇整课未出现，学员看行业文章依然看不懂 | 新概念缺位 | 新增**新概念词典**（18 个词，一句话 + 课程里在哪遇到） |
| 6 | Week2 直接「先 Skill 后 Agent」，但没讲 Agent 为什么长这样 | 缺 harness/决策环概念 | harness 概念在 Day 8 落地：模型 + 工具 + 记忆 + 循环 = 骨架，Agent 跑在骨架上 |
| 7 | 第一节就背「验收纪律」，学员没有动机 | 价值感未建立 | 演进线收尾于「每次浪潮改变谁值钱」，验收纪律在实战节自然生长 |

**结论：不是加两节课的问题，是课程的地基层缺了「世界观」整块。**

## 二、模块化结构

课程从「十天流水」改为「六个模块」，模块是认知单元，天是交付单元：

```
M0 导论（课前自学 ~30′）      FDE 是什么 / 你将建成什么 / 课程怎么用
M1 AI 世界观（Day 1）         技术演进 · LLM 本体 · 生态图 · 新概念词典
M2 全局架构（融入 D1 后半+D2） 四层地图 · 信息架构 · 约束驱动选型
M3 全栈实战（Day 2–6）        前端 → 接口 → 数据库 → LLM → 部署 V1.0
M4 Agent 进阶（Day 7–9）      Skill 封装 → 工程化 → harness/Agent → 编排
M5 收官（Day 10）             V2.0 · 答辩 · 行业地图自评 · 自学路线
```

设计原则更新（在原五条上增补）：

6. **世界观先于动手**：学员必须先能讲清「我在什么时代、AI 是什么、生态里有什么」，才碰代码；
7. **每个新概念都有图**：演进有时间线图，生态有分层图，架构有四层图，Agent 有决策环图；
8. **词典随身**：新概念词典是附件不是课文，十天里反复回查；
9. **FDE 不做第一课**：它是课程的介绍页——学员 Day 10 答辩后自然成为 FDE。

## 三、十天重排（每天 100–140 分钟）

### M1 · Day 1 · AI 世界观：看懂你所在的时代（120′ · 7 节）—— 全天无代码，但不无产出

| # | 课节 | 分钟 | 形式 | 要点 / 产出 |
|---|------|-----|------|------------|
| 1 | 技术演进简史：六次浪潮，谁值钱 | 20 | 概念 | 单机→Web→云→移动→AI 辅助→AI 原生；每次浪潮重排职业价值；**图：演进时间线** |
| 2 | LLM 是什么：能力、边界与幻觉 | 15 | 概念 | 会什么（生成/理解/推理）、不会什么（记忆/真相/主动）；幻觉不是 bug 是机制 |
| 3 | LLM 生态图：你在哪一层 | 20 | 概念 | 模型层（闭源 API/开源权重/国内外厂商）→ 平台层（网关/托管/本地推理）→ 协议工具层（MCP/Function Calling/Agent 框架）→ 应用层；**图：生态图，标「你在这里」** |
| 4 | 新概念词典 18 词 | 20 | 概念+自测 | harness/agent/RAG/MCP/context engineering/eval/workflow vs agent/vibe coding…；配词典附件，课堂抽测 6 词 |
| 5 | AI 应用的四层架构 + 两周路线 | 15 | 概念 | 前端/接口/数据库/模型；十天演进图；模块地图 |
| 6 | 实战：课程环境导览 + 选方向 | 20 | 实战 | Agent Lab 五步演示（导师演，学员看）；写方向卡（3 个可数据化问题） |
| 7 | 验收：概念地图自测 + 方向卡 | 10 | 验收 | 自测 8 题（演进/生态/词典/架构各 2）；方向卡过导师闸 |

> 产出：方向卡 + 世界观自测过线。**这一天不懵，后面九天都顺。**
