# 第 4 节 · 分段开发操作卡

## 固定顺序

```text
P1 骨架 → 打开页面
P2 样式 → 肉眼对照
P3 交互 → 亲手点击
P4 状态 → 四种结果逐一查看
```

## 三文件

- `frontend/index.html`
- `frontend/styles.css`
- `frontend/app.js`

## 常见问题

- 页面空白：确认文件是否真实保存、HTML 是否完整；
- 无样式：检查 `styles.css` 的相对路径；
- 按钮无反应：检查 `app.js` 路径并打开控制台；
- 修改后无变化：刷新页面，确认打开的不是旧文件。

## 禁止项

- 不复制真实业务数据；
- 不写 API 密钥；
- 不编造后端接口；
- 不一次提交四段任务。
