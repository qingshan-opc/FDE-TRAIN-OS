# 第 2 节 · 练习：环境分家改造（随堂 10′）

## 任务

给自己的项目做完整分家：

1. **清点**：列出代码里所有「像配置的东西」（密钥/令牌/URL/开关）；
2. **搬家**：全部改为 `os.environ` 读取；
3. **三件套落地**：
   - [ ] `.env` 含本地真值，且已加入 `.gitignore`；
   - [ ] `.env.example` 含键名 + 假值 + 中文注释，提交进 Git；
   - [ ] 平台面板需要配哪些变量，列成清单（第 5 节部署时用）；
4. **公开测试**：假想仓库此刻公开——逐项确认无真值泄露，写一句结论。

## .env.example 示范

```bash
# 模型网关令牌（找教务领取，形如 gw-xxxxx）
GATEWAY_TOKEN=your-token-here
# 数据库文件路径（默认 ./cockpit.db，一般不用改）
DB_PATH=./cockpit.db
```

## 过关标准

- 清点无遗漏（导师抽查 `git grep` 结果）；
- 三件套四勾全；
- 公开测试结论明确。
