# FDE Learning OS 0.1 发布清单

## 镜像 / 进程

| 组件 | 说明 |
|------|------|
| API | 镜像 tag：`fde-api:0.1.0`（`docker build -t fde-api:0.1.0 .`） |
| 本地进程 | `./scripts/start.sh` → `uvicorn ... :8760` |
| Postgres | compose `postgres:16` · 端口 `5433` · `DATABASE_URL=postgresql://fde:fde@127.0.0.1:5433/fde` |
| MinIO | compose · `9000/9001`；开发默认落盘 `data/artifacts` 经 `/artifacts` 暴露 |
| 灵知 | 外挂 `8230` |
| anyCode Dashboard | 外挂 `43180`（`AGENT_MODE=auto`） |

## 本地生产形态（推荐）

```bash
docker compose up -d postgres minio
# .env 中 DATABASE_URL=postgresql://fde:fde@127.0.0.1:5433/fde
./scripts/start.sh
./scripts/smoke_e2e.sh
```
