## 高频踩坑

| 坑 | 解法 |
|----|------|
| 本地改了忘 push | `git status` + `git push`，然后等平台重新构建 |
| 端口不匹配 | 启动命令用平台给的 `$PORT` 变量 |
| SQLite 数据「回到旧版」 | 重新部署会换容器——教学期正常；数据演示改完记得记录 |
| 构建超时 | 依赖装太多；精简 requirements.txt |
