# 第 6 节 · 验收：技能包三问与过闸

> 🎬 视频位（现阶段：口播稿）
> Week 2 第一关。今天你从「写 Prompt 的人」变成了「设计工作方式的人」。

## 教学目标

- 通过 Skill 三问口试；
- 现场运行演示：导师看证据链，抽查判据；
- commit 存档，预告 Day 8：工程化 + Agent 登场。

## 流程安排（10′）

| 时段 | 内容 |
|------|------|
| 0–4′ | Skill 三问口试（导师抽查） |
| 4–8′ | 证据链验收：说明书 → 运行记录 → 验收单 → Git |
| 8–10′ | commit + Day 8 预告 |

## Skill 三问（必背）

对你的 Skill 脱口而出：

1. **它做什么？**（输入 → 输出，一句话：「吃 ____，交 ____」）
2. **步骤谁定的？**（你——AI 按说明书执行，不自由发挥）
3. **好坏谁判的？**（你——按验收段逐条判，有证据句）

## 今日验收清单（GATE 7）

- [ ] Skill 三问脱口而出；
- [ ] 证据链完整：skills/<名>.md + runs/三件套 + 二连过；
- [ ] 抽查判据：导师随机指一条验收判据，学员指出最近一次运行中对应的证据句；
- [ ] commit：`feat: 第一个 Skill——<名称>`。

## 🎬 口播稿（约 5 段 · 待审）

> 同学们，第七天验收，第二周第一关。第一周最后一天，你的驾驶舱上线了；第七天，你的第一个同事上岗了——它不吃饭不摸鱼，拿着你写的说明书，每次交出同样标准的货。你从写 Prompt 的人变成了设计工作方式的人，对吧。
> Skill 三问，脱口而出。第一问它做什么？输入到输出，一句话：吃某某，交某某。第二问步骤谁定的？你——AI 按说明书执行，不自由发挥。第三问好坏谁判的？你——按验收段逐条判，有证据句。三问答不上来，说明书还没写透，嘛。
> 证据链验收：skills/ 里的说明书、runs/ 里的三件套、连续两次验收全过，全部进 Git。导师会随机指一条验收判据，你要指出最近一次运行里对应的证据句。判据和证据对得上，才叫真验收，对吧。
> GATE 7 清单：Skill 三问脱口而出；证据链完整；抽查判据能指证据；commit 信息写 feat: 第一个 Skill——你的 Skill 名称。一天就做了一个 Skill，少吗？第一个做透比什么都重要——三筛、四部件、验收、证据，这套动作明天开始加速复用，对吧。
> 收个尾：Skill 能分享给同事——说明书就是交接物，让对方跑一次并独立验收，就是分享仪式。第八天咱们掀开引擎盖：AI 怎么拿着说明书干活？Harness、工具、记忆、决策环——Agent 登场。今晚预习公开课 O2 的 Agent 篇，对吧。


## 常见懵点

- 「一天就做了一个 Skill，少吗？」→ 第一个做透比什么都重要：三筛、四部件、验收、证据——这套动作明天开始加速复用；
- 「Skill 能分享给同事吗？」→ 能——说明书就是交接物；让对方跑一次并独立验收，就是分享仪式。
