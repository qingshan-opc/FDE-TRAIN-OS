// 十天路线图

十天，从需求到上线

每天 120 分钟：40 分钟方法课 + 70 分钟实战 + 10 分钟 GATE 验收。点开每一天，看看你的产出物。

开通 QRAE 工作区，认识六岗位智能体的分工与脾气。学会 @岗位 指派任务、读工作区文件、下达清晰指令的三段式结构：背景 / 目标 / 约束。

DELIVERABLES

  • 个人 QRAE 工作区开通并跑通
  • 《我的产品一句话想法》v1
  • GATE：成功指挥 3 个岗位完成一次接力

用"痛点 × 人群 × 场景"框架从自己的专业经验里挖出真需求。指挥 @产品经理 做竞品扫描和用户画像，把模糊的想法收敛成一个 10 天能做完的最小产品。

DELIVERABLES

  • 《产品选题卡》：痛点 / 用户 / 场景
  • 竞品扫描简报（PM 智能体产出）
  • GATE：选题通过"小而真"三问检验

学习 PRD 的最小骨架：用户故事、功能清单、验收标准。指挥 @产品经理 把需求写入 workspace/requirements.md，并学会用"追问三轮"法把文档打磨到可开发。

DELIVERABLES

  • requirements.md（含验收标准）
  • 功能优先级 P0 / P1 清单
  • GATE：PRD 通过完整性 checklist

把 PRD 交接给 @UI设计师，学会看信息架构和页面流转。掌握"说人话改稿"技巧：不用懂设计术语，用业务语言描述感受，让 UI 智能体迭代到满意。

DELIVERABLES

  • 可点击交互原型（3-5 个核心页面）
  • 页面流转图一页纸
  • GATE：找 1 位同学试用原型并记录反馈

指挥 @前端 按原型实现页面。学会"截图 + 描述"的走查方法，像甲方验收设计稿一样验收代码成果：像素对得上吗？交互顺不顺？手机上看行不行？

DELIVERABLES

  • 前端页面 v1（可本地预览）
  • 走查问题清单（bug & 体验）
  • GATE：核心页面与原型一致度 ≥ 90%

指挥 @后端 设计数据表和接口。你只需要回答好三个业务问题：要存什么？谁能看？错了怎么办？学会用真实业务数据做"端到端冒烟"，验证前后端连通。

DELIVERABLES

  • 数据模型说明（人话版）
  • 前后端联通的最小闭环
  • GATE：真实数据写入 → 查询 → 展示成功

最像真实职场的一天。多岗位并行时学会排优先级、解决"前端怪后端、后端怪需求"的经典冲突。掌握问题定位三板斧：复现 / 隔离 / 派单。

DELIVERABLES

  • 联调问题台账（已分级派单）
  • 核心流程全链路打通
  • GATE：主流程无阻断性 bug

指挥 @测试 编写用例：正常流、异常流、边界值。学会看懂测试报告，判断"这个 bug 要不要现在修"。邀请 3 位班级同学做真实用户测试。

DELIVERABLES

  • 测试用例表 + 测试报告
  • 真实用户反馈 ≥ 3 份
  • GATE：P0 用例 100% 通过

指挥 @运维 完成部署：域名、HTTPS、数据备份。理解上线的本质不是"发布按钮"，而是上线 checklist。把产品链接发给第一个真实用户。

DELIVERABLES

  • 可公开访问的产品链接
  • 上线 checklist（含回滚预案）
  • GATE：外部用户成功完成核心操作

整理完整项目档案：PRD、原型、测试报告、上线链接。完成 5 分钟毕业路演，领取结业证书。更重要的是：带走一套可复用的"指挥 AI 团队"方法论，下一个产品你可以独立做。

DELIVERABLES

  • 毕业路演（5 分钟，班级直播）
  • 完整项目档案包 + 结业证书
  • GATE：通过毕业评审 · 正式毕业 🎓
