# 第 2 节 · 企业数字化五阶段详解（25′ · 概念）

> 一句话节引言：上节讲了技术浪潮怎么重排「谁值钱」；这节换企业视角——一家公司从 Excel 报表到 Agent 替你跑流程，通常要爬五级台阶。**Agent 化 = 你们第二周要去的地方。**

## 教学目标

- 按顺序说出五阶段：**信息化 → 数字化 → 网络化 → 智能化 → Agent 化**；
- 每一阶段能答三问：企业在干什么 / 系统长什么样 / 人的角色是什么；
- 把五阶段与部门驾驶舱项目对上号，并指出 Week 2 的落点。

## 讲授要点

### 五阶段总览（梯子，不是选型）

| 阶段 | 企业在干什么 | 系统长什么样 | 典型名词 |
|------|-------------|-------------|---------|
| **信息化** | 把纸面流程搬进电脑 | OA、ERP、Excel 报表 | 录入、审批流 |
| **数字化** | 业务数据结构化、可查询 | 数据库、BI、驾驶舱 | KPI 表、指标 |
| **网络化** | 系统之间能对话 | API、微服务、多端 | 契约、网关 |
| **智能化** | 用大模型读数据、出建议 | LLM 接入、RAG、Eval | Prompt、降级 |
| **Agent 化** | 让 AI 按流程执行、留证据 | Skill、Harness、编排 | MCP、人工确认 |

这五级**不是每家公司都要爬满**，但你要能认出自己部门在哪一级、下一级缺什么。

### L1 · 信息化：先电子化

- **企业在干什么**：发票、请假、库存——从纸到屏幕；效率来自「少跑一趟」；
- **系统长什么样**：Excel 仍是主角；OA/ERP 开始上线，但数据常常「进系统就死」；
- **人的角色**：录入员、报表员——人仍是数据的搬运工；
- **与驾驶舱**：此时「驾驶舱」多是 PPT 梦想，数据还在 Excel。

### L2 · 数字化：数据有地址

- **企业在干什么**：KPI、订单、客户——要可查、可对比、可追责；
- **系统长什么样**：数据库 + 报表/驾驶舱；Day 4 的 DB_Schema 就在这一层；
- **人的角色**：数据 owner、流程梳理者——从搬数据变成「定义指标什么意思」；
- **与驾驶舱**：驾驶舱区块背后有真表、真字段；重启不丢。

### L3 · 网络化：系统能对话

- **企业在干什么**：前端、后端、第三方——不能各干各的；
- **系统长什么样**：API 契约、网关、多端（Web/App/小程序）；Day 3 的 API_Spec 在这；
- **人的角色**：契约设计者——改接口前先改合同；
- **与驾驶舱**：页面数据变真；错误态、空态要对用户诚实。

### L4 · 智能化：模型读数据、出建议

- **企业在干什么**：摘要、问答、辅助决策——但不能「我觉得还行」；
- **系统长什么样**：LLM 网关、Prompt、RAG、Eval/Guardrails；摘要区块接电；
- **人的角色**：Context 工程师 + **验收官**——Rubric 代替感觉；
- **与驾驶舱**：第六区块 AI 摘要；网关挂了要降级，不能白屏。

### L5 · Agent 化：能干活，不只说话

- **企业在干什么**：把重复流程封装成 Skill，让 Agent 在 Harness 里跑；
- **系统长什么样**：Skill 定义、工具表、记忆、重试、日志、人工确认闸；
- **人的角色**：**FDE**——定方向、写验收、指挥 Agent，不是替它打字；
- **与驾驶舱**：Week 2 主题——从「能看」到「能替你跑一段流程」。

### 和第一节世界观怎么接

- 第一节：**技术浪潮**压低成本、抬高判断（谁值钱）；
- 本节：**企业台阶**说明你在组织里推进的是哪一层变革；
- 合起来：你不是在背名词，是在给部门项目**定位坐标**。

## 🎬 口播稿（约 6 段 · 待审）

> 同学们，上节讲了技术浪潮怎么重排谁值钱。这节换企业视角：一家公司从 Excel 报表到 Agent 替你跑流程，通常要爬五级台阶。记住名字：信息化、数字化、网络化、智能化、Agent 化。这是梯子，不是让你今晚全爬完。
> 第一级信息化：纸变屏。OA、ERP、Excel 报表。人在当录入员、报表员。第二级数字化：KPI 进库，可查可对比。系统有数据库和驾驶舱——你们 第四天 的表结构就在这一层。人变成指标的定义者，不再只是搬数据，对吧。
> 第三级网络化：前后端用 API 契约对话，多端可访问。第三天 的 API_Spec 就在这一层——改接口先改合同。第四级智能化：LLM 读数据、出建议。但输出要用 Rubric 验收，网关挂了要降级——摘要区块接电，就在 L4，对吧。
> 第五级 Agent 化：把重复流程封装成 Skill，Harness 让 Agent 循环执行，留证据、要人工确认。人的角色是 FDE——定方向、做验收，指挥 Agent，不是替它打字。这就是你们第二周要去的地方：从能看到能干活，对吧。
> 和驾驶舱怎么连？信息化时驾驶舱多是 PPT 梦想；数字化有真 KPI；网络化页面数据变真；智能化长出 AI 摘要；Agent 化是 Skill 替你跑流程。你们项目已经踩在 L2 到 L4 之间——第二周 往 L5 走，对吧。
> 带走一句话：先认出你部门在哪一级，再决定下一级缺什么。五阶段是诊断地图，不是选型清单。下一节我们讲软件是怎么开发出来的——流程和需求调研，对吧。


## 常见懵点（导师备用）

- 「我们还在 Excel，算哪级？」→ 信息化为主，数字化萌芽——别自卑，先让一块 KPI 入库就是升级；
- 「智能化和 Agent 化有什么区别？」→ 智能化是「出建议」；Agent 化是「按步骤执行并留证据」——信任要求完全不同；
- 「五阶段必须按顺序吗？」→ 常见路径如此，但小团队可能跳级试点；地图用来**诊断缺口**，不是用来卡进度。
