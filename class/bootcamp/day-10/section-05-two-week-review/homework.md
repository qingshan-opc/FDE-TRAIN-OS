# 第 5 节 · 作业（毕业周作业）

## 本周内（毕业后第一周）

1. **第一个动作**：执行 final-review.md 里写的「本周内的第一个动作」，并把结果记进迭代日志；
2. **接真实数据**：把驾驶舱的任一个区块接到你的真实工作数据上——哪怕只是导出的 Excel；
3. **讲一次**：给同事/朋友讲一遍你的驾驶舱（8 分钟答辩结构照样好用），收集一个问题写进迭代日志。

## 30 天检查点

- 回看 final-review.md 的 30 天里程碑：达成 / 偏航 / 调整——写一笔；
- 需要深化哪块，就去对应公开课（O1–O5 回查表在 resources.md）。

## 课程闭环（最后一次提交）

```bash
git add docs/final-review.md
git commit -m "docs: 两周复盘与 90 天路线——课程收官"
```

恭喜你。这门课没有「毕业快乐」的客套——只有一个可回放、可追责、可继续迭代的 Git 仓库，和一个知道自己在行业地图哪里的你。
