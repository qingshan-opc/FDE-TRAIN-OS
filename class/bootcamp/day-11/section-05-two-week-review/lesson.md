# 第 5 节 · 两周复盘：行业地图自评 + 自学路线（15′ · 概念）

> 🎬 视频位（现阶段：口播稿）
> 最后 15 分钟，不看代码。把十天折叠成一张地图，然后告诉你：接下来的路怎么走。

## 教学目标

- 完成两周复盘：从「我以为」到「我知道」的认知清单；
- 在行业地图上标出自己现在的位置：会什么层、缺什么层；
- 产出个人 90 天自学路线：按「下一站」选路，不是按「 hottest 」选路。

## 讲授要点（15′）

| 时段 | 内容 |
|------|------|
| 0–5′ | 认知折叠：「我以为 → 我知道」三对清单 |
| 5–10′ | 行业地图自评：四层 × 三 Skill × 十条证据，标出你的位置 |
| 10–15′ | 90 天自学路线：按下一站选（公开课 O5 的路径表） |

### 认知折叠（写进 final-review.md）

```
十天前我以为这行是＿＿＿，现在我知道它是＿＿＿
十天前我以为 AI 会＿＿＿，现在我知道它会/不会＿＿＿
十天前我遇到问题是＿＿＿，现在我是＿＿＿（定位→假设→验证→记录）
```

### 行业地图自评

对着四层架构图 + 生态图（公开课 O1–O3 的图）给自己标星：

- 前端 / 接口 / 数据库 / 模型层：各打 ✓△✗（对应十条证据的自评）；
- 编排与安全（闸/日志/Skill）：单独一档——这是大多数人的空白，你已经有；
- 标完看一眼：**你的长板在哪层，短板在哪层，一目了然。**

### 90 天路线（按下一站选，呼应 O5）

| 下一站 | 先修 | 路径 |
|--------|------|------|
| 在职提效：把驾驶舱用在真工作上 | 数据接入 + 闸的信任分级 | O2 → O3 |
| 求职转行：作品集 + 面试话术 | 把十条证据翻译成简历语言 | O5 |
| 深入工程：实时、多 Agent、评测 | WebSocket / eval / 多 Agent 协作 | O3 → O2 |
| 独立产品：从驾驶舱到小 SaaS | 用户、部署、计费的最小闭环 | O3 → O5 |

## 🎬 口播稿（约 5 段 · 待审）

> 同学们，最后十五分钟，咱们不看代码。把十天折叠成一张地图：十天前我以为这行是什么，现在我知道它是什么；十天前我以为 AI 会怎样，现在我知道它会什么、不会什么。填进 final-review.md，对吧。
> 然后在行业地图上标你的位置——前端、接口、数据库、模型层各打勾、三角或叉。编排与安全单独一档，闸、日志、Skill，这是大多数人的空白，你已经有。大多数人学完一堆课还是不知道自己在哪，你知道长板短板，这就值，对吧。
> 遇到问题现在怎么干？定位、假设、验证、记录——这套方法比任何单点技巧都管用。十天够入门加方法论加一套真作品，不够精通；精通是接下来九十天的事，咱们别急着一口气吃成胖子，对吧。
> 最后选下一站：在职提效、求职转行、深入工程、还是独立产品。路线表在这，按下一站选，别按 hottest 选。想提效就先接真实数据；想求职就把十条证据翻译成简历语言；想深入工程就 WebSocket 和多 Agent——咱们各走各的路。
> 课到这里就结束了，路才刚开始。你是 FDE 了，去部署的地方见。以后遇到问题，AI 导师配置在每节目录里，方法也在——你已经不需要被领着走了。带走一句：地图在手，下一站自己选，对吧。


## 常见懵点

- 「十天就够了吗？」→ 够「入门 + 方法论 + 一套真作品」；不够「精通」——精通是接下来 90 天的事，路线就是为此设计的；
- 「我应该马上学第二阶段吗？」→ 先用一周把驾驶舱接到真实数据上——用过真数据，你才知道第二阶段该学什么；
- 「以后遇到问题找谁？」→ AI 导师配置就在每节目录里，方法也在：定位→假设→验证→记录——你已经不需要被领着走了。
