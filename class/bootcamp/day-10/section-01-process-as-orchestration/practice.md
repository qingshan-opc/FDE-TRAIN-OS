# 第 1 节 · 练习：业务流程即编排

## 任务

把昨晚的流程草稿画成 Skill 串联图（纸笔或 `docs/orchestration.md`）：

```
[步骤1: 谁干] → 产出什么
      ↓
[步骤2: 谁干] → 产出什么
      ↓
◇ 确认点？（在哪步之前）
      ↓
[步骤3: 谁干] → 产出什么
```

每步标注：① Skill/人；② 输入←谁；③ 可撤回吗。

## 互审（同桌三问）

1. 哪步是确认闸？它后面的步骤为什么不可撤回？
2. 数据流断在哪（哪步的输入没有来源）？
3. 哪步其实该给人而不是给 AI？

## 一键粘贴提示词

> 整段复制给 Cursor / Claude Code / 平台 Agent / 任意 AI 搭档。尖括号 `〈〉` 换成你的路径或名称。

```text
编排教练。把我的部门流程拆成 Skill 串联图 A→B→(确认闸)→C。
每步标注：执行还是判断、输入从哪来、错了能否撤回。不可撤回步前必须留闸位。
输出可写入 docs/orchestration.md 的 Markdown。
```

## 过关标准

- 串联图 3–5 步，每步三标注齐；
- 确认闸位置经得起同桌追问；
- 数据流无断点。
