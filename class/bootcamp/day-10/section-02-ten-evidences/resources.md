# 第 2 节 · 资源：证据整理工具

## 1. 证据一句话公式

```
「这是〈什么〉，它证明我会〈能力〉——〈一个具体细节〉。」
例：「这是 runs/0724.md，它证明我会做可追溯的编排——
     你看 17:15 那条驳回记录，理由和版本号都在。」
```

细节是灵魂：说「你看第几条」，比说「我很重视工程质量」有力十倍。

## 2. 诚实声明模板

```
「〈能力项〉我目前做到〈程度〉，还没做到〈差距〉，
 下一步我打算〈具体学法/时间盒〉。」
例：「实时推送我目前用指令面板降级，还没接 WebSocket，
 下一步我打算用一周时间按公开课 O3 的路径补上。」
```

## 3. 快速补证据的优先级（今晚时间盒内）

1. 答辩要讲的几条（三强必须先齐）；
2. 只差一点就能 ✓ 的 △（性价比最高）；
3. ✗ 且答辩不讲的：写诚实声明，不硬补。
