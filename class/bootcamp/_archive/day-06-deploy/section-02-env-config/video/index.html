02CORE

分家

分家。三件套记牢：`.env` 装本地真值，进 gitignore 永不提交；`.env.example` 装样板——键名加假值加注释，进 Git，别人 clone 下来照着配；线上真值放平台的环境变量面板，网页里配，不是文件。
