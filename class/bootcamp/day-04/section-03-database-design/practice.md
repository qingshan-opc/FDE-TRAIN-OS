## 实操任务（12′）

为「部门周报助手」画三张表的货架卡（照 users 的格式把后两张填完）：

| 列名 | 类型 | 约束 |
|------|------|------|
| id | 整数 | 主键 |
| name | 文本 | 非空 |
| dept | 文本 | 非空 |

**reports**（提示：要回答「谁、哪一周、交了什么、什么时候交的」）

| 列名 | 类型 | 约束 |
|------|------|------|
| | | |

**metrics**（提示：驾驶舱上的「提交率」卡片直接读这张表）

| 列名 | 类型 | 约束 |
|------|------|------|
| | | |

然后回答三问：

1. reports 表里哪一列是外键？它指向谁？
2. 「查张三第 30 周交了没」会用到哪几列？值得为它们建索引吗？
3. 主管要删一个已离职同事——他的周报记录该不该一起删？说出你的选择和理由（无标准答案，言之成理即可）。
