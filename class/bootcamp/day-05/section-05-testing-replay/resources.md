# 第 5 节 · 资源、工具与资料

| 名称 | 路径 | 用途 |
|---|---|---|

## 名词解释

| 名词 | 小白解释 |
|---|---|
| 变更影响 | 本次修改可能直接或间接影响的功能和数据 |
| 复测 | 按原失败步骤再次执行，确认缺陷是否消失 |
| 回归 | 检查修复是否破坏相关原有功能 |
| 发布闸门 | 版本交给运维前必须满足的测试条件 |

## 迭代测试最小覆盖

1. 服务能够启动并通过健康检查；
2. 新交互的四种页面状态；
3. 成功请求和至少一个错误请求；
4. 产品业务规则；
5. 数据保存与重启；
6. 受影响的原有主流程；
7. 缺陷复测与相关回归。
