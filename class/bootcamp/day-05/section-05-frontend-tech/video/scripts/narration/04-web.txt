先说 Web。网页从两千年左右的静态店铺页，发展到今天的强交互——你搜一下，后端算一下，再把结果渲染给你看。地基还是三件套：HTML 骨架、CSS 皮肤、JavaScript 肌肉。框架呢，就是预制装修套件。React——人最多、生态最大、AI 最会写，大型项目常用，也推荐大家优先熟悉。Vue——尤雨溪做出来的，中小型、单体应用很合适，企业小系统、大屏都行。Angular——新项目少一些、上手偏重，但大企业存量还在，别人说我们是 Angular你要听得懂。另外还有 Svelte；以及 React 再加服务端渲染的 Next.js——官网、内容站、电商很常见。小页面呢，不用框架完全够用，你们 第三天 的 index.html 就是。
