# 第 5 节 · 实操任务

## 本节任务

进行最终演示、口述答辩和第二周交接检查。

**指挥对象**：@项目经理 Agent + 学员演示

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@项目经理 Agent 请主持第一周最终验收。一次只让我完成一项：运行项目、演示完整业务流程、讲清七岗位交接、展示一次纠偏和一次问题修复、说明第二周 AI 从哪里接入。按我的真实表现记录结果和遗留问题，不要替我判定通过。
```

## 学员验收清单

- [ ] 项目能按 README 本地运行
- [ ] 业务链路可重复演示
- [ ] 五天主要证据文件齐全
- [ ] 学员能讲清各层和各岗位
- [ ] AI 边界与第二周接入点明确
- [ ] 未通过项有补救计划

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
