# 提示词 03a · 定义 SKILL.md（D7 · 第 4 节）

> 整份粘贴。本节 **只定稿说明书**，先不要写扫描器 / 运行器。

---

请在本仓库 **只创建 1 个真实业务 Skill 的说明书**（用你现有业务数据，禁止空洞 demo）。

## 交付

创建目录与文件：

```text
skills/<id>/SKILL.md
```

`SKILL.md` 必须包含：

1. YAML frontmatter：`name`、`description`（description 要写清「何时用 / 何时不用」）
2. 正文四部件：
   - **输入**：字段、来源（具体 API 路径或文件）、范围
   - **步骤**：可照做的动词序列（禁止「适当分析」等模糊词）
   - **输出**：产物格式与存放路径
   - **验收**：≥3 条可判对错的标准

## 硬约束

- 输入必须绑到学员自己的业务数据（本机 API 或导出 JSON），不要假数据故事。
- 本节 **不要** 实现扫描器、tool、HTTP API；下一节再做加载与 run。
- 定稿后列出：Skill 名称、输入从哪来、验收三条原文。

## 验收

- `skills/<id>/SKILL.md` 存在且四部件齐全
- 换一个人只看说明书，能说出输入从哪拿、怎么判对错
