# 第 2 节 · 实操任务

## 本节任务

按原型实现提交页，并亲手尝试留空、越界和正常提交。

**指挥对象**：@前端工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@前端工程师 Agent 请按已批准的页面样稿做好提交页。填写错误时要用普通员工能看懂的中文提醒。请边做边告诉我每个输入项从哪条需求来；完成后带我分别试一次正常填写和错误填写，等我批准。
```

## 学员验收清单

- [ ] 字段与 PRD 逐项一致
- [ ] 必填和边界校验真实生效
- [ ] 提示语为中文业务语言
- [ ] 正常输入能够提交到当前 Mock 数据层

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
