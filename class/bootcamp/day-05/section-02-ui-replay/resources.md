# 第 2 节 · 资源、工具与资料

## 资源

| 名称 | 路径 | 用途 |
|---|---|---|
| UI 智能体 | `/course-assets/bootcamp/day-01/agent-prompts/02-ui.md` | 交互翻译与状态补齐 |

| 原页面 | 现有项目运行页面 | 保持视觉与操作一致性 |

## 名词解释

| 名词 | 小白解释 |
|---|---|
| 交互流程 | 用户从进入页面到完成目标的动作与反馈顺序 |
| 页面状态 | 页面在加载、空数据、成功或失败时的样子 |
| 文字线框 | 不画精美视觉，只用文字说明区域、字段和动作 |
| UI 交接 | 前端开工所需的元素、行为、状态和文案合同 |

## 四状态检查卡

| 状态 | 必须回答的问题 |
|---|---|
| 加载 | 用户怎样知道系统正在处理？ |
| 空数据 | 没有结果时告诉用户什么？ |
| 成功 | 结果、数量和下一步怎样显示？ |
| 错误 | 原因、恢复动作和重试入口在哪里？ |
