## 发送类 Skill 模板片段

```markdown
# Skill: 周报发送

## 工具描述
- 名称：send-weekly-report
- 何时用：人工确认通过周报草稿后，将其发送到指定群/收件人
- 不用于：未经确认的自动发送、群发营销内容
- 输入要求：确认通过的草稿 + 批准记录；缺任一项拒绝执行

## 步骤
1. 检查是否存在本次运行的人工批准记录——没有则停止并说明
2. 读取确认通过的草稿版本（不是最新未确认版！）
3. 发送到指定目标
4. 在执行日志记录：时间/目标/版本

## 边界与异常
- 未收到批准：不执行，保持等待
- 草稿与批准版本不一致：停止并告警（防「批完又改」）
```

