## 口试自答（3′）

不看课件，在草稿纸上各写一句话：

1. 确认闸三问：看什么 / 谁来看 / 多久看一次；
2. 三反模式：信息不足 / 频率麻木 / 无痕可追——你的设计各怎么破；
3. 信任分级路径：每次都看 → 连续 N 次通过 → 抽看 1/3 → 抽看 + 定期审计。

写完对照第 2 节 lesson 自批，错一处回去重看对应段落。
