## 工具描述反例 vs 正例

| 反例（宽） | 正例（有护栏） |
|-----------|---------------|
| 「生成报告」 | 「生成本周运营周报，输入为 KPI+异常 JSON；不用于通用写作与对外发送」 |
| 「处理数据」 | 「整理本周线索并按规则打分；不用于修改原始数据」 |

## 描述调试速查

| Agent 表现 | 描述问题 | 修法 |
|-----------|---------|------|
| 该调不调 | 「何时用」太窄/太专业 | 加同义场景（周报/周总结/weekly） |
| 不该调乱调 | 缺「不用于」 | 补护栏，列出易误场景 |
| 调了但输入错 | 输入要求不清 | 写明格式与缺数据行为 |
| 在多个工具间犹豫 | 描述与别的工具重叠 | 划清边界（各自的「不用于」） |
