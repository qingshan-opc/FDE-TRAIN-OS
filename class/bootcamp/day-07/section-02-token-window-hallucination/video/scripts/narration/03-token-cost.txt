Token 为什么重要？两件事：钱，和注意力。API 一般按输入加输出一起计费——你问得多、它答得长，都花钱。你往 Cursor 里贴整个代码仓库、整份 PRD，表面是「让它看全」，实质是在烧 Token，还可能把关键约束淹没在垃圾堆里。打个比方：Token 像手机流量，不是你数了多少字，是套餐按块扣的。所以啊，写 Prompt 省钱不是抠门，是工程习惯：废话清掉、同一段别贴三遍、格式写清。有同学可能会说：贵就贵一点呗。训练营可以；企业里对话一长、并发一高，账单会咬人。听见了吗？下一页讲「流量」之外还有「套餐总上限」——窗口。作业感一句：下次贴材料前，先问「这段是不是得看见」。企业里还有并发：一百人同时问，账单是乘上去的，所以省 Token 是基本功。
