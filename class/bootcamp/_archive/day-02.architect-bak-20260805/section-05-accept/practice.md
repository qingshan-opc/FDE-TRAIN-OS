# 第 5 节 · 实操任务

## 本节任务

完成驾驶舱，亲手走查四页并至少写两条修复单。

**指挥对象**：@前端工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@前端工程师 Agent 请完成驾驶舱，让数字和分类情况都从现有演示记录算出来。然后带我按“提交—列表—详情—驾驶舱”走一遍，把发现的问题记进前端检查表并逐项修复。全部完成后自检，停下来等我批准。
```

## 学员验收清单

- [ ] 四页可互相到达
- [ ] 看板指标与选题一致
- [ ] 统计 Mock 服从契约
- [ ] 走查至少记录两项真实问题或明确的验证证据
- [ ] 修复后由学员复验并批准 V0.5

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
