# 第 3 节 · 概念：Agent 与 Harness 解剖（20′ · 概念）

> 🎬 视频位（现阶段：口播稿 + 讲解图）
> 快答开场（昨晚预习）：Harness 四要素。然后掀引擎盖——你这两天做的事，到底是在给谁打工？

## 教学目标

- 背下 Harness 四要素：**模型 + 工具表 + 记忆 + 循环**（骨架）；
- 理解 Agent = 跑在骨架上的角色（说明书/人格/目标）；
- 看懂决策环：理解 → 规划 → 调工具 → 观察 → 继续；
- 分清 workflow vs agent：固定流程 vs 自主决策。

### Harness 四要素（全是老熟人）

| 要素 | 管什么 | 你已经做过的对应物 |
|------|--------|------------------|
| 模型 | 思考的大脑 | Day 5 网关后的 LLM |
| 工具表 | 能动手做什么 | Day 7 的 Skill（马上就是） |
| 记忆 | 上下文里带什么 | Day 5 上下文装配 |
| 循环 | 反复「想-做-看」 | 你的迭代闭环（人工版） |

**Agent = Harness（骨架）+ 角色（你的说明书/人格/目标）**。你写的 Skill，就是给它预备的工具；你写的 ai-tutor.yaml，其实就是一份 Agent 角色定义——你早就在造 Agent 了。

### 决策环（一次循环）

```
理解任务 → 规划步骤 → 选择并调用工具 → 观察结果 → 继续/收尾
     ↑______________________________________________|
```

### workflow vs agent（什么时候用哪个）

| | workflow | agent |
|---|---------|-------|
| 步骤 | 你定死（Day 9 编排） | 它现想（决策环） |
| 适合 | 步骤稳定、要可预测 | 路径多样、要灵活 |
| 风险 | 低（所见即所得） | 高（可能选错工具/走弯路） |
| 例子 | 拉数据→生成周报→给你看 | 「帮我看看这周经营上有什么值得注意的」 |

> Day 9 学 workflow，今天先见 agent。**能 workflow 的别 agent**——可预测性是企业场景的第一美德。

> 收个尾：Agent 决策，Harness 骨架，Skill 是工具。下一节把你的 Skill 挂上 Agent 的工具表——从今天起，你派活用自然语言，挑工具的活 Agent 自己干，对吧。


## 常见懵点

- 「Agent 和聊天机器人什么区别？」→ 聊天机器人只有模型；Agent 有工具表和循环——能动手、能分多步；
- 「Agent 会自己写 Skill 吗？」→ 高级形态会（公开课 O2）；今天它调用你写的；
- 「决策环会不会死循环？」→ 会，所以工程上要设最大轮数/超时（第 4 节会看到平台的护栏）；
- 「harness 这个词到底怎么理解？」→ 马具/骨架：马（模型）狂奔，harness 让它拉车——工具、记忆、循环都是「套具」。
