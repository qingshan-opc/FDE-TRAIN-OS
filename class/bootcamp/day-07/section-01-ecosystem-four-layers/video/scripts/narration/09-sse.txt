很多同学会问：API 和 SSE 啥关系？别对立——SSE 不是另一家供应商，是 API 的一种返回方式。一次性响应：你发出去，干等，整包 JSON 回来再渲染——像寄信，等回信全文。SSE，Server-Sent Events：服务端按 Token 一段段推，浏览器边收边显示——像打电话，对方一句句说。ChatGPT 那种「字一个个蹦出来」，多半就是流式加 SSE。驾驶舱助手位、摘要预览，本课建议 SSE：体感快、能显示生成中、断了能重试。WebSocket 是双向长连，聊天流多数用不上，先别绕。有同学可能会说：那我把 Key 写进网页？绝不——密钥放后端或环境变量。来，对照屏幕：API 负责「打到哪」；SSE 负责「怎么流回来」。本节练习会丢给你一段提示词：接入 DeepSeek-flash，采用 SSE——让 Agent 帮你改到跑通，对吧。
