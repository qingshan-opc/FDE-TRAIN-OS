# 第 3 节 · 实操任务

## 本节任务

用实际请求演示提交一条、查询它、打开详情并看到统计变化。

**指挥对象**：@后端工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@后端工程师 Agent 请按已批准的数据约定，打通提交、列表、详情和驾驶舱统计。请分四步完成，每一步先告诉我数据怎样走，再用真实操作证明。最后演示“提交一条—查到它—驾驶舱数字变化”，把证据留下并等我批准。
```

## 学员验收清单

- [ ] 四个接口与契约一致
- [ ] 非法输入被后端拒绝
- [ ] 数据真实写入 SQLite
- [ ] 统计与记录可核对
- [ ] 验证文档含真实请求响应

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
