# 第 3 节 · 实操任务

## 本节任务

学员按缺陷归属逐条派单，并亲手复测。

**指挥对象**：@责任工程师

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@测试工程师 Agent 请根据我选中的问题，先用大白话告诉我应该交给前端还是后端，再生成一句能直接复制的修复任务。等我把修复结果带回来后，请带我重新检查；不要替开发岗位修改程序，也不要提前写“复查通过”。
```

## 学员验收清单

- [ ] 每张修复单四要素齐全
- [ ] 派给正确责任岗位
- [ ] 学员复测失败用例和至少一条相关用例
- [ ] 根因和修改范围写入记录

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
