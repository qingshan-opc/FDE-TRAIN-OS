# 第 4 节 · 练习

## 知识确认（3′）

1. 用骨架 / 皮肤 / 肌肉分别指认 HTML、CSS、JavaScript。
2. 各用一句话说出 React 和 Vue 最大的卖点。
3. 「怎么选四问」按顺序背出来。

## 实操任务（8′）

**「给三个场景选武器」**：为下面三个场景各选一个前端方案（可以是「不用框架」），并用四问中的一到两问说明理由：
1. 市场部下周要一个活动报名页，就用一次；
2. 公司要做一个三十个页面的内部管理系统，前端只有一位会 Vue 的实习生；
3. 你要做一个长期打磨、准备对外发布的 AI 写作工具，团队还没招人。

## 一键粘贴提示词

> 整段复制给 Cursor / Claude Code / 平台 Agent / 任意 AI 搭档。尖括号 `〈〉` 换成你的路径或名称。

```text
做前端技术地图填空：我的驾驶舱触点是 Web；备选框架 2 个；用四问（用户在哪/商店?/团队会什么/AI 熟不熟）选出一个并写不选理由。
```

## 完成标志

- 三件套比喻能完整复述
- 五个选项（含「不用框架」）各能说一句画像
- 三个场景的选择都有「四问」依据，不是拍脑袋
