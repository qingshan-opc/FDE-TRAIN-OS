# 第 2 节 · 提交与验证

## 提交文件

- `day5-replay/iteration-ui-spec.md`
- `day5-replay/ui-handoff.md`

## 通过条件

- 页面改动没有超出迭代 PRD；
- 输入、显示字段、动作和反馈明确；
- 加载、空数据、成功和错误状态齐全；
- 每条关键交互能对应产品验收标准；
- 交接文件明确下一棒是 `@前端`；
- 学员本人已经回复“确认原型”。

## 不通过时回到哪里

- 需求冲突：退回 `@产品经理`；
- 页面状态缺失：留在 `@UI` 补齐；
- 需要新业务规则：退回 `@产品经理` 确认，不让 UI 自行决定。
