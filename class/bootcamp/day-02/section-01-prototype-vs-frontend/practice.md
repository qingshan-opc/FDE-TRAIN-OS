# 第 1 节 · 练习

## 知识确认

1. UI 原型和正式前端分别解决什么问题？
2. AI 能生成页面后，前端岗位为什么仍然重要？
3. 需求、设计或接口信息缺失时，前端分别应回到哪个岗位？

## 本地观察

打开 Day1 的 `ui-prototype.html`，只观察不修改：

- 它是否只有一个文件；
- 页面使用的是演示数据还是真实数据；
- 是否能看出加载、空数据和错误状态；
- 是否能看出未来后端数据应该从哪里进入。

把观察结果写成四行，保存为 `day2-observation.md`。

## 提交验证

- 能用自己的话解释“原型验证方向，前端承担运行”；
- 能指出至少一个原型仍需工程化的地方；
- 没有直接修改 Day1 已验收的 UI 文件。
