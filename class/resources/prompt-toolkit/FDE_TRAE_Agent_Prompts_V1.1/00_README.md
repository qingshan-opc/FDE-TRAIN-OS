# FDE TRAE 软件团队 Agent 提示词包 V1.1（小白互动版）

本版本服务于零基础学员的 Week 1 实战：学员亲自组建、指挥和验收 AI 软件团队，在 5 天内完成一个可运行的桌面 Web MVP。

本版把专业标准放进岗位内部，让学员只需用一句大白话指挥团队。重点规则如下：

- 每个 Agent 身份固定，禁止自行切换岗位；
- 上游未明确批准时，下游不得开工，不能把“继续做下一步”理解成批准；
- 学员可用一句自然语言下达任务，由 Agent 自己整理任务和专业要求；
- Agent 先用大白话复述目标，一次只问一个问题，不能把技术选择题丢给小白；
- 学员答不上来时，Agent 给 2—3 个具体选项、说明区别并推荐一个；
- Agent 分步完成并带学员亲手检查，让学员看到产品是怎样形成的；
- 非关键缺失采用最小可逆假设继续，只有影响范围、安全或数据的事项才阻塞；
- UI 阶段必须产出可点击高保真原型，不能只交文字规范；
- 前端 Mock、后端接口、前后端真实联调是三个不同状态；
- QA 发现前端仍在使用 Mock 时，必须判定系统联调测试 `BLOCKED`；
- 默认只做桌面 Web，不做手机端、登录权限、Docker 和复杂企业基础设施；
- 每个岗位完成后必须自检，并给出供学员复制的下一岗位提示词，但不得自动执行。

## Week 1 默认项目骨架

除非已批准的 PRD 明确修改，默认项目范围为：

1. 驾驶舱看板；
2. 表单提交页；
3. 列表页；
4. 详情页（保留“AI 分析区｜Week2 接入”）；
5. Week 1 数据链路：提交 → SQLite → 列表 → 详情 → 驾驶舱统计；
6. Day 2 使用 Mock，Day 3 切换真实接口；
7. 技术栈：Next.js + TypeScript + Tailwind CSS；
8. 桌面 Chrome 验收，基准宽度 1280px；
9. AI 分析接口只预留契约或诚实返回“Week2 未接入”，不得在 Week 1 伪造真实 AI 结果；
10. 默认不做手机端、登录、注册、复杂权限、Docker、CI/CD、多环境和生产级高可用。

## TRAE 使用方法

1. 在 TRAE 中分别创建 7 个自定义 Agent；
2. 将对应岗位文件中“完整提示词”复制到该 Agent；
3. 学员通过 `@岗位名 + 一句话任务` 下达指令，不用填写技术任务单；
4. Agent 先复述、一次问一个问题，再分步完成并带学员检查；
5. Agent 交付“待检查”后，只有学员明确回复“批准”，才可记录批准；
6. Agent 输出下一岗位的一句话任务后停止，学员亲自复制并 `@下一岗位`；
7. 任何 Agent 都不得冒充下一岗位继续工作。
