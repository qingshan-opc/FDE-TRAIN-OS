# 第 5 节 · 实操任务

## 本节任务

将已批准 PRD 交给 UI/UX，逐页点击验收并至少下达一条定向纠偏。

**指挥对象**：@UI/UX 设计师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@UI/UX 设计师 Agent 请读已批准的需求，把驾驶舱、提交、列表、详情做成能打开、能点击的页面样稿。请一页一页完成并带我点击检查。AI 区要先写“第二周接入”和“演示数据”，再画按钮。最后自检并等我批准。
```

## 学员验收清单

- [ ] 四页均可从 index.html 打开并互相跳转
- [ ] 提交后能在原型列表中看到记录，用于验证流程
- [ ] 字段、状态与 PRD 一致
- [ ] AI 区的 Week2 和演示数据标识清楚
- [ ] 至少完成一轮具体纠偏后再批准

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
