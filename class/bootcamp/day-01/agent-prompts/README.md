# Day 1 · TRAE 六岗位智能体提示词

## 创建顺序

1. 产品经理：`01-product-manager.md`
2. UI：`02-ui.md`
3. 前端：`03-frontend.md`
4. 后端：`04-backend.md`
5. 测试：`05-testing.md`
6. 运维：`06-operations.md`

## 使用方法

在 TRAE 对话区点击当前 `@Agent`，选择“创建智能体”。名称使用课程规定的中文岗位名，把对应文件中“提示词正文”以下内容完整复制到提示词输入框，关闭“可被其他智能体调用”，然后创建。

创建后通过 `@岗位名称` 手动切换。六岗位之间通过工作区文件交接，不让智能体自动互相调用。

```text
@产品经理 → @UI → @产品经理验收 UI
→ @前端 → @后端 → @测试
→ 不通过退回责任岗位 → @测试复测
→ @运维 → @产品经理最终验收
```
