# 第 3 节 · 实操任务

## 本节任务

让运维工程师按现状整理本地交付，并由学员模拟新接手者验证。

**指挥对象**：@运维工程师 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@运维工程师 Agent 请带我像一个第一次接触项目的人那样，从零在本地运行它。一次只给我一个动作，先解释这一步做什么、成功后会看到什么。把真实结果和常见错误整理成本地交付检查；不要做公网发布，也不要写“已上线”。
```

## 学员验收清单

- [ ] 运行步骤从空环境假设写起
- [ ] 前后端启动和端口明确
- [ ] SQLite 位置和数据保留方式明确
- [ ] 学员按说明重新跑通
- [ ] 状态没有夸大为上线

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
