自测

6 题快速确认

Day 1 第 7 节抽测范围。点「看提示」对照自己的复述，别先偷看。

1. 幻觉为什么「不是 bug 是机制」？

模型永远在给「最像真的」的答案，不是「经过核实」的答案——幻觉来自预测机制本身。

2. 同一个模型，为什么在 Agent 工具里比在聊天窗里「更能干」？

差在 Harness：模型 + 工具表 + 记忆 + 循环——骨架不同，不是模型突然变聪明了。

3. RAG 解决什么问题？怎么解决的？

治幻觉的主流药方之一：先检索相关片段，再让模型基于片段回答。

4. Workflow 和 Agent 怎么选？

能写死就写 Workflow；写不死、要现场决策，才上 Agent。

5. 上下文工程：食材放少了和放多了各会怎样？

给少了它瞎编；给多了它迷失——决定「这次调用放什么进视野」。

6. Eval 和「我觉得还行」的区别？

Eval = 固定题库 + 明确判分；感觉无法复现、无法验收。
