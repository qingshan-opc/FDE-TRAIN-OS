# 第 4 节 · 缺陷与复测模板

```markdown
## BUG-001 · 提交后数据消失
- 严重程度：阻塞
- 主要责任岗位：后端
- 复现步骤：启动 → 提交记录 → 重启 → 查询
- 预期结果：记录仍然存在
- 实际结果：查询结果为空
- 证据：test-evidence/TC-008/
- 建议方向：检查写入与事务提交
- 复测结果：待复测
```

## 生命周期

```text
发现 → 归责 → 确认范围 → 修复
→ 原步骤复测 → 相关回归 → 关闭
```

## 严重程度

- 阻塞：系统不能运行、核心流程中断、数据或安全风险；
- 严重：重要功能错误但存在临时绕行；
- 一般：次要功能或反馈问题；
- 建议：不影响当前验收的改进项。
