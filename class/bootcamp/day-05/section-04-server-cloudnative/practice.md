# 第 4 节 · 实操任务

## 本节任务

完善三份交付文档，内容由学员提供，Agent 只负责结构和校对。

**指挥对象**：通用对话

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@项目经理 Agent 请先读项目和检查结果，再带我完成使用说明、项目复盘和五分钟讲解提纲。三件事一次做一件，每件先问我一个问题再整理。讲解要从业务价值开始，用一条真实记录证明系统能用，并诚实说明 AI 要到第二周才接入。
```

## 学员验收清单

- [ ] README 四部分齐全且按步骤可运行
- [ ] 限制与未完成项真实
- [ ] 复盘包含具体数字或事件
- [ ] 路演能在五分钟内讲清价值、证据和边界

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
