# 第 5 节 · 本地实操

在 QRAE 中切换到 `@测试`。测试岗位只记录与验证，不直接修改代码。

## 第 1 段 · 读取变更与风险

```text
请读取 iteration-prd.md、ui-handoff.md、frontend-handoff.md、iteration-api-spec.md 和 backend-handoff.md。
只列新增能力、受影响原功能和前三项风险。
输出后停止。
```

## 第 2 段 · 生成测试计划

```text
请生成 day5-replay/iteration-test-plan.md。
覆盖启动、健康、页面四状态、成功与错误请求、业务规则、数据持久化和受影响回归。
每条写操作步骤、预期结果和证据位置。
保存后停止，等我回复“确认测试”。
```

## 第 3 段 · 逐条执行

```text
已确认。一次只给我一条测试操作和预期结果。
等我反馈实际结果与证据后再继续。
不得想象执行结果，不得在测试岗位修改代码。
```

## 第 4 段 · 缺陷闭环

```text
失败时生成 iteration-defect-log.md，并指定一个主要责任岗位。
告诉我切换到哪个岗位完成修复。
修复后回到 @测试，按原步骤复测并执行相关回归。
```

## 第 5 段 · 测试报告

```text
请生成 day5-replay/iteration-test-report.md。
写明环境、范围、结果、缺陷、复测、回归、限制、风险和是否建议发布。
保存后停止，不要自动切换到运维。
```
