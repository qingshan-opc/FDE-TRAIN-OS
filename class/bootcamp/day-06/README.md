## 这一天在解决什么

前四天你手里已经有了真东西：PRD、架构决策、高保真原型、接口与数据库设计。
问题是你可能「会做但说不清」——周五晚上别人问你「这一周学了什么」，你只能掏出几个文件。

理论课为什么放在周六而不是第一天？**先有体感，再给名字。**
第一天就讲云原生和技术地图，你一个字也记不住；现在每一个理论你都能指着工作区里的文件说「哦，原来这个就是」。

今天的节奏：每节讲清一块地图；第 4 节当场在仿真终端把命令行八句敲一遍。
**不再单开一节「验收课」**——概念靠节内知识确认与 Day 快测卡住，收束靠企业任务：对着自己的项目手绘一张技术架构图。
