# 第 1 节 · 本地实操

## 开始前

打开前四天完成的项目，并在 QRAE 中选择 `@产品经理`。不要新建第二个大项目。

## 第 1 段 · 读取第一版证据

```text
请只读取第一版 PRD、测试报告、部署说明和最终验收。
用五句话复述当前用户、已解决问题、核心流程、已知限制和发布状态。
现在不要修改任何文件。输出后停止。
```

## 第 2 段 · 选择微迭代

```text
请结合我的专业领域，一次只问一个问题。
帮助我选择一项当天可以完成的真实改进。
先给三个不同方向的例子，再等我选择。
确认后把 Day5 新文件统一放入 day5-replay。
```

## 第 3 段 · 逐题访谈

```text
围绕目标用户、使用场景、当前困难、期望动作、成功结果和不做范围逐题访谈。
每次只问一题，并给一个容易理解的示例。
等我回答后再继续，不要一次抛出整张问卷。
```

## 第 4 段 · 生成产品交付

```text
请生成 day5-replay/iteration-prd.md 和 pm-handoff.md。
写清用户故事、范围、不做范围、业务规则、页面状态和可判断的验收标准。
列出交给 UI 的输入文件和待确认问题。
保存后停止，等我回复“确认需求”。
```

## 学员检查

- 这项改进能否在当天完成？
- 每条验收标准能否明确判断通过或失败？
- 是否写清本轮不做什么？
- 是否没有覆盖第一版文件？

全部通过后回复：`确认需求`。
