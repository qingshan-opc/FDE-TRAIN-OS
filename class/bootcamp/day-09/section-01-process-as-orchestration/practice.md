# 第 1 节 · 练习：流程拆解图（随堂 8′）

## 任务

把昨晚的流程草稿画成 Skill 串联图（纸笔或 `docs/orchestration.md`）：

```
[步骤1: 谁干] → 产出什么
      ↓
[步骤2: 谁干] → 产出什么
      ↓
◇ 确认点？（在哪步之前）
      ↓
[步骤3: 谁干] → 产出什么
```

每步标注：① Skill/人；② 输入←谁；③ 可撤回吗。

## 互审（同桌三问）

1. 哪步是确认闸？它后面的步骤为什么不可撤回？
2. 数据流断在哪（哪步的输入没有来源）？
3. 哪步其实该给人而不是给 AI？

## 过关标准

- 串联图 3–5 步，每步三标注齐；
- 确认闸位置经得起同桌追问；
- 数据流无断点。
