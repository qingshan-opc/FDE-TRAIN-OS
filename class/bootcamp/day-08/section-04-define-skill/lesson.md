# 第 4 节 · 写好技能说明书（30′ · 实战）

> 🎬 视频位（现阶段：口播稿）
> 开写。30 分钟后，`skills/` 目录里要有你的第一份说明书——四部件齐全，验收可判。

## 教学目标

- 按模板写出 Skill 说明书 v1：输入/步骤/输出/验收；
- 掌握写作手法：步骤写动作、验收写判据、模糊词当场消灭；
- 通过「换人测试」：同桌只看说明书，能说出要做什么、怎么判好坏。

## 流程安排（30′）

| 时段 | 内容 |
|------|------|
| 0–5′ | 写法讲解：动作动词库 + 判据句式库 |
| 5–20′ | 写作冲刺：四部件逐段写（导师巡场，模糊词当场划） |
| 20–27′ | 换人测试：同桌互读互问，改到无歧义 |
| 27–30′ | 定稿进 Git，预演第 5 节运行 |

## 动作动词库（步骤段用）

```
拉取 / 筛选 / 对比 / 汇总 / 排序 / 找出 / 计算 / 生成 / 检查 / 列出
```

🚫 禁用：分析、处理、优化、整理一下、研究研究——这些不是动作，是愿望。

## 判据句式库（验收段用）

```
结构判据：「X 段齐全」「含字段 A/B/C」
数字判据：「每个数字能在 <来源> 中找到出处」
意图判据：「当 <情况> 时，必须 <表现>」（Day 5 用例格式直接搬）
```

## 写作冲刺顺序（推荐）

```
① 先写输出（交什么货）→ ② 再写验收（怎么判）→ ③ 再写输入（吃什么料）→ ④ 最后写步骤（怎么从料到货）
```

倒着写的原因：货和判据定了，步骤只是连线题——正着写容易在步骤里迷路。

## 🎬 口播稿（约 6 段 · 待审）

> 同学们，这节开写。三十分钟后，skills/ 目录里要有你的第一份 Skill 说明书——四部件齐全，验收可判，同桌能读懂。写之前咱们先给两个库：动作动词库和判据句式库，对吧。
> 步骤段只许出现动作动词：拉取、筛选、对比、汇总、排序、找出、计算、生成、检查、列出。分析一下处理一下优化一下——这些不是动作，是愿望。我巡场见到就划掉，改写成 AI 能执行的具体动作，嘛。
> 验收段用判据句式：结构判X 段齐全、含字段 A/B/C；数字判每个数字能在来源中找到出处；意图判当某情况时，必须某表现——第一周用例格式直接搬。验收写几条？至少三条，结构、数字、意图各一，对吧。
> 写作顺序听好：倒着写。先写输出——交什么货；再写验收——怎么判；然后输入——吃什么料；最后步骤——从料到货就是连线题。正着写的人，都在步骤里迷路了。输出段贴一个好示例，是最划算的消歧方式，对吧。
> 写完做换人测试：同桌只看你的说明书，说出要做什么、怎么判好坏。他说错了，就是你写岔了——改说明书，不怪他。步骤里能写分支吗？能，但每个分支都要落到动作动词；分支超过三层，说明该拆成两个 Skill，嘛。
> 定稿进 Git，预演下一节运行。带走两个库：动作动词写步骤，判据句式写验收，换人测试消歧义。下一节 AI 拿着你的说明书上岗——派活、收货、按标准验收、留证据，对吧。


## 常见懵点

- 「步骤里能写分支吗（如果…就…）？」→ 能，但每个分支都要落到动作动词；分支超过 3 层，说明该拆成两个 Skill；
- 「验收写几条？」→ ≥3 条，结构/数字/意图至少各一；
- 「说明书里要贴示例吗？」→ 输出段贴一个好示例（Day 5 的 few-shot 手法）——最划算的消歧方式。
