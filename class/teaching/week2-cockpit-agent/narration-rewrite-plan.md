# 第二周 · 口播 / PPT 重做清单（审计用）

> 原则：**先审 `PPT_AND_NARRATION.md`（屏幕要点 + 口播）→ 你点头 → 再渲视频 / 改 HyperFrames。**  
> 分词稿 `video/scripts/narration/*.txt` 与总稿应对齐；本轮先改总稿，分词稿随总稿同步。

## 要不要重做？

**要。** 课纲口径已变，旧口播仍按「周末必做驾驶舱桥接 / 第一周=驾驶舱 / Agent Lab 作业台 / 对照 anycode」在讲，和现课不一致，不能直接出片。

## 新口径（口播必须统一）

1. Week1 = **业务系统**（CRUD）；看板/助手位 = **选做**，不进硬 GATE  
2. 展示 D6 起：在 **同一应用** 里接 LLM → Skill → Loop → HITL → UI  
3. 实操在 **学员自己仓库 + 编码 AI**；不提平台 Lab 作业台、不提 anycode 源码  
4. Skill 日：第4节只写 `SKILL.md`（03a），第5节才加载·运行·证据（03b）  
5. 天数口头：**「第 N 天 / 展示 DN」** 与侧栏一致（文件夹 day-07 = 展示 D6 …）
