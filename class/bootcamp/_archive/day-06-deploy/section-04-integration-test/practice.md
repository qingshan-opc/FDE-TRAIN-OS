# 第 4 节 · 练习：清单全绿冲刺（随堂 20′）

## 任务

1. 把清单模板复制为 `docs/release-checklist.md`，按你的项目补具体值（接口路径、指标名）；
2. 逐项执行，每项记录：✓/✗ + 一句证据（截图编号/命令输出）；
3. 红灯项：诊断 → 修复 → 重测 → 记录修复过程（迭代日志同款格式）；
4. 全绿后，文件末尾写「本次体检结论：可上线」，提交 Git。

## 记录格式

```
| 检查项 | 结果 | 证据 | 备注 |
|--------|------|------|------|
| 六区块渲染 | ✓ | 截图01 | |
| 断网关降级 | ✗→✓ | 截图05 | source 标识未切换，已修 |
```

## 过关标准

- 清单九项全部 ✓（修复后 ✓ 也算，但备注要写清修了什么）；
- 安全项与 Git 项不过 → 一票否决，先处理；
- `docs/release-checklist.md` 进 Git。
