# 第 4 节 · 实操任务

## 本节任务

批准项目任务书后，将它交给产品经理；回答澄清问题并完成一轮定向返工。

**指挥对象**：@产品经理 Agent

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@产品经理 Agent 请读已批准的项目任务书，带我把使用者、使用场景、四个页面和通过标准问清楚。一次只问一个问题；我确认后再写需求文档。写完告诉我“我的哪些回答变成了哪些需求”，带我检查并等我批准。
```

## 学员验收清单

- [ ] 产品经理先提问，学员回答后才写 PRD
- [ ] PRD 六部分齐全且字段与选题一致
- [ ] P0 不超过四项并列出本期不做事项
- [ ] 学员至少修改或否决一项并明确批准 PRD

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
