# 第 5 节 · 实操任务

## 本节任务

指挥前端切换真实 API，学员亲手走完整业务流程并记录证据。

**指挥对象**：@前端工程师 Agent + 学员亲测

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@前端工程师 Agent 请把四个页面从演示数据切换成后端的真实业务数据。先用大白话告诉我哪些地方会改变，确认后再切换。完成后带我亲手走“提交—保存—列表—详情—驾驶舱更新”，记录真实结果；不要只看代码就宣布完成。
```

## 学员验收清单

- [ ] 业务数据不再来自 Mock
- [ ] 提交到看板更新全链路通过
- [ ] 冒烟记录每步有证据
- [ ] AI 边界仍然诚实
- [ ] 发现的问题按契约定位并复验

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
