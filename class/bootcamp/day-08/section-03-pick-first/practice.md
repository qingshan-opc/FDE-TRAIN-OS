# 第 3 节 · 练习：三筛法选题

## 任务

1. 把你的 3 个候选填入打分表，逐项打分；
2. 写出第一名的**胜出理由**（引用三筛原文，禁止「我觉得这个好」）；
3. 写出第二名**落选的原因**（同样引用三筛）；
4. 同桌互审：对方能复述你的理由，且挑不出「低险」漏洞。

## 陈述模板

> 「我的第一个 Skill 是 ____。
> 高频：____（具体频率）；
> 稳定：____（步骤为什么可写成说明书）；
> 低险：____（做错了代价是什么，为什么可控）；
> 数据：输入来自 ____。」

## 一键粘贴提示词（学习教练）
> **学习教练提示词**：用来出题考你、审草稿、模拟评委——**不要**整段丢给 TRAE 当写代码任务。尖括号 `〈〉` 换成你的场景。



```text
候选 3 个可 Skill 化任务（来自我的周报助手）。用「重复频率 / 说明书化难度 / 验收清晰度」打分，选出今天要做的第 1 个，并写一句为什么不选另外两个。
```

## 过关标准

- 打分表无空格；
- 胜出理由与落选原因都引用三筛；
- 「低险」一栏经得住同桌追问（「做错了会怎样？」）。
