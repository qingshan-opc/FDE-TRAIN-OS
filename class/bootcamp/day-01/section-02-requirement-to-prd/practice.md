# 第 2 节 · 实操任务

## 本节任务

按课程提示词包逐个创建七个 Agent，并填写每个岗位的输入、输出和不能替你做什么。

**指挥对象**：TRAE 手动操作 + 通用对话

## 一键粘贴提示词

> 将 `〈〉` 中的内容换成你的项目实际信息。Agent 交付后先验收，不要直接让它继续下一岗位。

```text
@项目经理 Agent 请带我认识刚组建的七个岗位。一次只讲一个岗位，用大白话问我“它接谁的工作、交付给谁、不能替我做什么”。我答错时请解释；最后整理成团队协作卡，等我检查。
```

## 学员验收清单

- [ ] 七个 Agent 均能在 TRAE 中被 @ 到
- [ ] 至少完整读过项目经理、产品经理和 UI/UX 三份岗位提示词
- [ ] 团队协作卡写清七个岗位的输入、输出与边界
- [ ] 能解释 REVIEW 和 APPROVED 的区别

## 纠偏句式

```text
@〈责任岗位〉 我没有批准当前交付。具体问题是：〈哪里不对〉；请改成：〈可判断的目标〉。
修改后请重新执行〈验证动作〉，列出实际文件与证据，并以 REVIEW 状态交付。不要继续下一岗位。
```

## 完成标志

- 学员亲自检查完上方清单并保留真实证据；
- 至少能指出一个判断依据，而不是只复述 Agent 的总结；
- 交付先停在 REVIEW，只有学员明确回复 APPROVED 才进入下一步。
