03PRIMARY · MySQL / PG / SQLite

主库怎么点单

常规业务主库最常听到两个；原型再加一个文件库。

Legacy / 团队惯性 MySQL 用得最广的老牌。接老系统、全是 MySQL 老手时稳。
2026 默认 PostgreSQL 功能全、扩展强；向量插件做 AI 相似推荐顺手。
Prototype SQLite 一个文件就是库。小工具起步；人多再迁 PG。
新项目 → PG 老系统 → MySQL 两周原型 → SQLite

04SQL FAMILY · 跟库说话

DDL / DQL / DML

名字别被吓到——三类动作：改结构、查数据、改数据。

DDL

定义结构

建表、改表——房子怎么隔间。

DQL

查询

把符合条件的数据捞出来。

DML

增删改

往房子里放、拿、改东西。

本质：约定怎么存、怎么取 别的库有自己的 API
05LANGUAGES · 四大路线

语言选边，框架是招牌

Enterprise

Java · Spring Boot

大厂标配。银行电信核心系统主场；规矩全、能扛大场面。

AI Native

Python · FastAPI

AI 的母语。开发快，自动出 OpenAPI——和 API_Spec 天生一对。

Fullstack

Node · Express / Nest

前后端一门语言。小团队、全栈一条顺路。

Infra

Go · Gin（+ Rust）

快和省。网关、中间件；更底层常听到 Rust。

06DECISION · 三句话选型

怎么选：三句话

01

AI 项目 → Python + FastAPI

模型生态在这，起手快。

02

企业长期系统 → Java + Spring Boot

要打通既有系统、要招得长期维护的人。

03

小工具验证 → FastAPI 或 Node

三天能跑起来比什么都重要。库：SQLite → PG → Redis。
