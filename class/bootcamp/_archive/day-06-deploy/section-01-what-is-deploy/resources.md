## 托管平台速查（本课默认）

| 概念 | 你需要知道的 |
|------|-------------|
| 连接 Git 仓库 | 平台监听你的 push，自动跑管线 |
| 构建命令 | 通常是 `pip install -r requirements.txt`（平台多数能自动识别） |
| 启动命令 | `uvicorn main:app --host 0.0.0.0 --port $PORT` |
| 环境变量面板 | 网页上配置，不进代码——第 2 节的主角 |

> `--host 0.0.0.0` 的意思：接受来自任何机器的请求（localhost 只接受本机）——上云必需。
