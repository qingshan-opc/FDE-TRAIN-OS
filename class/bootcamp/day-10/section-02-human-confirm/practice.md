# 第 2 节 · 练习：人工确认与日志

## 任务一：设计你的闸（4′）

为你的流水线确认闸填写设计卡：

```
确认闸位置：在 ____（步骤）之前
① 看什么：____（列 3–5 项：草稿？关键数字？风险标红？）
② 谁来看：____
③ 看多久一次：新上线 ____ → 信任升级路径：____
驳回时怎么办：____（打回哪一步？记什么？）
```

## 任务二：找茬（3′）

下面三个确认闸设计各有问题，指出并改：

1. 确认界面：「AI 已完成处理，确认继续？[确定]」；
2. 每 10 分钟弹一次确认，一天 40 次；
3. 批准和驳回都不留记录，「反正大家互相信任」。

## 一键粘贴提示词

> 整段复制给 TRAE。尖括号 `〈〉` 换成你的路径或名称。

```text
确认闸设计卡：看什么 / 谁来看 / 多久看一次。
为我的「发送/改数」步骤写确认界面最低信息：草稿 + 关键数字 + 风险标红。
再写信任分级：什么条件下可以从每次看降到抽看。
```

## 过关标准

- 设计卡五格填完，「看什么」含具体信息项；
- 找茬三题各说出「死法 + 修法」（对应三个反模式）。
