# 第 1 节 · 练习：异常归类（随堂 6′）

## 任务

六个场景，各答：属于哪类异常（输入错/环境错/能力限/目标歧）？Skill 该怎么表现？

1. 运行周报 Skill，但本周异常工单表是空的；
2. 运行中驾驶舱接口超时；
3. 老板说：「周报顺便抄送给客户」；
4. 输入的日期范围跨了两个月；
5. 老板说：「把上周和这周的合并一下」——「合并」可以是拼接也可以是对比；
6. 输入数据里订单量字段名从 `orders` 变成了 `order_count`。

## 过关标准

- 六题对 ≥5；
- 每题的「怎么表现」都落在「停下来、说清楚、等人来」框架内。

## 参考答案（做完再看）

1. 输入错（部分空）→ 明示「本周无异常」而非编造，或按边界声明处理；
2. 环境错 → 重试一次，仍败则报告停止；
3. 能力限（对外发送，高风险！）→ 声明超边界，拒绝或升级人工；
4. 输入错 → 拒绝并说明范围限制；
5. 目标歧 → 列出两种理解请求确认；
6. 输入错 → 指出字段对不上，请求确认新字段映射。
