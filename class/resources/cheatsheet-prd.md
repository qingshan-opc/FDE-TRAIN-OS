# 速查卡 · PRD 最小骨架

> 一页记住：迷你 PRD 只有四根骨头。少一根，下游（架构/前端/后端）就会返工。

## 四根骨头

| 骨架 | 一句话 | 自检问题 |
|------|--------|----------|
| 1. 产品概述 | 这是什么、为谁解决什么问题 | 能用两句话向同事讲清吗？ |
| 2. 目标用户与平台 | 谁在用、在哪个端用 | 用户画像具体到岗位了吗？平台列全了吗？ |
| 3. 用户故事 | 作为【谁】，我想要【做什么】，以便【得到什么价值】 | 三格都填了吗？「以便」后面是真价值吗？ |
| 4. 验收标准 | 每个故事配可衡量的通过条件 | 换一个不了解项目的人，能据此判定过/不过吗？ |

## 验收标准铁律

- **可衡量**：带数字或明确状态（「3 秒内展示」「不超过 60 字」），不写「快」「好用」。
- **第三方可判**：验收人不问你也能打勾/打叉。
- 一条故事至少一条标准；标准不过 = 故事没完成，没有「差不多」。
