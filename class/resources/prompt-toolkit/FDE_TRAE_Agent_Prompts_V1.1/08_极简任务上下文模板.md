# 极简任务上下文模板

学员不需要填写技术任务单。正常情况下只需输入：

```text
@岗位名 请带我完成【这节课的目标】。
先用大白话复述，一次只问我一个问题；确认后分步完成，每一步都带我检查。
最后请先自检，再停下来等我批准，不要替下一岗位继续。
```

如果学员只给一句话，岗位 Agent 应自行整理以下内部上下文，不得把表格重新丢给学员填写：

```text
【当前项目和阶段】从已有文件识别
【本节目标和边界】从学员指令与已批准成果提炼
【需要读取和交付的文件】由岗位自己查找
【怎样算完成】转成学员可亲手操作、可看到结果的检查
【不影响方向的小决定】岗位采用稳妥方案并用大白话说明
【会影响方向的问题】一次只问学员一个
```

## 批准与纠偏

批准必须单独明确表达：

```text
我检查通过，批准当前成果。请只给我下一岗位的一句话任务，不要替它执行。
```

纠偏建议使用：

```text
我暂不批准。问题是：【我实际看到什么】；我希望变成：【正确结果】。
请只修这个问题，修好后带我重新检查，不要增加新功能。
```

每次批准或返工后，请在工作区追加记录到 `docs/D{N}_command_log.md`（N 为当天 1–5），包含岗位、状态（APPROVED/REJECTED）、问题与目标。

“继续”“完成后端”“开始测试”等均不等于批准上游交付物。
