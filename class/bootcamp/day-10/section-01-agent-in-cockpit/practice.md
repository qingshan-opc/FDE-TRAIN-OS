# 第 1 节 · 练习：助手位接入三要件（随堂 25′）

## 任务 A · 唤起（≤8′）

- 在驾驶舱助手区块做出最小对话口：输入框 + 发送 + 回显；
- 发一条测试消息，确认 Agent 有响应（或降级：指令面板可复制指令到 Agent Lab）。

✓ 通过标准：从驾驶舱发出的指令，Agent 实际执行了一次。

## 任务 B · 状态（≤8′）

- 助手位显示流水线当前步骤：读 `runs/` 最新日志行，渲染成「步骤名 + 状态图标」；
- 手动跑一步，看驾驶舱状态是否更新。

✓ 通过标准：Agent 跑了一步，驾驶舱不用问就知道它干了什么。

## 任务 C · 闸在页内（≤9′，优先级最高，先做也可以）

- B 的草稿渲染进助手位：草稿 + 关键数字 + 风险标红；
- 「批准」「驳回（带理由输入）」两个按钮，点击结果写回流水线。

✓ 通过标准：不离开驾驶舱，完成一次「驳回 → 重做 → 批准」全流程。
