## 这一天在解决什么

Day 7 一件工具，Day 8 挂上 Agent。今天做全课最重要的一块设计：

1. **编排观**：业务流程即编排——把多步流程拆成 Skill 的串联，步骤你定死（workflow）（第 1 节，15′）；
2. **信任的工程设计**：人工确认点 + 执行日志——对外/改数据/花钱的步骤前必须过人工闸，每一步留痕（第 2 节，15′）;
3. **动手**：再封装两个 Skill（复用 D7 全流程，提速）→ 编排三 Skill 流水线 + 确认闸 + 执行日志（第 3–4 节，65′）。

**不再单开一节「验收课」**——闸口实测与 GATE 9 在 Lab / 企业任务节点完成。

> 概念只讲最小必要版；BPMN、工作流引擎、审批流系统 → 公开课 O2。
