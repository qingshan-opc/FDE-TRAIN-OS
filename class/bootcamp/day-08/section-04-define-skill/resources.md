## 必读

- 模板：第 2 节 resources 的 Markdown 四段式

## 完整示例（运营周报 Skill，可对照不可照抄）

```markdown
# Skill: 运营周报生成

## 输入
- 来源：你系统里真能调到的接口或导出（近7天）；有驾驶舱 KPI/异常更好
- 范围：本周（周一至今）
- 读者：部门总监，用于周会开场

## 步骤
1. 拉取本周每日 KPI 与 open 异常清单
2. 对比今日与 7 天前，找出变化最大的 2 个指标
3. 按逾期天数降序，列出前 3 张异常工单（负责人+逾期天数）
4. 按输出格式生成周报，自检数字出处

## 输出
- 格式：Markdown 四段（头条/数据/风险/建议）
- 长度：≤300 字
- 红线：只用来源中真实数字；无感叹号
- 示例：（贴一段上周写的好周报）

## 验收
- 结构：四段齐全
- 数字：每个数字能在来源数据中找到出处
- 意图：变化最大的指标必须出现在头条
- 建议：主语是人、可执行，无「建议关注」
```

## 模糊词替换速查

| 🚫 愿望 | ✅ 动作 |
|---------|--------|
| 分析一下数据 | 找出环比变化最大的 2 个指标 |
| 整理一下工单 | 按逾期天数降序列出前 3 张 |
| 写个总结 | 按四段格式生成 ≤300 字周报 |
